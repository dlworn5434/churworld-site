적용 방법
1. 압축을 푼다
2. 안의 src, public 폴더를 기존 Astro 프로젝트에 덮어쓴다
3. PowerShell에서 실행:
   cd C:\Users\dlwor\Desktop\churworld-site
   npm.cmd run dev
4. 브라우저에서 http://localhost:4321 확인
