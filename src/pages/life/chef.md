## 요리사 핵심 요약

요리사는 **손질도마·후라이팬·재료 냉장고**로 재료를 손질하고, 노멀(일반)·실버(은별)·골드(금별) 품질의 요리를 만드는 생산 직업이야.

기존 요리사 조리대·프라이어와 `/life cook`의 조리창은 사용이 종료됐어. 새 주방 도구를 설치해서 이용해 줘.

- 기본 성공 확률 80%, 실패 확률 20%
- 품질 기본 가중치: 노멀 80 / 실버 15 / 골드 5
- 후라이팬은 **일반 우클릭 한 번에 한 번씩** 조리해
- 기본 조리 시간은 15초이며 스탯·스킬·뒤집개 효과로 줄일 수 있어
- 도마는 칼로 손질하고, 손질 완료 횟수에 따라 자동으로 성장해
- 냉장고 하나에 **왼쪽 도마 1개·오른쪽 후라이팬 최대 3개**를 연결할 수 있어
- 완성한 요리를 먹으면 품질과 재료에 따라 마나를 회복해
- 실패하면 결과 아이템과 요리사 숙련 EXP를 받지 못해

공용 스탯과 요리사 스킬에 따라 실제 성공률, 품질과 결과 수량은 달라질 수 있어.

## 주방 준비와 설치

손질도마·후라이팬·재료 냉장고·손질용 칼은 **흔한 작업대**에서 제작할 수 있어. 필요한 재료는 게임 안 제작 화면에서 확인해 줘.

- 설치할 권한이 있는 곳에서 도구를 들고 **블록 윗면을 우클릭**해.
- 설치한 사람이 주인이 되며, **설치한 주인만 사용**할 수 있어.
- 냉장고는 세로 두 칸의 빈 공간이 필요해.
- 냉장고와 연결하려면 도구를 **같은 사람이 같은 방향으로** 설치해.

냉장고 정면에서 바라봤을 때의 배치는 다음과 같아.

| 바로 왼쪽 | 가운데 | 오른쪽 1칸 | 오른쪽 2칸 | 오른쪽 3칸 |
| --- | --- | --- | --- | --- |
| 손질도마 | 재료 냉장고 | 후라이팬 | 후라이팬 | 후라이팬 |

도마는 바로 왼쪽에, 팬은 바로 오른쪽부터 **빈칸 없이 연속으로** 놓아야 해. 냉장고 바닥과 같은 높이나 **한 칸 높은 상판**에 둘 수 있어. 같은 옆 칸의 위아래에 도구를 겹쳐 두면 연결되지 않아.

냉장고는 재료 공급을 돕는 가구야. 냉장고 없이도 도마와 팬에 직접 재료를 넣어 사용할 수 있어.

## 기본 조작

| 조작 | 기능 |
| --- | --- |
| 뒤집개를 양손에서 내려놓고 도마·팬·냉장고 Shift + 우클릭 | 설정 화면 열기 |
| 뒤집개를 주 손 또는 보조 손에 들고 Shift + 우클릭 | 냉장고를 부탁해 스킬 사용 |
| 도마·팬의 설정 화면에서 레시피 선택 | 만들 항목 준비 |
| 설정 화면 아래 인벤토리의 재료 클릭 | 필요한 재료 넣기 |
| 설정 화면 위 보관 재료 클릭 | 재료 꺼내기 |
| 냉장고 설정 화면에서 재료 Shift + 클릭 | 같은 아이템을 빈 공간만큼 한 번에 이동 |
| 필요한 재료를 들고 도마·팬 우클릭 | 손에 든 재료 넣기 |
| 손질용 칼을 주 손에 들고 도마 좌클릭 | 손질 진행 |
| 재료가 준비된 팬 일반 우클릭 | 요리 한 번 시작 |

진행 중인 제작은 레시피를 바꿀 수 없어. 제작이 끝난 뒤 **레시피 변경**을 누르면 공급을 잠시 멈추고 남은 재료를 연결 냉장고로 돌려보내. 새 항목을 고르거나 변경을 취소하면 이전 공급 설정으로 돌아와. 반환할 공간이 부족하면 먼저 빈칸을 마련해 줘.

## 손질도마 사용하기

1. 도마를 **Shift + 우클릭**하고 원하는 손질 레시피를 골라.
2. 설정 화면이나 재료를 든 우클릭으로 재료를 넣어. 연결된 냉장고에서도 공급받을 수 있어.
3. 재료가 준비되면 **손질용 칼을 주 손에 들고 좌클릭**해. 도마 위에 필요한 손질 횟수가 표시돼.
4. 마지막 손질이 끝나면 완성품이 도마 앞쪽으로 나와. 가까이 가서 주우면 돼.

손질에는 실패가 없어. 요리의 품질·추가 생산·숙련 보상 대신 **해당 도마의 성장**이 적용돼. **칼과 불의 호흡**을 배웠다면 손질 완료 때 다음 요리에 쓸 손질 보너스도 쌓여.

### 도마 자동 성장

도마는 손질을 한 건 끝낼 때마다 완료 횟수가 쌓여. 클릭 횟수나 결과물 개수가 아니라 **손질 완료 횟수**로 성장하며, 별도 강화 비용은 들지 않아.

| 도마 단계 | 누적 손질 완료 | 한 번 손질에 필요한 클릭 |
| --- | ---: | ---: |
| 0단계 | 0회 | 10회 |
| 1단계 | 300회 | 9회 |
| 2단계 | 1,000회 | 8회 |
| 3단계 | 2,000회 | 7회 |

성장한 단계는 다음 손질부터 적용돼. 설정 화면에서 진행도를 확인할 수 있고, 도마를 회수해 다시 설치해도 성장 기록은 유지돼.

## 후라이팬 사용하기

1. 팬을 **Shift + 우클릭**하고 만들 레시피를 골라.
2. 필요한 재료를 직접 넣거나 냉장고에서 공급받아 **조리 준비 완료** 상태로 만들어.
3. 설정 화면을 닫고 팬을 **일반 우클릭**하면 한 번 조리해. 뒤집개 효과를 받으려면 시작할 때 뒤집개를 들어 줘.
4. 팬 위의 남은 시간과 진행 막대를 확인하고, 완성품이 앞쪽으로 나오면 주워.

재료를 넣은 클릭이나 레시피 선택만으로는 팬이 시작되지 않아. 완성된 뒤에도 다음 요리는 **다시 우클릭해야** 시작돼. 빈손으로 시작할 수도 있어.

설정 화면을 닫아도 조리는 계속돼. 주인이 접속 중이고 주방이 있는 지역이 로드돼 있을 때 진행되므로, 접속 종료나 지역 로드 해제 중에는 진행이 멈춰.

여러 팬을 동시에 쓰려면 [뒤집개의 내구성 인챈트](#뒤집개-사용하기)를 준비해. 팬을 여러 개 설치하는 것과 동시에 조리할 수 있는 수는 별개야.

## 냉장고로 재료 공급하기

냉장고는 **27칸**에 재료를 보관해. Shift + 우클릭으로 열고 아래 인벤토리의 아이템을 클릭하면 넣고, 위 보관 재료를 클릭하면 꺼낼 수 있어.

도마와 팬에서 레시피를 먼저 선택해 두면, 연결된 냉장고가 **다음 한 번 제작에 부족한 재료만** 공급해. 같은 재료를 여러 도구에서 쓰면 왼쪽 도마부터 공급하니 재고를 확인해 줘. 팬은 공급이 끝나도 직접 우클릭해야 조리를 시작해.

- 냉장고의 **자동 공급 ON/OFF**로 연결된 도구 전체에 공급을 켜거나 끌 수 있어.
- 후라이팬에도 **자동 공급 ON/OFF**가 있어. 특정 팬에만 재료를 보내고 싶지 않을 때 꺼 줘.
- 공급을 꺼도 이미 시작한 요리는 계속 진행돼.
- 냉장고를 내용물째 회수해 다시 설치하면 공급은 **OFF**로 시작해. 배치를 마친 뒤 켜 줘.

## 완성품 수령과 도구 회수

- 완성품은 도마·팬 앞쪽에 **일반 바닥 아이템**으로 떨어져. 다른 유저도 주울 수 있으며 호퍼와 가방 자동수거도 각 기능의 조건에 따라 작동해.
- 인벤토리와 가방이 모두 가득 차면 바닥에 남아. 일반 아이템처럼 소멸할 수 있으니 바로 챙겨 줘.
- 배출할 빈 공간이 없으면 배출 대기 상태가 돼. 도구 앞과 주변의 공간을 비워 줘.
- 도구를 옮길 때는 제작을 마친 뒤 설정 화면의 **도구 회수**를 눌러. 남은 재료는 연결 냉장고로 돌려보내며, 연결이 없으면 인벤토리 공간이 필요해.
- 냉장고는 **내용물째 회수**할 수 있어. 회수한 주인만 다시 설치할 수 있고, 재설치 후 자동 공급을 다시 켜야 해.

## 레시피 확인하기

팬·도마 설정 화면에서 만들 항목과 필요한 재료를 확인해. 요리 레시피북은 `/life recipes` 또는 `/life cookbook`으로 열 수 있어.

주방의 레시피 목록에서는 **휠·화살표·위아래 드래그**로 페이지를 넘길 수 있어. **Shift + 좌클릭**하면 가운데 3×3 화면에서 재료 아이콘과 필요 수량을 확인해. 미리보기에서는 재료를 꺼내거나 소모하지 않으며, 돌아가기나 ESC로 닫을 수 있어.

요리책에서는 목록·상세·검색·정렬을 이용할 수 있어. **우클릭과 Shift + 우클릭도 조회만 가능**하며, 기존 조리창 열기와 재료 자동 배치는 지원하지 않아.

## 요리사 스킬

현재 사용할 수 있는 요리사 스킬은 **6개**야.

| 스킬 | 효과 | 1 / 10 / 20 / 25 / 30 / 35랭크 기준 |
| --- | --- | --- |
| 손맛 | 노멀 결과를 실버로 승급 | +1 / +10 / +20 / +28 / +36 / +44%p |
| 손맛 | 실버 결과를 골드로 승급 | +0.4 / +4 / +8 / +12.5 / +17 / +21.5%p |
| 대가의 한 숟갈 | 완성품 1개 추가 획득 | 0.75 / 7.5 / 15 / 21 / 27 / 33% |
| 비법 양념 | 양념을 소모해 골드 품질 확정 | 고정 1랭크 |
| 냉장고를 부탁해 | 효과 중 시작한 요리의 조리 시간 단축 | 지속 12 / 20 / 30 / 36 / 41 / 46초 |
| 달아오른 주방 | 음식 요리 성공을 이어가면 다음 조리 시간 단축 | 35랭크에서 열기 1 / 2 / 3단계별 5 / 10 / 15% 감소 |
| 칼과 불의 호흡 | 도마 손질로 보너스를 쌓아 다음 음식 요리의 실패 확률 감소 | 35랭크에서 남은 실패 확률 30% 감소 |

**손에 익은 레시피·정성 한 스푼**은 제거됐어. 투자했던 포인트는 돌려받고, 해당 장비 잠재는 중복되지 않는 다른 요리 스킬로 전환돼. 같은 메뉴를 반복하는 재료 절약과 이 두 스킬의 추가 황금 효과는 더 이상 적용되지 않아.

### 냉장고를 부탁해

뒤집개를 **주 손 또는 보조 손에 들고 Shift + 우클릭**하면 사용할 수 있어. 효과가 유지되는 동안 **새로 시작한 요리**에 조리 시간 감소가 적용돼. 냉장고 가구의 자동 재료 공급과는 별도 기능이야. 주방 설정을 열 때는 뒤집개를 양손에서 내려놓아 줘.

| 항목 | 1 / 10 / 20 / 25 / 30 / 35랭크 |
| --- | --- |
| 조리 시간 배율 | 0.85 / 0.78 / 0.68 / 0.58 / 0.48 / 0.38배 |
| 재사용 대기시간 | 90 / 80 / 65 / 60 / 58 / 55초 |
| 마나 소모 | 30 |

이미 진행 중인 요리의 시간은 소급해서 줄어들지 않아. 팬을 우클릭해 시작하는 시점에 스킬 효과가 남아 있어야 해.

### 달아오른 주방

음식 요리를 **5 / 10 / 20회 성공**하면 열기가 1 / 2 / 3단계로 올라가. 다음에 시작하는 조리 시간이 줄어들며, 낮은 스킬 랭크에서는 효과도 그에 비례해 적용돼.

실제로 조리하거나 유효한 도마 손질을 하는 동안 유지돼. 활동을 멈춘 뒤 45초까지 유지되고, 그 뒤에는 30초마다 단계가 내려가. 창만 열어 두거나 실패한 요리로 성공 횟수를 늘릴 수는 없어.

### 칼과 불의 호흡

도마 손질을 한 건 끝낼 때마다 **손질 보너스 1회분**, 최대 **3회분**을 쌓아. 다음 음식 조리를 시작할 때 1회분을 사용해 남은 실패 확률을 줄여. 예를 들어 35랭크에서 실패 확률 20%는 14%가 돼. 여러 팬에서 같은 보너스를 중복으로 쓰지는 않아.

두 패시브는 별도 키 입력이나 추가 마나 소모가 없어. 떡밥에는 적용되지 않으며, **열기와 손질 보너스는 재접속·서버 재시작 시 초기화**돼.

최신 런처 모드에서는 열기 단계에 따라 팬 테두리의 주황빛과 음식 위 김이 보이고, 손질 보너스를 얻거나 사용할 때 칼날·궤적 연출이 나타나. 보이지 않으면 게임과 런처를 완전히 종료한 뒤 업데이트해 줘.

## 뒤집개 사용하기

뒤집개를 **주 손 또는 보조 손에 들고 팬을 우클릭**하면 인챈트 효과를 받을 수 있어. 주 손에 칼, 보조 손에 뒤집개를 들어도 돼.

양손에 뒤집개가 있으면 **주 손의 뒤집개 하나만** 적용돼. 효과는 조리 시작 시 결정되므로, 시작 후 손을 바꿔도 진행 중인 요리의 효과는 바뀌지 않아.

| 인챈트 | 효과 |
| --- | --- |
| 행운 I~III | 레벨당 실버 기본 가중치 +5%, 골드 기본 가중치 +10% |
| 효율 I~V | 레벨당 조리 시간 5% 감소, V에서 25% 감소 |
| 내구성 없음·I | 동시 조리 1개 |
| 내구성 II | 동시 조리 2개 |
| 내구성 III | 동시 조리 3개 |

행운은 품질 확률에 %p를 직접 더하는 방식이 아니라 **기본 가중치를 늘리는 효과**야. 동시 조리 수는 본인의 진행 중인 팬 전체를 세며, 다른 월드에 있거나 잠시 로드되지 않은 팬도 포함해. 뒤집개가 없으면 1개이고 최대 3개까지야. 조리를 시작한 뒤 뒤집개를 내려놓아도 기존 조리는 계속되지만, 새 조리를 시작할 때는 그때 들고 있는 뒤집개로 한도를 확인해.

## 비법 양념

비법 양념 스킬을 배운 뒤 팬에 비법 양념을 함께 넣으면 골드 결과가 있는 요리를 **골드 품질로 확정**할 수 있어.

- 요리 1개마다 비법 양념 1개 소모
- 연결된 냉장고에 양념을 보관해 두면 적용 가능한 요리에 한 번분씩 자동 공급
- 골드 결과가 없는 레시피에는 사용할 수 없음

## 음식을 먹고 마나 회복하기

후라이팬에서 만든 요리를 끝까지 먹으면 **음식 1개마다** 다음 마나를 회복해. 배고픔이 가득 차 있어도 먹을 수 있어. 이전에 만든 같은 요리도 마나 회복을 받을 수 있어.

| 요리 종류 | 노멀 | 실버 | 골드 |
| --- | ---: | ---: | ---: |
| 기본 요리 | 3 | 5 | 10 |
| 물고기가 들어간 요리(무지개 요리) | 5 | 7 | 15 |

- 현재 마나의 최대치를 넘겨 회복되지는 않아.
- 먹는 도중 멈추면 마나가 회복되지 않아.
- 일반 바닐라 음식이나 떡밥에는 이 요리 마나 회복이 적용되지 않아.
- `/life mana`로 현재 마나를 확인할 수 있어.

## 추천 투자 방향

- 실패 감소와 숙련 성장: **지식**
- 높은 품질: **손맛 + 행운**
- 결과물 수량: **대가의 한 숟갈 + 감각**
- 빠른 조리: **근로 + 냉장고를 부탁해**
- 계속 요리하기: **달아오른 주방**
- 손질과 요리를 함께 하기: **칼과 불의 호흡**
