## 요리사 핵심 요약

요리사는 재료를 조리대에서 조합해 **노멀 · 실버 · 골드** 결과를 노리는 직업이야.

- 기본 성공 확률 80%
- 기본 실패 확률 20%
- 품질 체계는 노멀 / 실버 / 골드
- 보너스 테이블이 통과되면 추가 아이템이 붙을 수 있어

## 공용 스탯 체감

| 스탯 | 효과 |
| --- | --- |
| 근로 | 조리 시간 감소 |
| 지식 | 성공률 증가 |
| 감각 | 추가 산출 확률 증가 |
| 행운 | 실버 / 골드 결과 가중치 증가 |
| 흥정 · 명성 | 현재 핵심 미적용 |

## 요리사 스킬

| 스킬 | 설명 |
| --- | --- |
| 손맛 | 결과 등급 승급 확률 증가 |
| 대가의 한 숟갈 | 추가 산출 확률 증가 |
| 비법 양념 | 조건 충족 시 골드 등급 확정 |
| 냉장고를 부탁해 | 일정 시간 동안 요리 시간을 줄이는 액티브 |

## 레시피북

- `/life recipes` 또는 `/life cookbook` 으로 요리 레시피북을 열 수 있어
- 실전 조리는 **요리사 조리대**에서 진행하는 흐름을 먼저 익히는 편이 좋아

## 추천 플레이 감각

- 실패를 줄이고 싶으면 **지식**
- 더 좋은 품질을 노리면 **행운**
- 한 번에 많이 만들고 싶으면 **감각**
- 대량 제작 위주면 **근로** 체감이 큰 편이야
