## 요리사 핵심 요약

요리사는 재료를 조리대에서 조합해 **노멀·실버·골드** 품질의 요리를 만드는 생산 직업이야.

- 기본 성공 확률 80%, 실패 확률 20%
- 품질 기본 가중치: 노멀 80 / 실버 15 / 골드 5
- 기본 최대 10회까지 순차 조리를 등록하며, 요리 1회마다 기본 10초가 적용돼
- 뒤집개의 내구성 인챈트로 일괄 등록 상한을 최대 20회까지 늘릴 수 있어
- 완성한 요리를 먹으면 품질과 재료에 따라 마나를 회복해
- 실패하면 결과 아이템과 요리사 숙련 EXP를 받지 못해

| 결과 품질 | 기본 가중치 | 요리사 숙련 EXP |
| --- | ---: | ---: |
| 노멀 | 80 | 15 |
| 실버 | 15 | 22 |
| 골드 | 5 | 50 |

공용 스탯과 요리사 스킬에 따라 실제 성공률, 품질과 결과 수량은 달라질 수 있어.

## 공용 스탯 체감

| 스탯 | 효과 |
| --- | --- |
| 근로 | 조리 시간 감소 |
| 지식 | 성공률과 요리사 숙련 EXP 증가 |
| 감각 | 추가 결과물 획득 확률 증가 |
| 행운 | 실버·골드 품질 가중치 증가 |

## 요리사 스킬

| 스킬 | 효과 | 1 / 10 / 20 / 25 / 30 / 35랭크 기준 |
| --- | --- | --- |
| 손맛 | 노멀 결과를 실버로 승급 | +1 / +10 / +20 / +28 / +36 / +44%p |
| 손맛 | 실버 결과를 골드로 승급 | +0.4 / +4 / +8 / +12.5 / +17 / +21.5%p |
| 대가의 한 숟갈 | 완성품 1개 추가 획득 | 0.75 / 7.5 / 15 / 21 / 27 / 33% |
| 비법 양념 | 양념을 소모해 골드 품질 확정 | 고정 1랭크 |
| 냉장고를 부탁해 | 효과 중 시작한 요리의 조리 시간 단축 | 지속 12 / 20 / 30 / 36 / 41 / 46초 |

### 냉장고를 부탁해

스킬을 사용한 뒤 효과가 유지되는 동안 **새로 시작한 요리**에 조리 시간 감소가 적용돼.

| 항목 | 1 / 10 / 20 / 25 / 30 / 35랭크 |
| --- | --- |
| 조리 시간 배율 | 0.85 / 0.78 / 0.68 / 0.58 / 0.48 / 0.38배 |
| 재사용 대기시간 | 90 / 80 / 65 / 60 / 58 / 55초 |
| 마나 소모 | 30 |

이미 진행 중인 1회분의 시간은 소급해서 줄어들지 않아. 여러 개를 순차 조리할 때는 다음 1회분이 시작되는 시점에 냉장고 효과가 남아 있어야 시간 감소가 적용돼.

## 조리대 사용 방법

1. 요리사 조리대를 열고 가운데 재료 칸에 레시피 재료를 넣어.
2. 재료의 종류와 수량이 맞으면 순서와 관계없이 조리를 시작할 수 있어.
3. 좌클릭하면 1회, Shift+좌클릭하면 재료와 뒤집개가 허용하는 상한까지 등록해.
4. 요리는 **한 개씩 순서대로 완성**돼. 시간 보정이 없다면 10회 조리는 기본 총 100초가 필요해.
5. 조리대를 닫아도 작업은 계속돼. 진행 중에는 다른 요리를 새로 시작할 수 없으니 현재 묶음이 끝날 때까지 기다려.

## 뒤집개 사용하기

뒤집개를 **주 손에 들고 조리를 시작**하면 인챈트 효과를 받을 수 있어.

| 인챈트 | 효과 |
| --- | --- |
| 행운 I~III | 레벨당 실버 기본 가중치 +5%, 골드 기본 가중치 +10% |
| 효율 I~V | 레벨당 조리 시간 5% 감소, V에서 25% 감소 |
| 내구성 I / II / III | 일괄 등록 상한을 12 / 15 / 20회로 증가 |

뒤집개가 없거나 내구성 인챈트가 없으면 등록 상한은 10회야. 행운 효과는 품질 확률에 %p를 직접 더하는 방식이 아니라 **기본 가중치를 늘리는 효과**야. 조리 시작 시의 뒤집개 효과가 예약한 요리에 적용돼.

## 레시피북과 자동 배치

- `/life recipes` 또는 `/life cookbook`으로 요리 레시피북 열기
- 레시피 우클릭: 1개분 자동 배치
- Shift+우클릭: 재료와 뒤집개의 일괄 등록 상한까지 자동 배치
- 기본 요리 6종과 무지개 요리 6종은 [생활 제작법](/life/recipes#요리-레시피)에서 확인

## 비법 양념

비법 양념 스킬을 배운 뒤 조리대의 전용 칸에 양념을 넣으면 골드 결과가 있는 요리를 **골드 품질로 확정**할 수 있어.

- 요리 1개마다 비법 양념 1개 소모
- 여러 개를 시작하면 등록 수량만큼 양념 필요
- 골드 결과가 없는 레시피에는 사용할 수 없음

## 음식을 먹고 마나 회복하기

조리대에서 만든 요리를 끝까지 먹으면 **음식 1개마다** 다음 마나를 회복해. 배고픔이 가득 차 있어도 먹을 수 있어.

| 요리 종류 | 노멀 | 실버 | 골드 |
| --- | ---: | ---: | ---: |
| 기본 요리 | 3 | 5 | 10 |
| 물고기가 들어간 요리(무지개 요리) | 5 | 7 | 15 |

- 현재 마나의 최대치를 넘겨 회복되지는 않아.
- 먹는 도중 멈추면 마나가 회복되지 않아.
- 일반 바닐라 음식이나 떡밥에는 이 요리 마나 회복이 적용되지 않아.
- `/life mana`로 현재 마나를 확인할 수 있어.

## 추천 투자 방향

- 실패 감소와 숙련 성장: **지식**
- 높은 품질: **손맛 + 행운**
- 결과물 수량: **대가의 한 숟갈 + 감각**
- 빠른 묶음 생산: **근로 + 냉장고를 부탁해**
