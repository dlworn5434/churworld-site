## 요리사 핵심 요약

요리사는 재료를 조리대에서 조합해 **노멀 · 실버 · 골드** 결과를 만드는 생산 직업이야.

- 기본 성공 확률 80%
- 기본 실패 확률 20%
- 품질 체계는 노멀 / 실버 / 골드
- 기본 조리 시간은 **요리 1개당 10초**이며, 한 번에 최대 10개까지 대기열에 넣을 수 있어

성공한 요리의 기본 품질 가중치와 숙련 EXP는 다음과 같아. 공용 스탯과 요리사 스킬에 따라 실제 결과 확률은 달라질 수 있어.

| 결과 품질 | 기본 가중치 | 요리사 숙련 EXP |
| --- | ---: | ---: |
| 노멀 | 80 | 8 |
| 실버 | 15 | 12 |
| 골드 | 5 | 20 |

실패하면 결과 아이템과 요리사 숙련 EXP를 받지 못해.

## 공용 스탯 체감

| 스탯 | 효과 |
| --- | --- |
| 근로 | 조리 시간 감소 |
| 지식 | 성공률과 요리사 숙련 EXP 증가 |
| 감각 | 추가 산출 확률 증가 |
| 행운 | 실버 / 골드 결과 가중치 증가 |
| 흥정 · 명성 | 현재 핵심 미적용 |

## 요리사 스킬

| 스킬 | 설명 |
| --- | --- |
| 손맛 | 결과 등급 승급 확률 증가 |
| 대가의 한 숟갈 | 추가 산출 확률 증가 |
| 비법 양념 | 전용 칸에 넣은 요리 1개당 양념 1개를 소모해 골드 등급 확정 |
| 냉장고를 부탁해 | 일정 시간 동안 요리 시간을 줄이는 액티브 |

## 조리대 사용 방법

1. 요리사 조리대를 열고 가운데 재료 칸에 레시피 재료를 넣어.
2. 재료 배치는 순서와 관계없으며, 필요한 종류와 수량이 맞으면 조리를 시작할 수 있어.
3. **좌클릭**하면 1개를, **Shift + 좌클릭**하면 재료가 허용하는 범위에서 최대 10개를 조리해.
4. 여러 개를 한꺼번에 시작하면 한 개씩 순서대로 조리돼. 기본 기준으로 10개는 약 100초가 걸리며, 근로·도감·스킬 효과에 따라 실제 시간은 줄어들 수 있어.
5. 조리대를 닫아도 진행은 계속되며, 완료 후 결과를 받아가면 돼.

## 레시피북과 자동 배치

- `/life recipes` 또는 `/life cookbook` 으로 요리 레시피북을 열 수 있어
- 레시피를 **우클릭**하면 1개분, **Shift + 우클릭**하면 최대 10개분의 재료를 조리대에 자동 배치해
- 기본 요리 6종과 무지개 요리 6종의 정확한 재료는 [생활 제작법](/life/recipes#요리-레시피)에서 확인할 수 있어

## 비법 양념

`비법 양념` 스킬을 1랭크 배운 뒤 조리대의 전용 칸에 비법 양념을 넣으면 해당 요리를 **골드 등급으로 확정**할 수 있어.

- 요리 1개마다 비법 양념 1개가 필요해
- 여러 개를 조리하면 시작하는 수량만큼 양념도 준비해야 해
- 레시피에 골드 결과가 있는 요리에만 사용할 수 있어

## 추천 플레이 감각

- 실패를 줄이고 싶으면 **지식**
- 더 좋은 품질을 노리면 **행운**
- 한 번에 많이 만들고 싶으면 **감각**
- 대량 제작 위주면 **근로** 체감이 큰 편이야
