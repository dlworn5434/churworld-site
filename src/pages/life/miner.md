## 광부 핵심 요약

광부는 **바닐라 광석**과 야생에 나타나는 **커스텀 광맥 노드**를 함께 채굴하는 직업이야.

- 커스텀 광맥은 다이아몬드 곡괭이 이상으로 반복 타격해야 해
- 광석 감지는 주변 광석을 본인 화면에 발광 윤곽선으로 표시해
- 광부의 각성은 빠른 채굴을 돕고, 상위 스킬 각성 초월은 각성 중 한 번의 3×3 굴착을 제공해
- 광부에서 체감이 큰 공용 스탯은 근로·지식·감각·행운이야

## 공용 스탯 체감

| 스탯 | 효과 |
| --- | --- |
| 근로 | 커스텀 광맥에 주는 타격 피해 증가 |
| 지식 | 광부 숙련 EXP 증가 |
| 감각 | 커스텀 광맥을 다시 타격할 수 있는 간격 감소 |
| 행운 | 추가 광물 획득 확률 증가 |

## 광부 스킬

스킬 수치는 장비·도감·큐브 보너스를 포함한 **최종 유효 랭크**에 따라 적용돼. 직접 투자 상한과 최종 유효 상한의 차이는 [성장 구조](/life/growth#생활-스킬-랭크-구조)에서 확인할 수 있어.

| 스킬 | 효과 | 1 / 10 / 20 / 25 / 30 / 35랭크 기준 |
| --- | --- | --- |
| 광맥 파괴 | 연결된 같은 광석을 연쇄 채굴 | 최대 6 / 12 / 20 / 26 / 32 / 38블록 |
| 광맥 파괴 발동 | 연쇄 채굴 발동 확률 | 0.6 / 1.7 / 3 / 4 / 5 / 6% |
| 광맥 파괴 재사용 | 다시 발동할 수 있는 시간 | 180 / 155 / 120 / 95 / 70 / 45초 |
| 암벽 분쇄 | 커스텀 광맥 노드 타격 피해 증가 | 현재 수치는 게임 안 스킬 설명에서 확인 |
| 광물 잔재 | 바닐라 광물 추가 획득 확률 | 0.75 / 7.5 / 15 / 20 / 25 / 30% |
| 광석 감지 | 주변 광석을 찾아 표시 | 반경 10 / 16 / 22 / 28 / 34 / 36블록 |
| 광부의 각성 | 성급함과 야간 투시로 채광 보조 | 지속 8 / 14 / 20 / 29 / 38 / 47초 |
| 각성 초월 | 각성 중 첫 유효 좌클릭으로 3×3 굴착 | 길이 3 / 5 / 7 / 8 / 10 / 15블록 |

### 광석 감지

곡괭이를 들고 **Shift+우클릭**하거나 전용 클라이언트에서 지정한 생활 스킬 보조키로 사용해. 표시된 윤곽선은 본인 화면에서만 보여.

| 항목 | 1 / 10 / 20 / 25 / 30 / 35랭크 |
| --- | --- |
| 지속 시간 | 18 / 24 / 32 / 41 / 50 / 59초 |
| 최대 표시 수 | 24 / 36 / 52 / 60 / 72 / 84개 |
| 재사용 대기시간 | 300 / 250 / 190 / 143 / 95 / 80초 |
| 마나 소모 | 35 |

광석 감지에 직접 15랭크 이상 투자하면 표시 우선순위를 바꿀 수 있어.

- `/광부 모드변경 가치`: 가치가 높은 광석부터 표시
- `/광부 모드변경 거리`: 가까운 광석부터 표시

바꾼 모드는 다음 광석 감지부터 적용돼.

### 광부의 각성과 각성 초월

곡괭이를 들고 **Shift+C**, 전용 보조키 또는 스킬 화면의 발동 버튼으로 광부의 각성을 사용할 수 있어.

- 20랭크 미만: 성급함 I
- 20랭크 이상: 성급함 II와 야간 투시
- 마나 소모: 20
- 재사용 대기시간: 1 / 10 / 20 / 25 / 30 / 35랭크에서 240 / 205 / 165 / 128 / 90 / 52초

`각성 초월`은 광맥 파괴 10, 광부의 각성 10, 광물 잔재 5에 **직접 투자**해야 배울 수 있어. 각성 중 처음으로 유효한 천연 암석을 평범하게 좌클릭하면 전방에 3×3 굴착이 한 번 발생해.

- 초월 굴착을 위해 Shift+좌클릭할 필요는 없어
- 광석, 유저가 설치한 블록, 커스텀 작물과 권한이 없는 블록은 건드리지 않아
- 유효하지 않은 블록을 누르면 초월 굴착 기회가 소모되지 않아

## 채광 숙련 EXP

바닐라 광석은 종류에 따라 광부 숙련 EXP가 달라.

| 광석 | EXP | 광석 | EXP |
| --- | ---: | --- | ---: |
| 석탄 | 3 | 구리 | 1 |
| 철 | 6 | 금 | 13 |
| 레드스톤 | 4 | 청금석 | 6 |
| 다이아몬드 | 42 | 에메랄드 | 46 |
| 네더 금광석 | 4 | 네더 석영 | 2 |
| 고대 잔해 | 98 | 심층암 광석 | 같은 광석의 일반형과 동일 |

커스텀 광맥 노드는 등급에 따라 30 / 74 / 198 EXP를 줘.

## 야생 커스텀 광맥

야생 1~6에서 활동하면 **기어 브론즈·코어 스틸·심연 프리즘** 광맥이 주변에 나타날 수 있어.

- 다이아몬드 곡괭이 이상으로 여러 번 타격해 채굴해
- 광맥을 바라보면 필요한 도구와 현재 진행도를 확인할 수 있어
- 채굴되지 않은 광맥은 생성 후 15분이 지나면 사라질 수 있어
- 생활 도감이나 마을 효과로 나타난 개인 광맥은 처음 30초 동안 소유자만 채굴할 수 있어

같은 지역의 공용 광맥을 계속 채굴하면 재생이 느려질 수 있어. 지역을 옮기거나 잠시 쉬면 활력이 회복되며 자세한 기준은 [지역 활력 시스템](/life/systems#지역-활력)에서 확인할 수 있어.

## 추천 투자 방향

- 연쇄 채굴: **광맥 파괴**
- 커스텀 광맥 중심: **암벽 분쇄 + 근로·감각**
- 추가 광물: **광물 잔재 + 행운**
- 탐험 채광: **광석 감지**
- 짧은 시간에 집중 채굴: **광부의 각성 → 각성 초월**
