## 광부 핵심 요약

광부는 **바닐라 광석**과 **커스텀 광맥(오어 노드)** 을 함께 다루는 직업이야.

- 바닐라 광석은 꾸준한 기본 수익과 성장에 연결돼
- 커스텀 광맥은 상위 재료 파밍과 전용 루프의 핵심이야
- 광석 감지와 각성 계열 스킬이 체감이 큰 편이야
- 커스텀 광맥은 **다이아 곡괭이 이상**이 필요해

## 광부가 먼저 알아둘 것

- 광부 전용 핵심은 커스텀 광맥이야
- 광부에서 체감이 큰 공용 스탯은 **근로 · 지식 · 감각 · 행운**
- 광석 감지 기능으로 주변 광물을 찾을 수 있어
- 오어 노드를 자주 캔다면 채굴 데미지 계열 스킬이 특히 중요해

## 공용 스탯 체감

| 스탯 | 효과 |
| --- | --- |
| 근로 | 커스텀 광물 데미지 증가 |
| 감각 | 커스텀 광물 타격 간격 감소 |
| 행운 | 추가 드롭 확률 증가 |
| 지식 | 광부 숙련 EXP 증가, 최대 약 10% |

## 광부 스킬

| 스킬 | 설명 |
| --- | --- |
| 광맥 파괴 | 연결된 동일 광물을 연쇄 채굴 |
| 암벽 분쇄 | 커스텀 광물(오어 노드) 채굴 데미지 증가 |
| 광물 잔재 | 채광 시 바닐라 광물 추가 드롭 확률 증가 |
| 광석 감지 | 주변 광석을 본인 화면의 발광 윤곽선으로 표시 |
| 광부의 각성 | 성급함 · 야간투시를 받아 채굴을 보조 |

## 광석 감지 사용법

곡괭이를 들고 **Shift + 우클릭**하면 광석 감지를 사용할 수 있어. 전용 LifeCore 클라이언트 모드에서는 조작 설정에 보조키를 지정하고 **Shift + 지정 키**로도 발동할 수 있어.

감지된 광석은 **본인 화면에서만 보이는 발광 블록 윤곽선**으로 나타나. 다른 유저의 화면에는 표시되지 않아.

장비와 도감의 추가 랭크까지 포함한 **유효 랭크** 기준 수치는 다음과 같아.

| 항목 | 유효 1랭크 → 30랭크 |
| --- | ---: |
| 감지 반경 | 10 → 34블록 |
| 지속 시간 | 18 → 50초 |
| 최대 표식 | 24 → 72개 |
| 마나 소모 | 35 |
| 재사용 대기시간 | 300 → 95초 |

찾고 싶은 방식에 따라 감지 우선순위를 바꿀 수 있어.

- `/life scan mode value`: 가치가 높은 광석부터 표시
- `/life scan mode distance`: 현재 위치에서 가까운 광석부터 표시

모드 변경은 다음 광석 감지부터 적용돼. 표식이 많아 길을 찾기 어렵다면 거리 우선, 희귀 광석을 먼저 확인하고 싶다면 가치 우선을 추천해.

## 야생 커스텀 광맥

야생 1~6에서 활동하다 보면 주변에 커스텀 광맥이 나타날 수 있어. 현재 확인할 수 있는 광맥은 **기어 브론즈 · 코어 스틸 · 심연 프리즘** 3종이야.

- **다이아 곡괭이 이상**으로 여러 번 타격해 채굴해
- 광맥을 바라보면 필요한 도구와 현재 진행도를 확인할 수 있어
- 채굴되지 않은 광맥은 생성된 뒤 **15분**이 지나면 사라져
- 생활 도감이나 마을 효과 타워로 나타난 개인 광맥은 처음 **30초 동안 소유자만** 채굴할 수 있고, 이후에는 다른 유저도 채굴할 수 있어

## 추천 플레이 감각

- 초반에는 철, 금, 청금석처럼 접근이 쉬운 광물을 꾸준히 캐는 편이 안정적이야
- 오어 노드를 중심으로 갈수록 **암벽 분쇄** 체감이 커져
- 탐험형 채굴을 자주 하면 **광석 감지** 우선순위가 높아져
- 광맥이 몰려 있는 구간에서는 **광부의 각성** 타이밍이 중요해
