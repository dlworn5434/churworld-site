## 광부 핵심 요약

광부는 **바닐라 광석**과 **커스텀 광맥**을 채굴하는 생활이야. 광부의 각성으로 광석을 찾고, 연쇄 채굴과 콤보를 이어 가며 황금광로·과열 굴착·블랙홀을 활용해.

- 커스텀 광맥은 **다이아몬드 곡괭이 이상**으로 반복 타격해.
- 황금광로·과열 굴착·블랙홀은 **야생 1~6에서 서바이벌 상태로 곡괭이를 사용할 때** 작동해.
- 다른 유저가 설치한 블록이나 보호된 구역을 마음대로 캐는 기능은 아니야.
- 현재 랭크의 효과와 남은 재사용 시간은 생활 스킬 화면에서 확인해.

## 공용 스탯 체감

| 스탯 | 효과 |
| --- | --- |
| 근로 | 커스텀 광맥 타격 피해 증가 |
| 지식 | 광부 숙련도 획득 증가, 채광 콤보 유지시간 증가 |
| 감각 | 커스텀 광맥을 다시 타격할 수 있는 간격 감소 |
| 행운 | 추가 광물 획득 확률 증가 |

콤보 유지시간은 기본 8초에서 지식에 따라 최대 20초까지 늘어나. 실제 채광을 이어 가면 유지시간이 갱신돼.

## 현재 광부 스킬

스킬 효과는 장비·도감·큐브 보너스를 포함한 **최종 유효 랭크**를 기준으로 적용돼. [직접 투자와 유효 랭크의 차이](/life/growth#생활-스킬-랭크-구조)도 확인해 줘.

| 스킬 | 주요 효과 |
| --- | --- |
| 광맥 파괴 | 연결된 같은 광석을 확률적으로 연쇄 채굴하고 바닐라 광물을 추가 획득. 재발동 대기시간 없음 |
| 암벽 분쇄 | 커스텀 광맥 타격 피해 증가와 타격 간격 감소 |
| 광부의 각성 | 광석 감지·성급함·야간투시 효과를 한 번에 사용 |
| 황금광로 | 자연 광석을 직접 캘 때 확률적으로 나타나는 광로를 타격해 보상 획득 |
| 과열 굴착 | 자연 암석을 직접 캐서 충전한 뒤 3×3 범위의 자연 암석 추가 채굴 |
| 콤보마스터 | 채광 콤보에 따른 보조 효과와 100콤보마다 블랙홀 충전 |

기존 **광물 잔재는 광맥 파괴**, **광석 감지는 광부의 각성**으로 합쳐졌고, **각성 초월은 황금광로**로 바뀌었어. 통합 전 중복 투자분은 포인트로 돌아오며 기존 확장권 권한은 유지돼. 예전 큐브 옵션도 통합된 스킬에 맞춰 반영돼.

## 광부의 각성 사용하기

곡괭이를 들고 **Shift + 우클릭**, **Shift + C**, 지정한 생활 보조키 또는 스킬 화면의 발동 버튼으로 사용해. `/life scan`도 같은 각성을 사용하며 `/life scan off`는 광석 감지 표시를 종료해.

- 광석 윤곽선은 본인 화면에만 보여.
- 마나는 한 번에 **35**를 소모해.
- 성급함은 20랭크 미만 I, 20랭크 이상 II이며, 야간투시는 각성을 사용할 때 함께 적용돼.
- 탐지와 버프는 각 효과의 지속시간을 따르며, 재사용 시간은 통합된 각성 기준이야.

**광부의 각성에 직접 15랭크 이상 투자**하면 표시 우선순위를 바꿀 수 있어. 장비·도감·큐브로 더한 랭크만으로 이 조건을 채울 수는 없어.

- `/광부 모드변경 가치`: 가치가 높은 광석부터 표시.
- `/광부 모드변경 거리`: 가까운 광석부터 표시.

## 황금광로

자연 광석을 직접 채굴하면 기본 1% 확률로 광로가 나타날 수 있어. 발동 후 재사용 대기시간은 120초이며, 콤보마스터의 효과를 받으면 발동 확률이 높아질 수 있어.

1. 앞에 나타난 광로를 확인해.
2. 곡괭이로 광로를 타격해 공통 체력 100을 줄여. 왼쪽 버튼을 누르고 있어도 타격할 수 있어.
3. 끝까지 완료하면 광로가 회수되며 보상을 한 번 받아.

| 황금광로 유효 랭크 | 각 갈래의 길이 |
| --- | ---: |
| 1~9 | 9칸 |
| 10~19 | 12칸 |
| 20~34 | 16칸 |
| 35 | 20칸 |

- **1갈래는 정면**, **2갈래는 양쪽 대각선**, **3갈래는 정면과 양쪽 대각선**으로 열려. 각 갈래는 3×3 통로이며 대각선을 포함한 수평 8방향을 지원해.
- 갈래 확률은 1갈래 70%, 2갈래 25%, 3갈래 5%야. 만들어진 광로의 3%는 다이아 광로가 돼.
- 금광로는 유효 바닥 칸당 금 원석 1개, 다이아 광로는 다이아몬드 1개를 줘. 겹치는 입구는 한 번만 계산하며 지형과 보호 상태에 따라 실제 길이와 보상이 줄 수 있어.
- 표시된 금·다이아 광석은 본인에게 보이는 임시 광로야. 기존 광석을 금으로 바꾸는 기능이 아니야.
- 제한시간 초과, 거리 이탈, 사망·접속 종료·텔레포트·월드 이동으로 광로가 종료될 수 있으니 생성된 자리에서 마무리해.

## 과열 굴착

자연 암석을 직접 24개 캐면 과열이 충전돼. 콤보마스터와 현재 콤보에 따라 필요한 수가 줄어들 수 있어.

- 과열 굴착 1 / 10 / 20 / 35랭크에서 **3 / 4 / 5 / 6회** 충전돼.
- 충전 후 자연 암석을 직접 캐면 그 블록을 중심으로 **가로 3칸·세로 3칸, 추가 최대 8칸**의 자연 암석을 함께 캐.
- 추가 채굴이 일어났을 때 횟수 1회만 소모하고, 캘 대상이 없으면 소모하지 않아.
- 광석·유저 설치 블록·보호된 블록은 추가 채굴 대상이 아니야.
- 자동으로 캔 블록으로 과열을 다시 충전하지 않으며, 충전을 사용하는 동안에는 새 충전이 쌓이지 않아.

## 채광 콤보와 블랙홀

| 채광 대상 | 콤보 적립 |
| --- | --- |
| 자연 암석 | 10개마다 +1. 돌·심층암·화강암·섬록암·안산암·응회암을 섞어 캐도 합산 |
| 다이아몬드 광석 | +5 |
| 금 광석·네더 금 광석 | +3 |
| 철 광석 | +2 |
| 그 밖의 자연 광석 | +1 |
| 커스텀 광맥 | 실제 피해를 준 유효 타격마다 +1 |

심층암 광석도 같은 종류의 일반 광석과 같아. 행운 인챈트로 나온 아이템 수만큼 콤보가 늘어나는 것은 아니야. 광맥 파괴의 추가 광석과 광로 완료 보상도 콤보에 반영되지만, 블랙홀·과열의 자동 채굴로 다시 콤보를 쌓지는 않아.

**콤보마스터를 배웠다면 100콤보마다 블랙홀 1회가 충전**돼. 100콤보를 채운 순간 바로 발사되지는 않아.

- 다음 **자연 돌·광석을 직접 채굴 완료**하면 그 채굴 입력의 방향으로 발사돼.
- 커스텀 광맥 타격이나 자동 채굴만으로는 충전된 블랙홀을 발사하지 않아.
- 충전이 준비돼 있으면 해당 채굴의 무작위 황금광로보다 블랙홀을 먼저 사용해.
- 광로·블랙홀 진행 등으로 발사를 시작하지 못했다면 충전은 남아. 진행 중인 작업이 끝난 뒤 다시 직접 채굴해.
- 콤보 유지시간이 지나도 충전은 남지만, **접속 종료·사망·텔레포트·월드 이동 시에는 초기화**돼.

블랙홀은 3×3 범위로 전진하며 자연 돌·광석과 일부 자연 지형을 채굴해. 콤보마스터 1 / 10 / 20 / 35랭크의 거리는 **9 / 12 / 15 / 18칸**이야. 설치 블록·상자·가구·커스텀 작물·보호 구역은 보존되며, 연출 속 블록 파편을 따로 줍는 방식은 아니야.

## 야생 커스텀 광맥

야생 1~6에서 **기어 브론즈·코어 스틸·심연 프리즘** 광맥을 채굴할 수 있어.

- 다이아몬드 곡괭이 이상으로 여러 번 타격해.
- 광맥을 바라보면 필요한 도구와 현재 진행도를 확인할 수 있어.
- 채굴되지 않은 광맥은 생성 후 15분이 지나면 사라질 수 있어.
- 생활 도감이나 마을 효과로 나타난 개인 광맥은 처음 30초 동안 소유자만 채굴할 수 있어.

같은 지역의 공용 광맥을 계속 채굴하면 재생이 느려질 수 있어. 지역을 옮기거나 잠시 쉬면 회복되며, 자세한 기준은 [지역 활력](/life/systems#지역-활력)을 확인해 줘.

## 추천 투자 방향

- 연쇄 채굴과 추가 광물: **광맥 파괴**.
- 커스텀 광맥 타격: **암벽 분쇄 + 근로·감각**.
- 탐험과 빠른 채광: **광부의 각성**.
- 야생 굴착과 연속 채광: **황금광로·과열 굴착·콤보마스터**.
