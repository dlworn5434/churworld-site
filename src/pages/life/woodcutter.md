## 나무꾼 핵심 요약

나무꾼은 원목과 커스텀 나무를 벌목하며 숙련도를 올리고, **벌목 속도와 추가 목재 획득 능력**을 성장시키는 채집 생활입니다.

- 바닐라 원목·스템·하이피 벌목 기본 EXP: 1
- 커스텀 나무 벌목에는 다이아몬드 도끼 이상의 장비가 필요
- 주요 스탯: 근로 · 행운
- 스킬 메뉴: `/life skills woodcutting`

## 나무꾼 스킬

| 스킬 | 효과 | 현재 설정 |
| --- | --- | --- |
| 강인한 도끼 | 커스텀 나무 타격 피해 증가 | 랭크당 피해 +2 |
| 신속 벌목 | 나무를 다시 타격할 수 있는 간격 감소 | 랭크당 50ms 단축 |
| 목재 잔재 | 벌목 시 목재 추가 획득 확률 증가 | 랭크당 2%, 최대 50% |
| 숲의 분노 | 일정 시간 벌목 피해 증폭 | 1.5배부터 최대 3배, 마나 15 |
| 나무 감지 | 주변 커스텀 나무 위치 표시 | 반경 30블록, 마나 8 |

## 액티브 스킬 사용법

### 숲의 분노

도끼를 들고 **Shift + 우클릭**하면 발동합니다. 지속 시간은 12초부터 최대 41초, 재사용 대기시간은 120초부터 최대 62초까지 성장합니다.

### 나무 감지

도끼를 들고 **Shift + 좌클릭**하면 주변 30블록 안의 커스텀 나무를 잠시 표시합니다. 기본 지속 시간은 6초, 재사용 대기시간은 60초입니다.

## 공용 스탯 적용

| 스탯 | 나무꾼 효과 |
| --- | --- |
| 근로 | 벌목 시 도끼 내구도 소모 방지 확률 증가: 포인트당 0.5%, 최대 40% |
| 행운 | 목재 추가 획득 확률 증가: 포인트당 0.3%, 최대 15% |
| 지식 · 감각 · 흥정 · 명성 | 나무꾼 전용 설정에서는 현재 핵심 적용 없음 |

## 처음 시작할 때 추천 흐름

1. 다이아몬드 도끼 이상을 준비합니다.
2. 원목을 벌목해 나무꾼 숙련도와 공용 EXP를 함께 올립니다.
3. `/life skills woodcutting`에서 **강인한 도끼**와 **신속 벌목**을 먼저 확인합니다.
4. 커스텀 나무를 찾기 어렵다면 **나무 감지**, 수익을 높이고 싶다면 **목재 잔재**에 투자합니다.

## 추천 투자 방향

- 빠른 벌목: **강인한 도끼 + 신속 벌목**
- 목재 수량 늘리기: **목재 잔재 + 행운**
- 도끼 오래 쓰기: **근로**
- 탐색과 순간 화력: **나무 감지 + 숲의 분노**
