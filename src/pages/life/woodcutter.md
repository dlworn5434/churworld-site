## 나무꾼 핵심 요약

나무꾼은 야생의 **커스텀 나무**를 채집하거나, 내 마을에 **2×2 재배 나무**를 심어 원목을 수확하는 생활이야.

- 야생 커스텀 나무는 다이아몬드 도끼 이상으로 반복 타격해.
- 마을 재배 나무는 직접 심은 본인만 도끼로 층별 벌목하거나 범위 스킬로 수확할 수 있어.
- `/life skills woodcutting`에서 스킬에 투자하고 현재 적용 효과를 확인해.

## 나무꾼 스킬

| 스킬 | 사용하는 곳과 효과 |
| --- | --- |
| 강인한 도끼 | 야생 커스텀 나무의 타격 피해 증가와 타격 간격 감소 |
| 목재 잔재 | 커스텀 나무의 추가 목재·수액 획득, 마을 일반 재배 나무의 추가 원목 획득 |
| 숲의 분노 | 야생에서 피해 강화·나무 감지·신속 II를 함께 발동 |
| 되살아나는 숲 | 마을 재배 나무를 완전히 벤 뒤 같은 묘목 4개로 자동 재식재 |
| 금빛 수관 | 마을에 심은 나무가 황금나무로 자랄 기회 추가 |
| 연속 참격 | 마을에서 전방의 본인 재배 나무를 연속으로 수확 |
| 숲의 파동 | 마을에서 주변의 본인 재배 나무를 범위 수확 |

신속 벌목 효과는 **강인한 도끼**, 수액 채취 효과는 **목재 잔재**, 나무 감지 효과는 **숲의 분노**에 포함돼. 이 효과들을 별도 스킬로 배울 필요는 없어.

되살아나는 숲은 **1포인트로 해금**하는 스킬이야. 다른 스킬의 직접 투자·추가 랭크와 적용 한도는 [성장 구조](/life/growth#생활-스킬-랭크-구조)를 확인해 줘.

## 야생 커스텀 나무 찾기

야생 1~6에서 활동하면 주변에 **참나무 고목·가문비 고목·검은참나무 고목**이 나타날 수 있어.

- 다이아몬드 도끼 이상으로 여러 번 타격해 채집해.
- 나무를 바라보면 필요한 도구와 진행도를 확인할 수 있어.
- 채집되지 않은 나무는 생성 후 15분이 지나면 사라질 수 있어.
- 생활 도감이나 마을 효과로 나타난 개인 나무는 처음 30초 동안 소유자만 채집할 수 있고, 이후에는 다른 유저도 채집할 수 있어.

같은 지역의 공용 나무를 계속 채집하면 재생이 느려질 수 있어. **숲의 분노에 포함된 감지 기능**으로 주변 나무를 찾고, 활력이 부족한 지역은 잠시 쉬거나 다른 숲으로 이동해 줘. 자세한 기준은 [지역 활력](/life/systems#지역-활력)에서 확인할 수 있어.

## 마을 재배 나무 심고 베기

1. **자신이 소속된 마을의 땅**에 같은 종류의 묘목 4개를 2×2로 심어. 네 묘목 모두 본인이 심어야 해.
2. 위와 주변에 나무가 자랄 공간을 비워 두고 성장시켜. 자란 나무는 2×2 줄기, 12층으로 구성돼.
3. 도끼를 들고 아래쪽 원목을 바라보며 **Shift 없이 좌클릭을 유지**해. 맨 위층부터 원목 4개씩 수확해.
4. 클릭을 놓거나 다른 곳을 바라보면 멈춰. 같은 나무를 다시 캐면 남은 층부터 이어서 수확할 수 있어.

마을 재배 나무는 **심은 본인만** 전용 벌목과 스킬을 사용할 수 있어. 같은 마을원이어도 다른 사람이 심은 나무는 대상이 아니며, 마을의 설치·파괴 권한도 필요해. 원목을 직접 쌓아 만든 구조물이나 등록되지 않은 나무는 대상이 아니야.

직접 벌목 속도는 도끼의 **효율 인챈트와 근로 스탯**으로 빨라져. 도끼 내구도는 수확한 원목 수에 따라 소모되니 충분히 준비해 줘. 등록된 재배 나무는 도끼 우클릭으로 껍질을 벗길 수 없어.

## 액티브 스킬 사용법

도끼를 주 손에 들고 사용해. **야생과 마을에서 발동하는 스킬이 달라.**

| 장소 | 조작 | 발동 스킬 |
| --- | --- | --- |
| 야생 | Shift + 우클릭 | 숲의 분노 |
| 마을 | Shift + 좌클릭 | 연속 참격 |
| 마을 | Shift + 우클릭 | 숲의 파동 |

전용 클라이언트에서 보조키를 지정했다면 **Shift + 지정 키**로도 사용할 수 있어. 기존 분노 키는 야생에서 숲의 분노, 마을에서 숲의 파동을 사용하고, 기존 감지 키는 마을에서 연속 참격을 사용해. 보조키를 지정하면 해당 마우스 조합을 대체하므로 클릭으로 발동되지 않을 때는 조작 설정을 확인해 줘.

### 야생: 숲의 분노

일정 시간 커스텀 나무에 주는 피해를 높이고, 주변 나무 감지와 신속 II를 함께 받아. 감지 표시는 벽 너머에서도 본인 화면에만 보여.

- 기본 마나 소모는 15이며 지식 스탯으로 줄일 수 있어.
- 피해 강화와 감지의 지속 시간은 서로 다를 수 있어.
- 야생에서는 나무 감지를 따로 발동하지 않고 숲의 분노로 함께 사용해.

### 마을: 연속 참격·숲의 파동

**연속 참격**은 바라보는 방향의 나무를, **숲의 파동**은 주변 나무를 대상으로 해. 범위 안에 있는 **본인의 등록된 재배 나무**만 위층부터 차례대로 끝까지 수확해.

- 랭크가 오르면 범위와 대상 나무 수가 늘어나. 연속 참격은 최대 10그루, 숲의 파동은 최대 15그루까지 처리해.
- 기본 마나는 연속 참격 20, 숲의 파동 30이야. 지식은 마나 소모를, 감각은 두 스킬의 재사용 대기시간을 줄여 줘.
- 한 번 발동한 뒤에는 클릭을 계속 유지할 필요가 없어. 도끼를 바꾸거나 다른 마을로 이동하거나 시전한 자리에서 너무 멀리 벗어나면 중단돼.
- 중간에 보호나 나무 상태가 바뀐 대상은 제외돼. 아직 수확하지 않은 부분은 남아 있어.
- 되살아나는 숲을 배웠다면 스킬로 완전히 벤 나무도 재식재할 수 있어. 처리 중에는 다음 나무 수확이 잠시 기다릴 수 있어.

정확한 범위·대상 수·마나·재사용 대기시간은 스탯과 도감 효과를 반영한 스킬 화면에서 확인해 줘.

## 되살아나는 숲

스킬을 배운 뒤 마을 재배 나무를 마지막 층까지 수확하면, **인벤토리의 같은 종류 묘목 4개**를 소모해 원래 자리에 다시 심어.

- 묘목은 일반 인벤토리에 넣어 둬. `/가방`이나 보조 손에 둔 묘목은 사용하지 않아.
- 이름이나 설명이 붙은 아이템 대신 일반 묘목을 준비해.
- 묘목이 부족하거나 심을 공간·권한이 없으면 재식재되지 않아.
- 직접 벌목과 연속 참격·숲의 파동 모두 적용돼.

## 금빛 수관과 황금나무

금빛 수관을 배우면 마을 재배 나무가 **황금 원목과 황금 나뭇잎을 가진 나무**로 자랄 수 있어. **묘목을 심을 당시의 스킬 효과**를 기준으로 성장할 때 판정하므로, 새 묘목을 심기 전에 투자 상태를 확인해 줘.

황금나무도 본인이 직접 벌목하거나 마을 벌목 스킬로 수확할 수 있어. 황금 원목은 아이템으로 얻으며, 완전히 수확하면 [생활 황금 아이템인 황금 나무](/life/systems#생활-황금-아이템)를 한 번 더 추첨해. 추가 황금 아이템이 확정으로 지급되는 것은 아니야.

**황금 원목과 생활 황금 아이템 ‘황금 나무’는 서로 다른 아이템**이야. 직접 쌓은 황금 원목은 장식용이며 재배 나무의 스킬·보상을 다시 만들지 않아. 원목 판매와 수액 교환은 [경제 안내](/guide/basic/economy)에서 확인해 줘.

## 신비한 수액

야생 커스텀 나무를 완전히 벌목하면 **신비한 수액**을 얻을 수 있어. 목재 잔재를 올리면 추가 수액을 얻을 기회가 높아져. 수액은 [급수 물탱크](/life/farmer#급수-물탱크)의 성장 레벨을 올리는 데 사용해.

마을 재배 나무에서 목재 잔재로 얻는 추가 보상은 **일반 원목**이야. 황금 원목·나뭇잎·묘목에는 이 추가 원목 효과가 적용되지 않아.

## 공용 스탯 적용

| 스탯 | 야생 커스텀 나무 | 마을 재배 나무 |
| --- | --- | --- |
| 근로 | 타격 피해 증가 | 직접 벌목의 층별 수확 시간 단축 |
| 지식 | 도끼 내구도 보호·숙련 성장, 숲의 분노 마나 절약 | 도끼 내구도 보호·숙련 성장, 연속 참격·숲의 파동 마나 절약 |
| 감각 | 타격 간격 단축 | 연속 참격·숲의 파동 재사용 대기시간 단축 |
| 행운 | 추가 목재 획득 기회 증가 | 일반 원목의 추가 획득 기회 증가 |

근로로 줄어드는 마을 수확 시간은 **직접 도끼로 벨 때** 적용돼. 마을 범위 스킬의 대상 수와 범위는 해당 스킬 랭크를 올려 늘릴 수 있어.

## 추천 투자 방향

- 야생 채집: **강인한 도끼 + 숲의 분노**, 추가 목재와 수액은 **목재 잔재**
- 마을 반복 재배: **되살아나는 숲**을 배우고 인벤토리에 묘목 준비
- 여러 나무 수확: **연속 참격·숲의 파동**, 마나와 재사용 대기시간은 **지식·감각**
- 황금나무 재배: **금빛 수관**에 투자한 뒤 새 묘목 심기
