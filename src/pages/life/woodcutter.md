## 나무꾼 핵심 요약

나무꾼은 원목과 커스텀 나무를 벌목하며 숙련도를 올리고, **벌목 속도와 추가 목재 획득 능력**을 성장시키는 채집 생활입니다.

- 바닐라 원목·스템·하이피 벌목 기본 EXP: 1
- 커스텀 나무 벌목에는 다이아몬드 도끼 이상의 장비가 필요
- 주요 스탯: 근로 · 지식 · 감각 · 행운
- 스킬 메뉴: `/life skills woodcutting`

## 나무꾼 스킬

| 스킬 | 효과 | 1 / 10 / 20 / 25 / 30랭크 기준 |
| --- | --- | --- |
| 강인한 도끼 | 커스텀 나무 노드 타격 피해 증가 | +1 / +10 / +20 / +31 / +42 |
| 신속 벌목 | 나무 노드를 다시 타격할 수 있는 간격 감소 | 1.5 / 15 / 30 / 39 / 48% 감소 |
| 목재 잔재 | 벌목 완료 시 목재 추가 획득 확률 증가 | 1 / 10 / 20 / 29 / 38% |
| 숲의 분노 | 일정 시간 나무 노드 타격 피해 증폭 | 1.15배에서 최대 2.15배, 마나 15 |
| 나무 감지 | 주변 커스텀 나무 위치 표시 | 반경 12칸에서 최대 48칸, 마나 8 |

직접 스킬포인트로 투자할 수 있는 한도와 장비 보너스를 포함한 최종 적용 랭크는 다를 수 있습니다. 현재 적용값은 게임 안 스킬 화면에서 확인하세요.

## 액티브 스킬 사용법

### 숲의 분노

도끼를 들고 **Shift + 우클릭**하면 발동합니다. 랭크에 따라 피해가 1.15배에서 최대 2.15배로 증가하고, 지속 시간은 12초에서 최대 40초, 재사용 대기시간은 120초에서 최소 65초까지 성장합니다.

### 나무 감지

도끼를 들고 **Shift + 좌클릭**하면 주변 커스텀 나무를 잠시 표시합니다. 랭크에 따라 반경은 12칸에서 최대 48칸, 표시 대상은 6개에서 최대 36개, 지속 시간은 10초에서 최대 42초로 증가합니다. 재사용 대기시간은 120초에서 최소 42초까지 줄어듭니다.

## 커스텀 나무 찾기

커스텀 나무는 **야생 1~6**에서 활동 중인 플레이어 주변에 나타납니다. 한곳에서 기다리기보다는 야생을 이동하며 찾고, 가까운 노드를 놓쳤다면 **나무 감지**를 사용하세요.

- 현재 커스텀 나무 종류: 참나무 · 가문비나무 · 짙은 참나무
- 다이아몬드 도끼 이상의 도구로 반복 타격해야 합니다.
- 노드를 바라보면 필요한 도구, 진행도와 다시 타격할 수 있는 상태가 표시됩니다.
- 생성된 노드는 채집되지 않으면 15분 뒤 사라질 수 있습니다.
- 도감이나 마을 효과로 나타난 개인 노드는 처음 30초 동안 소유자만 채집할 수 있으며, 이후 다른 플레이어도 채집할 수 있습니다.

## 공용 스탯 적용

| 스탯 | 나무꾼 효과 |
| --- | --- |
| 근로 | 커스텀 나무 노드에 주는 타격 피해 증가 |
| 지식 | 도끼 내구도 소모 방지와 나무꾼 숙련 EXP 증가 |
| 감각 | 나무 노드를 다시 타격할 수 있는 간격 단축 |
| 행운 | 벌목 완료 시 추가 목재 획득 확률 증가 |
| 흥정 · 명성 | 현재 나무꾼 핵심 미적용 |

## 처음 시작할 때 추천 흐름

1. 다이아몬드 도끼 이상을 준비합니다.
2. 원목을 벌목해 나무꾼 숙련도와 공용 EXP를 함께 올립니다.
3. `/life skills woodcutting`에서 **강인한 도끼**와 **신속 벌목**을 먼저 확인합니다.
4. 커스텀 나무를 찾기 어렵다면 **나무 감지**, 수익을 높이고 싶다면 **목재 잔재**에 투자합니다.

## 추천 투자 방향

- 빠른 벌목: **강인한 도끼 + 신속 벌목**
- 목재 수량 늘리기: **목재 잔재 + 행운**
- 도끼 오래 쓰기와 숙련 성장: **지식**
- 기본 타격 성능: **근로 + 감각**
- 탐색과 순간 화력: **나무 감지 + 숲의 분노**
