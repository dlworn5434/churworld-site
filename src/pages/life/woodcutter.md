## 나무꾼 핵심 요약

나무꾼은 바닐라 원목과 야생의 커스텀 나무를 벌목하며 **노드 피해, 타격 속도, 추가 목재와 탐색 능력**을 키우는 직업이야.

- 바닐라 원목·스템·하이피 벌목 기본 EXP: 2
- 커스텀 나무는 다이아몬드 도끼 이상으로 반복 타격
- 커스텀 노드 EXP: 등급에 따라 30 / 74 / 198
- 스킬 메뉴: `/life skills woodcutting`

## 나무꾼 스킬

아래 수치는 장비·도감·큐브 보너스를 포함한 최종 유효 랭크 기준이야.

| 스킬 | 효과 | 1 / 10 / 20 / 25 / 30 / 35랭크 기준 |
| --- | --- | --- |
| 강인한 도끼 | 커스텀 나무 타격 피해 증가 | +1 / +10 / +20 / +31 / +42 / +53 |
| 신속 벌목 | 다시 타격할 수 있는 간격 감소 | 1.5 / 15 / 30 / 39 / 48 / 57% |
| 목재 잔재 | 노드 완료 시 목재 추가 획득 확률 | 1 / 10 / 20 / 29 / 38 / 47% |
| 숲의 분노 | 일정 시간 나무 타격 피해 증폭 | 1.15 / 1.35 / 1.6 / 1.88 / 2.15 / 2.42배 |
| 나무 감지 | 주변 커스텀 나무 표시 | 반경 12 / 20 / 30 / 39 / 48 / 57블록 |
| 수액 채취 | 노드 완료 시 신비한 수액 획득 | 0.2 / 2 / 4 / 6 / 8 / 10% |

직접 투자 상한과 최종 유효 상한은 [성장 구조](/life/growth#생활-스킬-랭크-구조)에서 확인할 수 있어.

## 액티브 스킬 사용법

### 숲의 분노

도끼를 들고 **Shift+우클릭**하거나 전용 클라이언트에서 지정한 생활 스킬 보조키로 사용해.

- 지속 시간: 1 / 10 / 20 / 25 / 30 / 35랭크에서 12 / 20 / 30 / 35 / 40 / 45초
- 재사용 대기시간: 120 / 105 / 85 / 75 / 65 / 55초
- 마나 소모: 15

### 나무 감지

도끼를 들고 **Shift+좌클릭**하거나 지정한 보조키로 사용해. 주변 커스텀 나무를 본인 화면에 표시하고 야생 생활을 보조해.

| 항목 | 1 / 10 / 20 / 25 / 30 / 35랭크 |
| --- | --- |
| 최대 표시 수 | 6 / 12 / 20 / 28 / 36 / 44개 |
| 지속 시간 | 10 / 15 / 20 / 31 / 42 / 53초 |
| 재사용 대기시간 | 120 / 100 / 75 / 59 / 42 / 25초 |
| 마나 소모 | 8 |

표시는 벽 너머에서도 확인할 수 있어. 현재 지역의 활력이 부족하면 채집 가능한 다른 지역을 찾는 데도 도움이 돼.

## 수액 채취

`수액 채취`는 나무 감지 10과 강인한 도끼 10에 **직접 투자**해야 배울 수 있는 상위 패시브 스킬이야.

- 커스텀 나무 노드를 완전히 벌목했을 때 확률 판정
- 성공하면 `신비한 수액` 1개 획득
- 장비·도감·큐브로 더해진 랭크는 선행 조건을 대신하지 않아
- 신비한 수액은 현재 별도 사용처가 안내되지 않은 생활 재료이므로 보관해 두는 것을 권장해

## 커스텀 나무 찾기

커스텀 나무는 야생 1~6에서 활동 중인 플레이어 주변에 나타나.

- 참나무 고목
- 가문비 고목
- 검은참나무 고목

다이아몬드 도끼 이상으로 반복 타격하고, 노드를 바라보면 필요한 도구와 진행도를 확인할 수 있어. 채집되지 않은 노드는 생성 후 15분이 지나면 사라질 수 있어.

생활 도감이나 마을 효과로 나타난 개인 노드는 처음 30초 동안 소유자만 채집할 수 있고 이후에는 다른 유저도 채집할 수 있어.

## 지역 활력

같은 지역의 공용 나무 노드를 계속 완료하면 그 지역의 재생 대기시간이 늘어나. 광산 활력과 숲 활력은 서로 따로 계산돼.

- 재생이 느려졌다면 다른 지역으로 이동하거나 잠시 쉬기
- 개인 도감·효과 타워 보너스 노드는 지역 활력 소모에서 제외
- 나무 감지를 사용하면 활력이 남은 주변 지역을 찾는 데 도움을 받을 수 있음

단계별 기준과 회복 시간은 [지역 활력 시스템](/life/systems#지역-활력)에서 확인해 줘.

## 공용 스탯 적용

| 스탯 | 나무꾼 효과 |
| --- | --- |
| 근로 | 커스텀 나무 노드 타격 피해 증가 |
| 지식 | 도끼 내구도 소모 방지와 나무꾼 숙련 EXP 증가 |
| 감각 | 다시 타격할 수 있는 간격 단축 |
| 행운 | 추가 목재 획득 확률 증가 |

## 추천 투자 방향

- 빠른 벌목: **강인한 도끼 + 신속 벌목**
- 추가 목재: **목재 잔재 + 행운**
- 탐색과 순간 화력: **나무 감지 + 숲의 분노**
- 신비한 수액 수집: 선행 스킬을 직접 투자한 뒤 **수액 채취**
