| `/장비강화` | 장비 관리 화면에서 착용 중이거나 인벤토리에 있는 방어구 별 강화 |
| `/큐브 검사` | 주 손 방어구의 저장 잠재등급·강화 기준 적용등급·실제 옵션 확인 |
| `/큐브 수령` | 완료·선택 대기 중인 큐브 결과 수령 |

현재 마나는 접속을 종료하거나 서버가 재시작돼도 저장됩니다. 재접속만으로 최대치까지 채워지지 않으며, 저장된 수치부터 자연 회복을 이어 갑니다.

후라이팬에서 만든 요리를 먹어 마나를 회복할 수도 있습니다. 기본 요리는 노멀·실버·골드 순서로 **3·5·10**, 물고기가 들어간 요리는 **5·7·15**를 회복하며 배가 불러도 먹을 수 있습니다. 자세한 조건은 [요리사 안내](/life/chef#음식을-먹고-마나-회복하기)를 확인하세요.

## 고급 생활 스킬

고급 스킬은 직업 숙련도 70만 달성한다고 자동으로 열리지 않습니다. 아래 선행 스킬에 투자한 **직접 랭크**를 만족해야 하며, 장비·도감·큐브 보너스는 선행 조건에 포함되지 않습니다.

| 직업 | 고급 스킬 | 직접 투자 선행 조건 | 핵심 효과 |
| --- | --- | --- | --- |
| 광부 | 각성 초월 | 광맥 파괴 10, 광부의 각성 10, 광물 잔재 5 | 각성 중 첫 유효 좌클릭에 3×3 굴착 1회 |
| 어부 | 물고기 떼의 부름 | 쌍걸 10, 숙련된 낚시 10 | 제한 시간 안의 다음 3회 투척을 빠른 입질로 변경 |
| 대장술 | 초월 단조 | 폭발 제련 10 | 현재 시설의 미완료 작업 전체 남은 시간 절반 단축 |

정확한 조작과 랭크별 효과는 각 직업 문서에서 확인하세요.

나무꾼은 기존 수액 채취·감지·신속 효과가 다른 스킬에 통합됐습니다. 현재 일곱 스킬에는 별도의 선행 스킬 조건이 없으며, **되살아나는 숲은 1포인트로 해금**합니다. [나무꾼 스킬과 적용 범위](/life/woodcutter)를 확인하세요.

## 경험치 효과와 요일 보너스

`/경험치`를 입력하면 현재 적용 중인 개인·서버 전체 경험치 효과를 확인할 수 있습니다. 생활 숙련도 쿠폰과 공용 성장 쿠폰은 서로 다른 종류이며 아이템을 우클릭해 사용합니다.

- 같은 종류의 증가 효과는 기본 배율을 넘는 증가분끼리 합산
- 개인 효과와 서버 전체 효과가 함께 있으면 둘을 곱하지 않고 더 높은 효과 적용
- 요일 보너스는 위에서 계산된 효과에 별도로 곱해짐

| 요일 | 생활 숙련도 | 공용 성장 |
| --- | --- | --- |
| 월요일 | 농부 ×1.5 | ×1.2 |
| 화요일 | 광부 ×1.5 | ×1.2 |
| 수요일 | 요리사 ×1.5 | ×1.2 |
| 목요일 | 나무꾼 ×1.5 | ×1.2 |
| 금요일 | 어부 ×1.5 | ×1.2 |
| 토요일 | 대장술 ×1.5 | ×1.2 |
| 일요일 | 모든 생활·생산 ×1.3 | ×1.3 |

남은 시간과 실제 적용 배율은 `/경험치` 화면을 기준으로 확인해 주세요.

## 생활 조각과 강화석

채광·낚시·농사·요리·벌목·사육에서 새 생활 조각 대신 **강화석을 직접** 얻을 수 있습니다. 강화석은 확률 보상이며, 해당 활동의 황금 기본 추첨에 적용되는 최종 확률의 **1/5**로 별도 판정합니다.

- 강화석은 본인에게 각인되고 기본 스탯까지 분배된 드라코라이트 방어구의 별 강화에 사용합니다.
- 이미 보유한 생활 조각은 사라지지 않으며 기존 제작·교환에 그대로 사용할 수 있습니다. 다섯 직업의 조각을 하나씩 합치는 [기존 강화석 제작법](/life/recipes#생활-조각으로-강화석-만들기)도 유지됩니다.
- 사육사의 추가 생산품이나 보조 타격마다 강화석을 다시 추첨하지는 않습니다.
- 어부 작업대에 쓰는 **낚시 조각**은 별도 재료이며, 파츠 제작·수명 연장에 계속 사용합니다.

## 생활 황금 아이템

생활 활동을 하다 보면 일반 결과물과 별도로 황금 재료를 얻을 수 있습니다.

| 활동 | 획득 아이템 |
| --- | --- |
| 자연 생성 광석 채굴·커스텀 광맥 완료 | 황금 광물 |
| 낚시 성공 | 황금 물고기 |
| 커스텀 작물 수확 | 황금 작물 |
| 요리 성공 | 황금 요리 |
| 자연 생성 원목 벌목·커스텀 나무 완료 | 황금 나무 |
| 사육 생산품 수확 | 황금 축산물 |

**금별 물고기나 골드 품질 요리와는 다른 별도 아이템**입니다. 생활 조각과도 구분됩니다.

## 지역 활력

공용 광맥과 공용 나무 노드는 가까운 지역에서 연속으로 많이 채집할수록 잠시 재생이 느려지는 **지역 활력**을 사용합니다. 광맥과 나무의 활력은 서로 따로 계산됩니다.

| 같은 지역의 연속 채집 완료 | 다음 공용 노드 재생 시간 |
| ---: | ---: |
| 0~4회 | 기본 시간 |
| 5~6회 | 기본 시간의 2배 |
| 7회 이상 | 기본 시간의 5배 |

- 약 10분 동안 그 지역에서 같은 종류의 노드를 더 채집하지 않으면 활력이 한 단계씩 회복됩니다.
- 많이 소진된 지역도 약 30분 동안 쉬면 기본 재생 상태로 돌아옵니다.
- 광석 감지와 숲의 분노에 포함된 나무 감지 효과는 주변의 채집 가능한 노드를 찾는 데 도움을 줍니다.
- 도감이나 건축물 효과로 개인에게 나타나는 전용 노드는 지역 활력을 소모하지 않습니다.

한곳의 노드만 계속 기다리기보다 감지 스킬을 이용해 주변 지역을 번갈아 이용하면 더 안정적으로 채집할 수 있습니다.

## 추천 사용 흐름

1. 길라잡이로 초반 목표 확인
2. 제작법을 확인해 자주 하는 직업의 작업대부터 확보
3. 직업 상세 문서를 보며 스탯과 스킬 방향 정하기
4. 모은 아이템을 생활 도감에 등록해 직업별 영구 보상 받기
5. 의뢰와 반복 루프로 숙련도와 공용 레벨 함께 올리기
6. 상위 재료가 모이면 드라코라이트 방어구를 각인한 뒤 큐브 잠재능력을 부여하고, 기본 스탯 분배 후 별 강화 진행
7. 투자 방향을 바꿀 때는 초기화 책으로 투자 상태를 초기화한 뒤 다시 분배하기
8. 마을을 만들었다면 도면과 도구함을 준비해 장식·생산·효과 건축물 확장하기

생활 도감에 등록한 아이템은 되돌릴 수 없으므로 [생활 도감 안내](/life/codex)의 등록 조건을 먼저 확인하세요. 별 강화는 실패해도 방어구가 파괴되지 않지만 재료와 비용은 사용되며, 높은 단계에서는 하락할 수 있습니다. 강화 단계에 따라 큐브 옵션의 현재 적용등급도 달라지므로 [장비·큐브 안내](/life/equipment)를 먼저 확인하세요.
