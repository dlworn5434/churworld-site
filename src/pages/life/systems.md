## 자주 쓰는 확인 명령어

| 명령어 | 기능 |
| --- | --- |
| `/life` | 생활·생산 메인 메뉴 |
| `/life 도감` | 생활 도감 열기 |
| `/life recipes` | 요리 레시피북 열기 |
| `/life mana` | 현재 마나 확인 |
| `/경험치` | 적용 중인 개인·전체 경험치 증가 확인 |
| `/제작 로그 대기열` | 진행 중인 제작 확인 |
| `/제작 로그` | 최근 제작 결과 확인 |
| `/큐브 검사` | 주 손 방어구의 큐브 옵션 확인 |
| `/큐브 수령` | 완료·선택 대기 중인 큐브 결과 수령 |
| `/장비강화` | 주 손의 드라코라이트 방어구 강화 |

## 추천 사용 흐름

1. 길라잡이로 초반 목표 확인
2. 제작법을 확인해 자주 하는 직업의 작업대부터 확보
3. 직업 상세 문서를 보며 스탯과 스킬 방향 정하기
4. 여유 재료를 도감에 등록해 영구 생활 보상 쌓기
5. 상위 재료가 모이면 드라코라이트 방어구·큐브·별 강화 진행
6. 의뢰와 반복 루프로 숙련도와 공용 레벨 함께 올리기
