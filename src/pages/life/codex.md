## 생활 도감이란?

생활 도감은 채광·농사·낚시·요리·벌목·생존·탐험 아이템과 방어구를 등록해 단계별 목표를 달성하는 콘텐츠입니다. 등록 단계가 올라가면 게임 머니, 직업별 영구 효과, 생활 스킬 추가 랭크와 생존 보상을 받을 수 있습니다.

- 명령어: `/생활 도감` 또는 `/life 도감`
- 생활·생산 메인 메뉴에서도 **생활 도감**을 선택할 수 있습니다.
- 도감 보상은 공용 스탯 포인트가 아니라 해당 직업의 스킬·고유 효과 또는 생존 능력에 적용됩니다.
- 단계 보상은 목표를 달성하면 자동으로 적용됩니다.

## 도감 구성

현재 생활 도감은 **8개 분류, 23개 하위 분류, 총 150개 항목**으로 구성됩니다.

| 분류 | 하위 분류 | 항목 수 |
| --- | --- | ---: |
| 광부 | 곡괭이류, 일반 광물, 고급 광물·블록, 커스텀 광물 | 27 |
| 농부 | 괭이류, 농작물 | 19 |
| 어부 | 골드 물고기 | 14 |
| 요리사 | 골드 요리 | 6 |
| 나무꾼 | 도끼류, 일반 원목, 커스텀 나무 재료 | 20 |
| 생존 | 검, 몬스터 드롭 | 20 |
| 기타 | 고대 도시, 시련의 회당, 고고학, 희귀, 전설 | 24 |
| 방어구 | 가죽, 철, 금, 다이아몬드, 네더라이트 | 20 |

각 항목을 선택하면 현재 등록량, 다음 목표, 받을 보상을 게임 안 도감 화면에서 확인할 수 있습니다. 도감에는 대장술 분류가 없습니다.

### 기타 도감

기타 도감은 탐험과 희귀 수집품을 다루는 분류입니다.

| 하위 분류 | 대표 등록 아이템 |
| --- | --- |
| 고대 도시 | 메아리 조각, 음반 조각 5, 파수·고요 갑옷 장식 |
| 시련의 회당 | 흐름·나사 갑옷 장식, 창조자·절벽 음반, 흐름 현수막 무늬 |
| 고고학 | 유물 음반, 스니퍼 알, 흐름·돌풍·긁개 도자기 조각 |
| 희귀 | 피글린 음반, 크리퍼·피글린·좀비 머리, 스켈레톤 해골 |
| 전설 | 드래곤 머리, 겉날개, 셜커 껍데기, 바다의 심장, 네더의 별 |

기타 도감을 모두 완료하면 누적 **43,600원, 공용 액티브 스킬 쿨타임 5% 감소, 공용 액티브 스킬 지속 시간 5% 증가, 최대 마나 +15**를 얻습니다.

### 방어구 도감

방어구 도감은 가죽·철·금·다이아몬드·네더라이트 방어구의 투구·흉갑·각반·장화를 등록하는 총 20개 항목입니다.

모두 완료하면 누적 **17,000원, 최대 체력 +42, 이동 속도 +13%, 직접 공격·휩쓸기·발사체 피해 8.5% 감소**를 얻습니다. 낙하·용암·익사 같은 환경 피해까지 줄여 주는 효과는 아닙니다.

### 농사 도감 보상

농사 도감의 단계 보상은 농부 플레이에 다음 효과를 더합니다.

- 농부 숙련 EXP 증가
- 수확 시 추가 작물 획득 확률 증가
- 3성 작물 가중치 증가
- 풍요 수확·장인의 손맛·곡선 수확·자동 파종 스킬 추가 랭크

항목마다 적용되는 수치와 스킬이 다르므로 등록 전에 해당 단계의 보상 아이콘을 확인하세요.

### 생존 도감

- 단계 보상으로 **허기 소모 감소, 마나 자연 회복 증가, 최대 마나 증가** 같은 영구 생존 효과를 얻을 수 있습니다.

#### 생존 도감 보상

대부분의 항목은 단계에 따라 아래 보상을 순서대로 받습니다. 항목의 단계 수까지만 적용됩니다.

| 단계 | 기본 보상 |
| ---: | --- |
| 1단계 | 300원 + 허기 소모 감소 0.2% |
| 2단계 | 500원 + 마나 자연 회복 증가 0.2% + 허기 소모 감소 0.5% |
| 3단계 | 1,000원 + 마나 자연 회복 증가 0.3% |
| 4단계 | 1,500원 + 마나 자연 회복 증가 0.3% |

일부 희귀 항목은 보상이 다릅니다.

- 슬라임볼 4단계: 마나 자연 회복 증가 1.5%
- 프리즈머린 수정·가스트 눈물 3단계: 마나 자연 회복 증가 0.3% + 허기 소모 감소 3%
- 스컬크 촉매 1~4단계: 1,000 / 2,000 / 3,000 / 5,000원 + 최대 마나 5 / 10 / 15 / 20 증가

생존 도감을 모두 완료하면 누적 **43,700원, 허기 소모 감소 19.3%, 마나 자연 회복 증가 9.8%, 최대 마나 +50**을 얻습니다.

## 등록 방법

1. `/생활 도감`을 입력하고 원하는 분류를 선택합니다.
2. 등록할 항목과 같은 아이템을 인벤토리에 준비합니다.
3. 항목을 **좌클릭**하면 한 번에 최대 64개를 등록합니다.
4. 항목을 **Shift + 좌클릭**하면 마지막 목표까지 필요한 수량을 한꺼번에 등록하도록 요청합니다.
5. 일괄 등록은 안내를 확인한 뒤 **10초 안에 같은 항목을 다시 Shift + 좌클릭**해야 확정됩니다.

> **등록 주의:** 등록한 아이템은 실제로 소모되며 되돌릴 수 없습니다. 거래하거나 사용할 아이템까지 등록하지 않도록 수량을 확인하세요.

등록 수량은 일반 인벤토리에 있는 아이템을 기준으로 확인합니다. 방어구 칸·보조손·마우스 커서에 들고 있는 아이템은 등록 대상에 포함되지 않습니다.

## 도구·무기·방어구 등록 조건

곡괭이·괭이·도끼·검·방어구는 사용 흔적이 없는 **새 바닐라 아이템**만 등록됩니다. 다음과 같은 아이템은 등록할 수 없습니다.

- 내구도가 감소한 도구
- 인챈트나 수선이 적용된 도구
- 이름을 바꾸거나 설명 문구가 붙은 도구
- 커스텀 모델 등 다른 사용 정보가 남은 도구

등록이 되지 않는다면 새로 제작한 순정 도구·무기·방어구인지 먼저 확인하세요.

## 스킬과 개인 노드 보상

도감에서 받은 추가 스킬 랭크는 해당 스킬을 직접 **1랭크 이상 배운 뒤** 적용됩니다. 아직 배우지 않은 스킬의 도감 보상은 사라지는 것이 아니라, 첫 랭크를 배운 뒤 적용됩니다.

직접 투자와 장비·도감·큐브 보너스를 합친 최종 적용 랭크는 35랭크까지입니다. 현재 새 고급 스킬인 각성 초월·물고기 떼의 부름·수액 채취·초월 단조는 큐브에는 등장하지만 도감의 추가 스킬 랭크 보상에는 포함되지 않습니다.

일부 최종 보상은 야생 월드에서 개인용 커스텀 광맥이나 나무를 만날 기회를 높여 줍니다.

- 개인 노드는 생성 후 **30초 동안 생성 대상 플레이어에게 보호**됩니다.
- 보호 시간이 지나면 다른 플레이어도 채집할 수 있습니다.
- 생성 후 **15분** 동안 채집하지 않은 노드는 사라질 수 있습니다.

정확한 등록 목표와 다음 단계 보상은 게임 안 도감 화면에서 확인하세요.

## 도감 보상과 장비 성장

도감의 스킬 랭크와 영구 효과는 드라코라이트 방어구의 기본 스탯·별 강화·큐브 잠재능력과 함께 적용됩니다. 각 성장 요소의 적용 한도와 사용법은 [성장 구조](/life/growth)와 [장비·강화·큐브](/life/equipment) 문서에서 확인하세요.
