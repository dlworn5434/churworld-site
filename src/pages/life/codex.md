## 생활 도감이란?

생활 도감은 생활 아이템을 단계별로 등록하고 **돈, 생활 스킬 보너스와 직업별 영구 효과**를 얻는 수집 콘텐츠입니다.

- 열기: `/life 도감` 또는 `/life codex`
- 등록한 아이템은 실제로 소모되며 되돌릴 수 없음
- 각 항목의 필요한 수량과 다음 보상은 도감 화면에서 확인
- 공용 스탯을 직접 지급하지 않고, 해당 생활의 스킬·고유 효과를 강화

## 등록 방법

1. `/life 도감`을 열고 생활 카테고리와 세부 분류를 선택합니다.
2. 등록하려는 항목과 같은 아이템을 인벤토리에 준비합니다.
3. 항목 버튼을 좌클릭하거나 Shift + 좌클릭합니다.
4. 등록 수량, 완료 단계와 적용된 영구 보상을 확인합니다.

| 조작 | 동작 |
| --- | --- |
| 좌클릭 | 인벤토리에서 최대 64개 등록 |
| Shift + 좌클릭 | 최종 목표까지 필요한 수량을 한꺼번에 등록 |
| 대량 등록 재클릭 | 10초 안에 같은 항목을 다시 눌러 최종 확정 |

갑옷 칸, 보조 손과 마우스 커서에 든 아이템은 등록 수량에서 제외됩니다.

## 도구 등록 주의사항

곡괭이·괭이·도끼는 **사용하지 않은 새 순정 도구만** 등록됩니다.

- 내구도가 닳은 도구 등록 불가
- 인챈트나 수선이 붙은 도구 등록 불가
- 이름·설명·커스텀 모델 등 사용 흔적이 있는 도구 등록 불가
- 도감용 도구는 제작한 직후 따로 보관하는 것이 안전

생활에서 실제로 사용하던 장비가 등록되지 않는 것은 정상입니다.

| 생활 | 세부 분류 | 대표 등록 대상 |
| --- | --- | --- |
| 채광 | 곡괭이류 | 나무부터 네더라이트까지 각 곡괭이 |
| 채광 | 일반 광물 | 석탄, 구리·철·금 주괴, 청금석, 레드스톤, 자수정, 다이아몬드, 에메랄드, 네더라이트 주괴 |
| 채광 | 고급 광물·블록 | 흑요석, 우는 흑요석, 광물 블록, 고대 잔해 |
| 채광 | 커스텀 광물 | 기어 브론즈 주괴, 코어 스틸 주괴, 어비스 프리즘 |
| 농사 | 괭이류 | 나무부터 네더라이트까지 각 괭이 |
| 농사 | 농작물 | 독이 있는 감자와 각종 3성 커스텀 작물 |
| 낚시 | 골드 물고기 | 골드 등급 참치, 파이크, 퍼치, 숭어, 정어리, 잉어, 메기, 문어, 개복치 등 |
| 요리 | 골드 요리 | 골드 딸기 바나나 믹스, 포도 레몬 젤리, 과일볼, 수프, 샐러드, 절임 |
| 벌목 | 도끼류 | 나무부터 네더라이트까지 각 도끼 |
| 벌목 | 일반 원목 | 오버월드 원목과 네더 줄기류 |

농작물 도감은 토마토·바나나·옥수수·무·오렌지·파인애플·양배추·포도·레몬·상추·석류·딸기의 **3성 결과물**을 사용합니다.

## 영구 보상은 어떻게 적용되나요?

도감 단계 보상은 해당 생활에 맞는 효과로 누적됩니다.

| 생활 | 적용될 수 있는 보상 예시 |
| --- | --- |
| 채광 | 광맥 피해량, 타격 간격, 바닐라 광물 추가 드롭, 커스텀 광물 추가 보상 |
| 농사 | 괭이 내구도 보호, 작물 추가 드롭, 3성 작물 가중치 |
| 낚시 | 입질 대기·접근 시간, 쌍걸, 보물, 조각, 커스텀 어종 확률 |
| 요리 | 조리 시간, 성공률, 추가 결과, 등급 승급과 골드 가중치 |
| 벌목 | 커스텀 나무 피해량·타격 간격, 추가 목재, 도끼 내구도 보호 |

생활 스킬 랭크 보상은 해당 스킬을 **최소 1랭크 직접 배운 뒤** 적용됩니다. 아직 배우지 않은 0랭크 스킬을 도감 보상만으로 새로 활성화할 수는 없습니다.

## 추천 등록 순서

1. 자주 얻고 다시 구하기 쉬운 기본 광물·원목부터 등록
2. 새 도구를 만들 때 도감 등록용을 한 개씩 따로 준비
3. 3성 작물·골드 물고기·골드 요리는 필요한 수량을 먼저 확인하고 여유분만 등록
4. Shift + 좌클릭 대량 등록 전 남길 아이템을 다른 보관함으로 옮기기

희귀 재료는 등록하면 복구할 수 없으므로, 제작이나 거래에 사용할 수량을 먼저 빼두는 것이 좋습니다.
