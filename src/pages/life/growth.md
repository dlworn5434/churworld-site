## 한눈에 보는 생활 구조

츄르월드의 생활 콘텐츠는 **공용 성장**과 **직업별 숙련도**를 함께 올리는 구조야.

- 공용 레벨은 모든 생활에 함께 적용되는 성장축
- 생활 숙련도는 광부 / 어부 / 농부 / 요리사 / 나무꾼 / 대장술이 각각 따로 가지는 성장축
- 자주 쓰는 공용 스탯은 **근로 / 지식 / 감각 / 행운**
- 흥정과 명성은 현재 기준으로 적용 범위가 제한적이거나 준비 중으로 보는 편이 안전해

## 공용 레벨

| 항목 | 현재 기준 |
| --- | --- |
| 최대 레벨 | 200 |
| 획득 방식 | 채광, 낚시, 농사, 요리 등 생활 활동 전반 |
| 레벨업 공식 | `500 × (현재 레벨 ^ 1.35)` 기반 |
| 스탯 포인트 | 공용 레벨 1당 1포인트 |

공용 레벨은 모든 생활을 묶는 중심 성장축이야.  
자주 하는 직업이 하나여도, 공용 레벨 투자로 다른 생활에도 동시에 효율을 줄 수 있어.

## 생활 숙련도 레벨

| 항목 | 현재 기준 |
| --- | --- |
| 대상 직업 | 광부 · 어부 · 농부 · 요리사 · 나무꾼 · 대장술 |
| 최대 레벨 | 60 |
| 역할 | 직업별 스킬포인트와 숙련도 성장 |
| 경험치 공식 | `60 + 25L + 12L²` (L = 현재 레벨) |

생활 숙련도는 직업별로 따로 올라.  
즉 광부 레벨과 어부 레벨은 서로 분리되어 있고, 해당 직업의 스킬 투자와 체감에 연결돼.

## 공용 스탯 종류

| 스탯 | 쉽게 말하면 | 대표 사용처 |
| --- | --- | --- |
| 근로 | 기본 작업 효율 | 광부 데미지, 어부 입질 속도, 농부·나무꾼 장비 내구도 보호, 요리·대장술 시간 감소 |
| 지식 | 결과를 더 좋게 만드는 보정 | 어부 커스텀 어획 확률, 요리·대장술 성공률 |
| 감각 | 추가 획득 / 반응속도 보정 | 광부 타격 간격, 농부 추가 드롭, 요리 추가 산출 |
| 행운 | 품질 / 추가 드롭 / 등급 운 | 광부·나무꾼 추가 드롭, 농사 2·3성, 어획·요리 등급, 대장술 추가 제작 |
| 흥정 | 경제 보정용 예약 스탯 | 적용 범위 제한적 |
| 명성 | 사회 / 경제 보정용 예약 스탯 | 적용 범위 제한적 |

## 직업별 스탯 적용 요약

| 직업 | 근로 | 지식 | 감각 | 행운 | 흥정 / 명성 |
| --- | --- | --- | --- | --- | --- |
| 광부 | 커스텀 광물 데미지 증가 | 현재 핵심 적용 아님 | 커스텀 광물 타격 간격 감소 | 추가 드롭 확률 | 현재 미적용 |
| 어부 | 입질 대기시간 감소 | 커스텀 어획 확률 증가 | 현재 핵심 적용 아님 | 실버 / 골드 등급 가중치 증가 | 현재 미적용 |
| 농부 | 괭이 내구도 소모 방지 | 현재 미적용 | 추가 드롭 확률 | 2성 / 3성 작물 가중치 증가 | 현재 미적용 |
| 요리사 | 조리 시간 감소 | 성공률 증가 | 추가 산출 확률 | 실버 / 골드 요리 가중치 증가 | 현재 미적용 |
| 나무꾼 | 도끼 내구도 소모 방지 | 현재 핵심 적용 아님 | 현재 핵심 적용 아님 | 추가 목재 획득 확률 | 현재 미적용 |
| 대장술 | 제작 시간 감소 · 재료 절약 | 제작 성공률 증가 | 현재 핵심 적용 아님 | 추가 결과물 확률 | 현재 미적용 |

## 처음 시작할 때 추천 루트

1. `/life` 로 메인 메뉴를 열어서 전체 생활 구조를 먼저 확인하기
2. `/guide` 또는 `/길라잡이` 로 초반 목표를 따라가며 핵심 장비와 작업대 익히기
3. 공용 레벨을 올리며 근로 · 지식 · 감각 · 행운을 자주 하는 생활에 맞춰 투자하기
4. 생활 문서에서 내가 주로 할 직업의 스킬과 루프를 먼저 익히기

## 길라잡이 대표 목표 예시

- 기본: 나무 벌목, 제작대 만들기, `/가방` 열기, 구리 / 철 / 금 채굴, 돌 굽기, `/거래소` 사용, 스탯 · 스킬 투자, 채팅 인사
- 어부: 바닐라 낚싯대 제작, 어부 작업대 제작, 물고기 낚기 16 / 32 / 64회
- 농부: 씨앗 심기, 커스텀 농작물 수확, 물뿌리개 / 비닐하우스 / 허수아비 / 화분 제작
- 광부: 대장간 화로 제작, 어비스프리즘 / 코어스틸 / 기어브론즈 광맥 채굴
- 요리사: 요리사 조리대 제작, 노멀 / 실버 / 골드 요리 완성
