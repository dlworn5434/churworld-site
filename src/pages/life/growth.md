## 한눈에 보는 생활·생산 구조

츄르월드의 생활·생산 콘텐츠는 **공용 성장**과 **직업별 숙련도**를 함께 올리는 구조야.

- 공용 레벨은 모든 생활과 생산에 함께 적용되는 성장축
- 생활 직업은 광부 / 어부 / 농부 / 나무꾼 / 사육사
- 생산 직업은 요리사 / 대장술
- 직업별 숙련도와 스킬은 일곱 직업이 각각 따로 가지는 성장축
- 현재 직접 투자할 수 있는 공용 스탯은 **근로 / 지식 / 감각 / 행운** 네 종류
- 스탯 투자 화면의 직업 탭에서 같은 스탯이 각 직업에 주는 실제 효과를 미리 확인할 수 있어

## 공용 레벨

| 항목 | 현재 기준 |
| --- | --- |
| 최대 레벨 | 200 |
| 획득 방식 | 채광, 낚시, 농사, 벌목, 사육, 요리, 제련 등 생활·생산 활동 전반 |
| 스탯 포인트 | 공용 레벨 1당 1포인트 |

공용 레벨은 모든 생활과 생산을 묶는 중심 성장축이야.  
자주 하는 직업이 하나여도, 공용 레벨 투자로 다른 직업에도 동시에 효율을 줄 수 있어.

## 직업별 숙련도 레벨

| 항목 | 현재 기준 |
| --- | --- |
| 생활 직업 | 광부 · 어부 · 농부 · 나무꾼 · 사육사 |
| 생산 직업 | 요리사 · 대장술 |
| 최대 레벨 | 70 |
| 역할 | 직업별 스킬포인트와 숙련도 성장 |

직업별 숙련도는 서로 따로 올라.  
즉 광부 레벨과 어부 레벨은 서로 분리되어 있고, 해당 직업의 스킬 투자와 체감에 연결돼.

## 생활 스킬 랭크 구조

생활 스킬은 내가 스킬포인트로 올린 **직접 투자 랭크**와 장비·도감·큐브에서 받는 **추가 랭크**를 구분해.

| 구분 | 현재 한도 | 설명 |
| --- | ---: | --- |
| 기본 직접 투자 | 20랭크 | 스킬포인트로 올릴 수 있는 기본 한도 |
| 확장 후 직접 투자 | 25랭크 | 확장 가능한 스킬에 스킬 확장권을 사용했을 때의 한도 |
| 최종 적용 랭크 | 35랭크 | 직접 투자와 장비·도감·큐브 보너스를 모두 합친 적용 한도 |

- 스킬 확장은 모든 보너스를 25랭크로 제한하는 기능이 아니라, **직접 투자 한도만 20에서 25로 넓히는 기능**이야.
- 확장한 스킬의 기록은 초기화 책을 사용해도 유지돼. 초기화 후 다시 투자할 때도 직접 25랭크까지 올릴 수 있어.
- 장비·도감·큐브 보너스로 스킬이 처음부터 열리지는 않아. 먼저 해당 스킬을 직접 1랭크 이상 배워야 추가 랭크가 적용돼.
- 선행 스킬이 필요한 고급 스킬은 장비·도감·큐브 보너스를 제외한 **직접 투자 랭크**로 조건을 확인해.
- 고정 1랭크 스킬처럼 별도 한도를 가진 스킬은 위의 확장 대상에서 제외돼.

직업별 선행 조건과 랭크별 효과는 [광부](/life/miner), [어부](/life/fisher), [농부](/life/farmer), [나무꾼](/life/woodcutter), [사육사](/life/breeder), [요리사](/life/chef), [대장장이](/life/blacksmith) 문서에서 확인할 수 있어.

사육사는 현재 **7개 패시브**, 요리사는 **6개 스킬**을 사용해. 삭제된 스킬에 직접 투자했던 포인트는 반환되고, 해당 장비 잠재는 같은 직업의 남은 스킬로 바뀌어. 기존 스킬 확장권 사용 기록은 유지돼.

| 행운 | 품질 / 추가 드롭 / 등급 운 | 광부·나무꾼 추가 드롭, 농사·사육 2·3성, 어획·요리 등급, 대장술 추가 제작 |

## 스탯 투자 화면 사용법

`/life`의 **스탯 투자**를 선택하면 공용·광부·어부·농부·요리사·나무꾼·대장술·사육사 탭을 볼 수 있어.

1. 효과를 확인할 공용 또는 직업 탭을 선택해.
2. 근로·지식·감각·행운 아이콘에 마우스를 올리면 직접 투자분과 착용 장비 기본 스탯을 합친 현재 수치, 현재 효과와 1포인트 투자 후 효과가 함께 표시돼.
3. 투자할 스탯 아이콘을 클릭하면 남은 공용 포인트 1개를 사용해.

- 직업 탭은 그 직업에서 받을 효과를 미리 보여 주는 화면이야. 탭마다 별도 스탯을 찍는 방식이 아니라, 투자한 공용 스탯이 모든 직업에 함께 적용돼.
- 포인트가 높아질수록 1포인트당 증가량이 완만해지는 구간이 있어.
- 화면에 표시되는 **현재 총 스탯이 200에 도달하면 해당 효과가 더 증가하지 않고 추가 투자도 할 수 없어**.
- 투자 방향을 바꾸려면 아래의 `공용 초심의 서`로 투자 상태를 초기화한 뒤 다시 분배할 수 있어.

## 생활 순위

서버의 생활 순위 홀로그램에서는 **공용 레벨**과 광부·어부·농부·나무꾼·요리사·대장술의 직업별 상위 10명을 확인할 수 있어.

- 화이트리스트에 등록된 유저만 순위에 집계돼
- 순위는 매일 **00시**에 갱신돼
- 화이트리스트 등록 상태가 바뀌면 집계 대상도 함께 갱신돼
- 레벨이 높은 순서로 정렬되고, 레벨이 같으면 현재 EXP가 높은 유저가 앞에 표시돼
- 직업별 1위는 해당 생활 직업의 1위 칭호와 연동돼
- 다음 갱신에서 순위가 바뀌면 1위 칭호 대상도 함께 바뀔 수 있어
- 홀로그램은 현재 저장된 순위이므로 실시간으로 오른 경험치가 즉시 반영되지는 않아

## 액티브 스킬 쿨다운 HUD

전용 `HybridHud` 모드를 사용하면 생활 액티브 스킬의 남은 재사용 대기시간을 화면에서 바로 확인할 수 있어.

- 표시 대상은 **광맥 파괴 · 광부의 각성 · 광석 감지 · 곡선 수확 · 자동 파종 · 숲의 분노 · 연속 참격 · 숲의 파동 · 물고기 떼의 부름 · 폭발 제련 · 초월 단조 · 냉장고를 부탁해**야
- HUD 모드는 남은 시간을 보기 쉽게 표시하는 선택 기능이야
- 모드를 설치하지 않아도 생활 스킬의 발동과 재사용 대기시간은 서버에서 정상 작동해

**J 키**로 HUD 편집기를 열어 쿨다운 표시 위치와 크기를 조절하거나 표시를 켜고 끌 수 있어. 왼쪽 위 상태창의 크기·배경 투명도와 채팅 글자 크기 조절은 [HUD와 채팅 설정](/guide/basic/hud)에서 확인해 줘.

## 생활 스킬 단축키

전용 LifeCore 클라이언트 모드를 사용하면 `설정 → 조작 설정 → LifeCore 생활`에서 생활 스킬 보조키를 지정할 수 있어. 보조키는 기존 마우스 조작과 함께 사용할 수 있는 선택 기능이야.

| 기능 | 기본 키 | 사용 조건 |
| --- | --- | --- |
| 낚시 미니게임 입력 | `Space` | 미니게임 진행 중 입력 |
| 광부의 각성 | `C` | 곡괭이를 들고 `Shift + 지정 키` |
| 광석 감지 | 미설정 | 곡괭이를 들고 `Shift + 지정 키` |
| 곡선 수확 | 미설정 | 괭이를 들고 `Shift + 지정 키` |
| 자동 파종 | 미설정 | 괭이를 들고 `Shift + 지정 키` |
| 숲의 분노 / 숲의 파동 | 미설정 | 도끼를 들고 `Shift + 지정 키`. 야생은 분노, 마을은 파동 |
| 연속 참격 | 미설정 | 도끼를 들고 `Shift + 지정 키`. 기존 나무 감지 키 사용 |
| 물고기 떼의 부름 | 미설정 | 낚싯대를 들고 지정 키 또는 `Shift + 좌클릭` |

- 광석 감지와 곡선 수확은 `Shift + 우클릭`, 자동 파종은 `Shift + 좌클릭`으로도 사용할 수 있어.
- 도끼는 야생에서 `Shift + 우클릭`으로 숲의 분노를, 마을에서 `Shift + 좌클릭`으로 연속 참격, `Shift + 우클릭`으로 숲의 파동을 사용해. 벌목 보조키를 지정했다면 해당 키가 대응하는 마우스 조작을 대신해.
- 냉장고를 부탁해는 뒤집개를 주 손이나 보조 손에 들고 `Shift + 우클릭`으로 사용해. 주방 설정을 열려면 뒤집개를 양손에서 내려놓아 줘.
- 사육사 스킬은 모두 패시브여서 별도 발동 키가 필요하지 않아.
- 키가 겹치거나 발동되지 않으면 `/키보드` 또는 조작 설정에서 현재 지정을 확인해 줘.

나무꾼은 현재 위치에 따라 사용하는 액티브 스킬이 달라. [나무꾼 안내](/life/woodcutter)에서 재배 나무 조건과 스킬 효과를 확인해 줘.

## 처음 시작할 때 추천 루트

1. `/life` 로 메인 메뉴를 열어서 전체 생활·생산 구조를 먼저 확인하기
2. `/guide` 또는 `/길라잡이` 로 초반 목표를 따라가며 핵심 장비와 작업대 익히기
3. 공용 레벨을 올리며 근로 · 지식 · 감각 · 행운을 자주 하는 직업에 맞춰 투자하기
4. 생활·생산 문서에서 내가 주로 할 직업의 스킬과 루프를 먼저 익히기
5. 상위 재료가 모이면 작업대와 농사 장비를 만들고, 드라코라이트 장비·큐브 성장에 사용하기

## 투자 포인트 초기화

투자 방향을 바꾸고 싶다면 서버 안 판매처에서 초기화 책을 구해 사용할 수 있습니다.

| 아이템 | 초기화 대상 | 유지되는 것 |
| --- | --- | --- |
| 생활 기억의 서 | 광부·어부·농부·나무꾼·사육사·요리사·대장술에 투자한 모든 스킬 | 각 직업 레벨과 EXP |
| 공용 초심의 서 | 근로·지식·감각·행운에 투자한 모든 공용 스탯 | 공용 레벨과 EXP |

1. 사용할 책을 주 손에 들고 우클릭합니다.
2. 안내를 읽고 **10초 안에 다시 우클릭**하면 초기화됩니다.
3. 투자한 포인트만 모두 반환되며 레벨과 EXP는 내려가지 않습니다.

초기화할 투자 내역이 없으면 책은 소모되지 않습니다. 생활 기억의 서와 공용 초심의 서는 대상이 서로 다르므로 이름을 꼭 확인하세요.

공용 초심의 서는 직접 투자한 포인트만 반환하므로 착용 장비의 기본 스탯은 바뀌지 않아. 방어구 한 부위의 기본 스탯을 다시 추첨하려면 [스탯 재분배 주문서](/life/equipment)를 사용해야 해.

## 길라잡이 대표 목표 예시

`/길라잡이` 또는 `/guide`를 열어 분류별 목표와 진행도를 확인해. 기본 생활을 익힌 뒤에는 **제작 → 고급 제작 → 성장** 목표까지 이어서 도전할 수 있어.

- 기본: 나무 벌목, 제작대 만들기, `/가방` 열기, 구리 / 철 / 금 채굴, 돌 굽기, `/거래소` 사용, 스탯 · 스킬 투자, 채팅 인사
- 어부: 바닐라 낚싯대 제작, 어부 작업대 제작, 물고기 낚기 16 / 32 / 64회
- 농부: 씨앗 심기, 커스텀 농작물 수확, 물뿌리개 / 비닐하우스 / 허수아비 / 화분 제작
- 광부: 대장간 화로 제작, 심연 프리즘 / 코어 스틸 / 기어 브론즈 광맥 채굴
- 요리사: 후라이팬 제작하기, 노멀 / 실버 / 골드 요리 완성
- 제작: 흔한 작업대에서 재료 자동 배치, 제작대·화로 완성품 수령, 여러 제작법 완성
- 고급 제작: 강화석 얻기, 큐브·큐브 각인 장치와 드라코라이트 방어구 제작
- 성장: 장비 소유권 각인, 기본 스탯 분배, 강화 3회 시도, 큐브 3회 사용, 본인 소유 드라코라이트 네 부위 착용

목표마다 완료 조건을 확인해. **완성품 수령이 목표라면 제작대·화로에서 결과까지 받아야** 진행돼. 자동 재료 넣기 목표는 레시피 미리보기만 보는 것으로는 완료되지 않아.

강화석은 채광·낚시·농사·벌목·요리·사육 중 직접 얻을 수 있어. **강화석 얻기** 목표는 인벤토리·보조 손·자동 가방의 실제 보유분을 확인하고, 이미 가진 강화석도 인정하며 소모하지 않아. 예전에 얻은 생활 조각의 제작·교환은 계속 이용할 수 있어.

실제 요리는 현재 [설치형 주방](/life/chef)에서 진행해. 기존 요리사 조리대의 제작·조리는 종료됐으므로 옛 가구를 새로 만들거나 열려고 하지 않아도 돼.

성장 목표의 강화는 성공 횟수가 아닌 **시도 횟수**를 세어. 네 부위 착용 목표는 투구·흉갑·각반·장화를 모두 본인에게 각인해 입어야 해. 각인부터 기본 스탯·강화·큐브까지의 조작은 [장비 성장 안내](/life/equipment)에서 확인해 줘.
