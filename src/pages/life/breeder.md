## 사육사 핵심 요약

사육사는 **소·돼지·양·닭·토끼**를 소환하고, 준비된 생산물을 검으로 수확하는 생활이야. 동물별 먹이나 레벨을 따로 관리하지 않아도 돼.

- `/생활 사육사`에서 **내 동물 관리**를 열어 알 없이 소환해.
- 본인이 소환한 동물만 수확할 수 있고, 생산물은 **1성·2성·3성** 품질로 나와.
- 목장을 증축하면 종류별 소환 한도·생산물 준비량·생산 속도가 늘어나.
- 스킬은 모두 **패시브**야. 직접 수확하면서 조건을 채우면 자동으로 발동해.

## 동물 소환과 회수

1. `/생활 사육사` 또는 생활 메뉴의 **내 동물 관리**를 열어.
2. 동물 종류를 고르고 **소환** 버튼을 눌러.
3. 60초 안에 위쪽 공간이 비어 있는 **잔디 블록을 우클릭**해.
4. 생산물이 준비되면 검을 주 손에 들고 동물을 좌클릭해서 수확해.

소환하려는 위치에는 설치 권한이 필요하고, 수확하려면 해당 위치의 파괴 권한도 있어야 해. 마을원이라도 **다른 사람의 사육 동물을 대신 수확할 수는 없어**. 자연에서 만난 일반 동물은 사육사 동물로 등록되지 않아.

같은 종류는 화면에 **대표 동물 1마리**로 나타나고 이름표의 숫자가 무리의 마릿수를 뜻해. 증축 후 같은 종류를 더 소환하면 기존 대표 무리에 합쳐져. 같은 종류를 추가할 때는 기존 동물 가까이에서 진행하고, 다른 종류의 내 무리와는 1.75블록 이상 떨어진 곳에 배치해 줘.

동물을 우클릭하면 상태와 수확 진행도를 볼 수 있어. **내 동물 관리에서 회수**하면 멀리 있는 동물도 보관할 수 있고, 다시 소환할 때 이미 쌓인 생산물·생산 시간·수확 진행도가 이어져. 회수한 동물은 알 아이템으로 돌아오지 않아.

## 생산과 수확

생산은 **주인이 접속해 동물의 현재 위치에서 24블록 안에 있을 때** 진행돼. 멀리 이동하거나 접속을 종료하면 멈추며, 돌아왔을 때 자리를 비운 시간만큼 한꺼번에 생산되지는 않아. 회수해 보관 중인 동물도 생산하지 않아.

- 이름표에서 **수확 가능한 회분과 진행도**를 확인해.
- 검으로 직접 타격해 수확 진행도 **100마다 준비된 생산물 1회분**을 수확해.
- 생산물이 아직 준비되지 않았다면 타격해도 수확 진행도는 쌓이지 않아.
- 준비량이 가득 차면 새 생산이 멈추므로 주기적으로 수확해 줘.
- 수확한 생산물은 동물 주변 바닥으로 떨어져. **다른 유저도 주울 수 있으므로** 바로 챙겨 줘.

검으로 사육 동물을 때리는 것은 생산물 수확 동작이야. 동물을 죽이거나 가위·양동이로 바닐라 생산품을 얻는 방식은 사용하지 않아.

### 동물별 생산품

수확할 때 해당 동물의 생산품 중 하나가 나와. 스킬과 스탯에 따라 추가 수량이나 높은 품질을 얻을 수 있어.

| 동물 | 나올 수 있는 생산품 |
| --- | --- |
| 소 | 목장 쇠고기, 목장 우유 |
| 돼지 | 목장 돼지고기, 질긴 가죽 |
| 양 | 목장 양고기, 보드라운 양털 |
| 닭 | 목장 닭고기, 목장 달걀 |
| 토끼 | 목장 토끼고기, 부드러운 토끼 가죽 |

서바이벌에서 수확하면 사육사 숙련도를 올릴 수 있고, 희귀 보상으로 **황금 축산물·강화석**을 얻을 기회도 있어. 생산품은 [요리](/life/chef), 목장 증축, 판매와 교환에 활용해.

## 목장 증축

**내 동물 관리 → 목장 증축**에서 조건과 필요한 재료를 확인하고 증축할 수 있어. 증축은 계정 전체에 적용되며 스킬 포인트를 사용하지 않아.

| 목장 단계 | 필요한 사육사 레벨 | 종류별 소환 한도 | 종류별 준비량 | 기본 생산 1회분 |
| --- | ---: | ---: | ---: | ---: |
| 기본 | 없음 | 1마리 | 3회분 | 60초 |
| 1단계 | 10 | 2마리 | 4회분 | 50초 |
| 2단계 | 25 | 3마리 | 5회분 | 약 42.9초 |
| 3단계 | 40 | 4마리 | 6회분 | 37.5초 |

표의 시간은 스탯·스킬을 적용하기 전 기준이야. 근로와 **무리의 호흡**에 따라 더 짧아질 수 있고, 마릿수를 늘렸다고 생산 속도가 마릿수만큼 다시 곱해지지는 않아.

증축에는 **사육으로 얻은 가죽과 양털**을 사용해. 질긴 가죽과 부드러운 토끼 가죽을 섞을 수 있고, 각 품질도 섞어서 사용할 수 있어. 일반 바닐라 가죽·양털은 증축 재료가 아니므로 확인 화면의 요구 재료를 봐 줘.

## 사육사 스킬

`/생활 skills breeding` 또는 생활 메뉴의 사육사 스킬 화면에서 투자할 수 있어. 현재 사용하는 스킬은 아래 **7개 패시브**야.

| 스킬 | 효과와 발동 조건 |
| --- | --- |
| 능숙한 손길 | 직접 타격과 자동 수확 보조의 진행도 증가 |
| 풍요로운 목장 | 수확 시 같은 생산품을 추가로 얻을 확률 증가 |
| 윤기나는 결실 | 2성·3성 생산품이 나올 확률 증가 |
| 은빛 검무 | 준비된 생산물에 직접 유효 타격 5회 후, 같은 무리에 참격 3회로 수확 보조 |
| 목장의 파동 | 직접 생산물 1회분을 수확하면 8블록 안의 다른 준비된 내 무리 최대 3곳에 수확 보조 |
| 별빛 소나기 | 직접 유효 타격 20회로 충전한 뒤, 다음 유효 타격에 8블록 안의 준비된 내 무리 최대 5곳에 수확 보조 |
| 무리의 호흡 | 서로 다른 동물 3종을 직접 수확하면 해당 3종의 다음 생산 1회씩 시간 단축 |

검무·파동·별빛은 **준비된 생산물의 수확 진행도**를 올려 줘. 아직 생산되지 않은 물건을 만들어 주지는 않아. 자동 보조 타격이 다른 패시브의 직접 타격·직접 수확 조건을 다시 채우지도 않아.

별도 스킬 단축키나 마나 소모 없이 발동해. 무리의 호흡은 중첩되지 않으며, 별빛 소나기가 완충됐는데 대상이 없으면 다음 기회까지 충전이 유지돼.

기존 **가벼운 발걸음·황금빛 축복**은 삭제됐어. 두 스킬에 투자했던 포인트는 돌려받고, 기존 장비의 해당 큐브 옵션은 남은 사육사 스킬로 바뀌어. 직접 투자·확장·장비 보너스의 차이는 [생활 스킬 랭크 구조](/life/growth#생활-스킬-랭크-구조)를 확인해 줘.

## 공용 스탯 체감

| 스탯 | 효과 |
| --- | --- |
| 근로 | 생산물 1회분이 준비되는 시간 단축 |
| 지식 | 사육사 숙련 EXP와 검무·파동·별빛의 자동 보조 진행도 증가 |
| 감각 | 같은 생산품 추가 획득 확률 증가 |
| 행운 | 2성·3성 생산품 비중 증가 |

생활 메뉴와 사육 정보 화면에서 **현재 목장 단계·소환 한도·생산 주기·준비량·스탯과 스킬의 실제 적용 효과**를 확인할 수 있어.

## 판매와 교환

**`/생활 사육상점`은 일반 유저도 이용할 수 있어.** 로얄츄르냥은 **상점 메뉴 → 사육사 상점**으로도 열 수 있어. 여기서 생산품과 황금 축산물을 판매해. 현재 판매 가격은 생산품 **1성 3원·2성 5원·3성 8원**, 황금 축산물은 **700원**이야. 거래 전 상점에 표시되는 가격을 확인해 줘.

**생활 교환소 → 사육사 교환** 또는 `/생활 사육품질교환`에서는 같은 종류의 생산품을 더 높은 품질로 바꿀 수 있어.

- **1성 3개 → 2성 1개**
- **1성 6개 → 3성 1개**
- **2성 2개 → 3성 1개**

가죽·양털을 일반 재료로 바꾸거나 이전에 얻은 사육 조각을 교환하려면 별도의 **`/생활 사육교환`**을 이용해. 품질 교환과는 다른 교환창이야.
