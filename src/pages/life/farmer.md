## 농부 핵심 요약

농부는 현재 **바닐라 작물보다 커스텀 작물 중심**으로 설계되어 있어.

- 현재 핵심 성장 대상은 커스텀 작물
- 품질은 기본적으로 **1성 80 / 2성 15 / 3성 5**
- 커스텀 작물 수확 EXP는 현재 6으로 통일
- 딸기, 상추, 양배추, 무, 토마토, 옥수수, 포도, 파인애플, 오렌지, 바나나, 레몬, 석류 같은 작물을 재배해

## 공용 스탯 체감

| 스탯 | 효과 |
| --- | --- |
| 근로 | 괭이 내구도 소모 방지 확률 증가 |
| 감각 | 추가 드롭 확률 증가 |
| 행운 | 2성 / 3성 작물 가중치 증가 |
| 지식 · 흥정 · 명성 | 현재 농부 핵심 미적용 |

## 농부 스킬

| 스킬 | 설명 |
| --- | --- |
| 풍요 수확 | 수확 시 같은 품질의 작물 1개를 추가로 얻을 확률 증가 |
| 장인의 손맛 | 1·2성 확률을 낮추고 3성 확률 증가 |
| 곡선 수확 | 괭이로 Shift + 우클릭해 일정 시간 전방 1×3 범위 수확 |
| 자동 파종 | 괭이로 Shift + 좌클릭해 일정 시간 수확한 자리에 자동 파종 |

현재 스킬 GUI에서 투자하는 핵심 스킬은 위 네 종류입니다. 자동 파종은 인벤토리에 해당 씨앗이 있어야 작동하며, 곡선 수확과 함께 사용하면 범위 수확 뒤 재파종까지 이어집니다.

## 계절과 농장 보조 시설

커스텀 작물은 씨앗 설명에 표시된 계절에 맞춰 심어야 합니다.

- **비닐하우스 유리**: 작물 바로 위 최대 5칸 안에서 계절 제한을 보완합니다. 화분 위 3칸 높이가 확인하기 편합니다.
- **허수아비**: 중심에서 7칸 범위의 작물을 보호해 까마귀 피해를 막습니다.
- 씨앗을 심기 전에 아이템 설명의 재배 가능 계절을 먼저 확인하세요.

## 추천 플레이 감각

- 빠른 반복 수확 효율은 **감각** 체감이 큼
- 더 좋은 등급 작물을 원하면 **행운** 비중이 커
- 괭이를 오래 쓰고 싶으면 **근로**가 편해
- 커스텀 작물 위주로 농장을 굴릴수록 농부 체감이 분명해져
- 넓은 밭은 **곡선 수확 + 자동 파종**을 함께 사용하면 반복 작업을 줄일 수 있어
