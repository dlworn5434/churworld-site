## 농부 핵심 요약

농부는 현재 **바닐라 작물보다 커스텀 작물 중심**으로 설계되어 있어.

- 현재 핵심 성장 대상은 커스텀 작물
- 품질은 기본적으로 **1성 80 / 2성 15 / 3성 5**
- 커스텀 작물 수확 EXP는 현재 6으로 통일
- 딸기, 상추, 양배추, 무, 토마토, 옥수수, 포도, 파인애플 같은 작물을 중심으로 이해하면 돼

## 공용 스탯 체감

| 스탯 | 효과 |
| --- | --- |
| 근로 | 괭이 내구도 소모 방지 확률 증가 |
| 감각 | 추가 드롭 확률 증가 |
| 행운 | 2성 / 3성 작물 가중치 증가 |
| 지식 · 흥정 · 명성 | 현재 농부 핵심 미적용 |

## 농부 스킬

| 스킬 | 설명 |
| --- | --- |
| 풍요 수확 | 수확 시 추가 작물 1개 드롭 확률 증가 |
| 장인의 손맛 | 1·2성 확률을 낮추고 3성 확률 증가 |
| 신선 보관 | 농산물 유통기한 증가 기능 (준비 중) |
| 곡선 수확 | 쉬프트 + 우클릭으로 전방 1×3 범위 수확 |
| 자동 파종 | 쉬프트 + 좌클릭으로 전방 자동 파종 시도 |

## 추천 플레이 감각

- 빠른 반복 수확 효율은 **감각** 체감이 큼
- 더 좋은 등급 작물을 원하면 **행운** 비중이 커
- 괭이를 오래 쓰고 싶으면 **근로**가 편해
- 커스텀 작물 위주로 농장을 굴릴수록 농부 체감이 분명해져
