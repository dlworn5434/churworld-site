## 대장술 핵심 요약

대장술은 **제작대와 대장간 화로에서 아이템을 제작·제련**하며 숙련도를 올리는 생활입니다. 제작 시간을 줄이고, 사용한 재료를 돌려받거나 결과물을 추가로 얻는 방향으로 성장합니다.

- 제작대 레시피 기본 EXP: 5
- 화로 레시피 기본 EXP: 3
- 주요 스탯: 근로 · 지식 · 행운
- 시작 목표: 길라잡이에서 대장간 화로 제작하기

## 대장술 스킬

| 스킬 | 효과 | 현재 설정 |
| --- | --- | --- |
| 강인한 제련 | 제련·제작 시간 단축 | 랭크당 2%, 스탯 합산 최대 40% |
| 재료 절약 | 사용한 재료 1개 반환 확률 | 랭크당 1.5%, 최대 30% |
| 장인의 솜씨 | 결과물 추가 획득 확률 | 랭크당 1%, 최대 20% |
| 숙련된 손길 | 제작 성공 확률 증가 | 랭크당 1%p, 최대 20%p |
| 폭발 제련 | 제련을 돕는 액티브 스킬 | 마나 20, 재사용 120초 |

## 공용 스탯 적용

| 스탯 | 대장술 효과 |
| --- | --- |
| 근로 | 제작 시간 추가 단축, 재료 절약 확률 증가 |
| 지식 | 제작 성공 확률 증가 |
| 행운 | 추가 결과물 확률 증가 |
| 감각 · 흥정 · 명성 | 현재 핵심 적용 없음 |

근로의 시간 단축은 최대 10%, 재료 절약 보정은 최대 8%까지 적용됩니다. 지식의 성공률 보정은 최대 10%p, 행운의 추가 결과물 보정은 최대 8%입니다.

## 시작 방법

1. `/길라잡이`에서 **대장간 화로 제작하기** 목표를 확인합니다.
2. 생활 제작대에서 대장간 화로 레시피와 필요한 재료를 확인합니다.
3. 제작대와 화로 레시피를 진행해 대장술 EXP를 올립니다.
4. `/life skills smithing`에서 원하는 제작 방향에 맞춰 스킬을 투자합니다.

## 추천 투자 방향

- 빠른 반복 제작: **강인한 제련 + 근로**
- 비싼 재료 아끼기: **재료 절약 + 근로**
- 결과물 수량 늘리기: **장인의 솜씨 + 행운**
- 실패 위험 줄이기: **숙련된 손길 + 지식**

레시피별 제작 시간, 성공률과 EXP가 따로 지정된 경우 해당 레시피 설정이 우선 적용될 수 있습니다.
