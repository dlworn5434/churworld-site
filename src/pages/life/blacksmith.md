## 대장술 핵심 요약

대장술은 **생활 제작대와 흔한 화로에서 아이템을 제작·제련**하며 숙련도를 올리는 생산 직업입니다. 제작 시간을 줄이고, 사용한 재료를 돌려받거나 결과물을 추가로 얻는 방향으로 성장합니다.

- 제작대 레시피 기본 EXP: 5
- 화로 레시피 기본 EXP: 3
- 주요 스탯: 근로 · 지식 · 행운
- 시작 목표: 길라잡이에서 대장간 화로 제작하기
- 상위 제작: 농사 장비, 큐브, 드라코라이트 방어구와 강화 재료

## 대장술 스킬

| 스킬 | 효과 | 현재 최대 기준 |
| --- | --- | --- |
| 강인한 제련 | 제작 시간을 근로와 별도로 단축 | 스킬만 최대 40%, 전체 단축 상한 60% |
| 재료 절약 | 제작 시작 시 사용 재료 1개 반환 확률 | 스킬만 최대 30%, 전체 상한 48% |
| 장인의 솜씨 | 제작 완료 시 결과물 1개 추가 획득 확률 | 스킬만 최대 21%, 전체 상한 38% |
| 장인의 흔적 | 제작 완료 시 생활도구 강화 재료 획득 | 현재 강화 재료가 등록되기 전까지 잠금 |
| 폭발 제련 | 현재 제작의 남은 시간 단축 | 마나 20, 20랭크부터 현재 작업 즉시 완료 |

## 공용 스탯 적용

| 스탯 | 대장술 효과 |
| --- | --- |
| 근로 | 제작 시간 추가 단축 |
| 지식 | 재료 절약 확률과 대장술 숙련 EXP 증가 |
| 감각 | 레시피 성공률 증가 |
| 행운 | 추가 결과물 확률 증가 |
| 흥정 · 명성 | 현재 핵심 적용 없음 |

현재 스탯 보정은 근로 제작 시간 최대 약 15%, 지식 재료 절약 최대 4%·대장술 숙련 EXP 최대 10%, 감각 성공률 최대 10%p, 행운 추가 제작 최대 4% 방향으로 적용됩니다.

## 시작 방법

1. `/길라잡이`에서 **대장간 화로 제작하기** 목표를 확인합니다.
2. [생활 제작법](/life/recipes)에서 대장간 화로 레시피와 필요한 재료를 확인합니다.
3. 생활 제작대와 흔한 화로 레시피를 진행해 대장술 EXP를 올립니다.
4. `/life skills smithing`에서 원하는 제작 방향에 맞춰 스킬을 투자합니다.

폭발 제련은 제작대 대기열에서 Shift + 클릭하거나, 흔한 화로 화면의 스킬 버튼으로 사용합니다. 1~19랭크는 남은 시간을 줄이고 20랭크부터 현재 작업 하나를 즉시 완료합니다.

## 추천 투자 방향

- 빠른 반복 제작: **강인한 제련 + 근로**
- 비싼 재료 아끼기: **재료 절약 + 지식**
- 결과물 수량 늘리기: **장인의 솜씨 + 행운**
- 실패 위험 줄이기: **감각**

레시피별 제작 시간, 성공률, EXP와 보너스 적용 여부가 따로 지정된 경우 해당 레시피가 우선합니다. 큐브·방어구 성장 흐름은 [장비·큐브 문서](/life/equipment)에서 이어서 확인하세요.
