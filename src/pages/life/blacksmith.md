## 대장술 핵심 요약

대장술은 **생활 제작대와 흔한 화로에서 제작·제련**하며 숙련도를 올리는 생산 직업이야. 제작 시간을 줄이고 재료를 아끼거나 결과물을 추가로 얻는 방향으로 성장해.

- 제작대 레시피 기본 EXP: 12
- 흔한 화로 레시피 기본 EXP: 5
- 개별 레시피에 별도 EXP가 있으면 해당 레시피 값이 우선
- 주요 제작: 농사 장비, 생활 광물, 큐브와 드라코라이트 방어구

## 대장술 스킬

| 스킬 | 효과 | 1 / 10 / 20 / 25 / 30 / 35랭크 기준 |
| --- | --- | --- |
| 강인한 제련 | 제작 시간 추가 단축 | 1.2 / 12 / 24 / 32 / 40 / 48% |
| 재료 절약 | 제작 시작 시 재료 일부 보존 | 0.75 / 7.5 / 15 / 22.5 / 30 / 37.5% |
| 장인의 솜씨 | 제작 완료 시 결과물 추가 획득 | 0.5 / 5 / 10 / 15.5 / 21 / 26.5% |
| 숙련된 손길 | 레시피 성공률 증가 | +0.5 / +5 / +10 / +15 / +20 / +25%p |
| 폭발 제련 | 현재 작업의 남은 시간 단축 | 25 / 60 / 100 / 100 / 100 / 100초 |
| 초월 단조 | 현재 시설의 미완료 작업 전체 남은 시간을 절반으로 단축 | 쿨타임 60 / 45 / 30 / 25 / 20 / 15분 |

## 공용 스탯 적용

| 스탯 | 대장술 효과 |
| --- | --- |
| 근로 | 제작 시간 추가 단축 |
| 지식 | 재료 절약 확률과 대장술 숙련 EXP 증가 |
| 감각 | 레시피 성공률 증가 |
| 행운 | 추가 결과물 확률 증가 |

## 제작 시작과 대기열

1. `/길라잡이`에서 대장간 화로 제작 목표를 확인해.
2. [생활 제작법](/life/recipes)에서 시설과 재료를 준비해.
3. 생활 제작대와 흔한 화로에서 제작·제련을 진행해.
4. `/life skills smithing`에서 원하는 방향의 스킬에 투자해.

생활 제작대는 6개 작업 칸에서 서로 다른 제작을 동시에 진행할 수 있어.

- 한 작업 칸에 같은 제작을 최대 10회 등록
- 진행 중·완료 후 미수령 작업을 모두 합쳐 최대 20개 보관
- 완료품을 오래 찾아가지 않아 전체 미수령 한도에 도달하면 새 작업을 시작할 수 없음
- 화면을 닫아도 작업은 계속 진행

## 폭발 제련

제작대 대기열에서 Shift+클릭하거나 흔한 화로 화면의 스킬 버튼으로 사용해.

- 마나 20 소모
- 재사용 대기시간: 1 / 10 / 20 / 25 / 30 / 35랭크에서 180 / 150 / 120 / 88 / 55 / 22초
- 현재 제작법의 작업 시간에 따라 20랭크 이상에서는 현재 작업이 즉시 완료될 수 있음

## 초월 단조

`초월 단조`는 폭발 제련에 직접 10랭크를 투자해야 배울 수 있는 상위 스킬이야.

작업대 또는 흔한 화로 화면의 전용 버튼으로 사용하면 **현재 열고 있는 시설과 같은 종류의 미완료 작업 전체**에 적용돼.

- 모든 대상 작업의 남은 시간을 각각 50% 단축
- 작업대에서 사용하면 작업대 작업, 화로에서 사용하면 화로 작업에 적용
- 마나 40 소모
- 장비·도감·큐브 보너스 랭크는 선행 조건을 대신하지 않음

## 추천 투자 방향

- 빠른 반복 제작: **강인한 제련 + 근로**
- 비싼 재료 보존: **재료 절약 + 지식**
- 결과물 수량 증가: **장인의 솜씨 + 행운**
- 실패 위험 감소: **숙련된 손길 + 감각**
- 여러 작업을 한꺼번에 단축: **폭발 제련 → 초월 단조**

레시피별 시간, 성공률, EXP와 보너스 적용 여부가 따로 지정된 경우 개별 레시피 설정이 우선해. 장비 성장 흐름은 [장비·큐브](/life/equipment)에서 이어서 확인해 줘.
