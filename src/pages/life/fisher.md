## 어부 핵심 요약

어부는 단순히 낚기만 하는 직업이 아니라, **등급 · 미니게임 · 조각 · 파츠** 까지 이어지는 복합 직업이야.

- 낚시 시 입질을 기다린다
- 커스텀 어획이 걸리면 미니게임이 시작될 수 있다
- 미니게임 실패 시 현재 기준으로 **완전 무보상**
- 성공 시 물고기, 보물, 조각, 파츠 재료 루프로 이어진다
- 낚시 성공 1회당 기본 어부 숙련 EXP는 18

## 미니게임 공통 원리

낚시 미니게임은 단순 성공 판정이 아니라 **물고기의 체력을 깎는 전투 방식**이야.

1. 커스텀 물고기가 걸리면 타이밍·균형·화살표 게임 중 하나가 무작위로 시작돼.
2. 올바르게 입력하거나 찌를 성공 구간에 유지하면 물고기에게 피해를 줘.
3. 제한 시간 **12초** 안에 물고기 체력을 0으로 만들면 낚시에 성공해.
4. 미스가 **5회** 누적되거나 시간이 끝나면 실패하며, 실패 시 보상은 없어.
5. 공격력은 기본 10에 장착한 파츠의 피해 옵션을 더해 계산해.

장착된 파츠의 남은 사용 횟수가 0이면 낚싯대에 붙어 있어도 효과가 적용되지 않아.

## 미니게임 종류와 조작

| 게임 | 조작 방법 | 피해를 주는 방법 | 실패에 가까워지는 행동 |
| --- | --- | --- | --- |
| 타이밍 게임 A | 움직이는 커서를 보고 **Shift** 입력 | 파랑·초록 성공 구간에서 입력. 초록 정밀 구간은 더 큰 피해 | 성공 구간 밖에서 입력 |
| 균형 게임 B | **Shift를 짧게 여러 번 입력**해 커서를 중앙으로 당김 | 움직이는 커서를 초록 성공 구간 안에 유지하면 반복 피해. 중앙에 가까우면 정밀 피해 | 성공 구간 밖에 1초 머물 때마다 미스가 쌓이고 물고기 체력 회복 |
| 화살표 게임 C | 화면에 표시된 **6개 방향**을 W·A·S·D 순서대로 입력 | 방향 하나를 맞힐 때마다 피해. 6개를 모두 맞히면 큰 풀클리어 보너스 피해 | 잘못된 방향 입력. 보호 효과가 없으면 현재 입력 줄이 초기화됨 |

화살표 게임 C의 제한 시간은 **12초**, 최대 실수는 **5회**야. 릴에 실수 보호 옵션이 있으면 한 판에서 잘못 누른 입력 1회를 막아 주며, 여섯 방향을 모두 맞혀야 풀클리어 보너스를 받을 수 있어.

## 낚시 감각 고정 주사기

`낚시 감각 고정 주사기`를 우클릭하면 타이밍 게임 A, 균형 게임 B, 화살표 게임 C 중 하나가 무작위로 선택되어 **7일 동안** 고정돼.

- 고정되는 것은 미니게임의 **종류**이며, 자동 성공이나 난이도 감소 효과는 아니야
- 낚시 미니게임이 진행 중일 때는 사용할 수 없어
- 효과가 남아 있을 때 다시 사용하면 기존 남은 기간 뒤에 7일이 추가돼
- `/생활 미니게임고정 상태`로 현재 고정된 게임과 남은 기간을 확인할 수 있어

획득 재화는 서로 다르므로 이름을 꼭 확인해.

| 획득처 | 가격 |
| --- | ---: |
| 후원상점 | 5,000 츄르 |
| 물물교환 | 츄르 코인 64개 |

## 물고기 변환

`/물고기 변환`에서 등록된 커스텀 물고기를 **무지개 물고기**로 바꿀 수 있습니다.

| 넣는 물고기 | 받는 무지개 물고기 |
| --- | ---: |
| 일반(노멀) ×1 | ×1 |
| 고급(실버) ×1 | ×2 |
| 희귀(골드) ×1 | ×4 |

변환 대상으로 등록되지 않은 아이템은 소모되지 않고 그대로 반환됩니다. 등급이 높은 물고기일수록 더 많은 무지개 물고기로 바뀌므로, 변환 화면에서 수량을 확인한 뒤 진행하세요.

## 낚시 파츠 시스템

어부 작업대에서는 낚싯대에 파츠를 장착하고 관리할 수 있어.  
파츠는 **낚싯대를 손에 든 상태에서 어부 작업대 사용**을 기준으로 이해하면 편해.

낚싯대 하나에는 **바늘·줄·릴을 각각 1개씩** 장착할 수 있고, 세 파츠의 효과가 함께 적용돼.

### 파츠가 게임에 적용되는 순서

1. 미니게임이 시작될 때 현재 손에 든 낚싯대의 바늘·줄·릴을 확인해.
2. 수명이 남은 파츠의 옵션을 모두 합쳐 공격력, 치명타, 판정 범위와 조작감을 계산해.
3. 선택된 미니게임에 맞는 옵션만 실제 플레이에 적용돼.
4. 낚시에 성공하면 장착된 바늘·줄·릴의 사용 횟수가 각각 1회씩 감소해.

### 미니게임별 파츠 효과

| 파츠 | 타이밍 게임 A | 균형 게임 B | 화살표 게임 C |
| --- | --- | --- | --- |
| 바늘 | 기본 공격력 증가, 초록 정밀 구간 피해 증가 | 반복 공격력과 중앙 정밀 피해 증가, 유지 바를 올리는 힘 증가 | 방향 하나를 맞힐 때의 피해 증가 |
| 줄 | 성공 구간이 넓어질 수 있음, 치명타 확률·배율 증가 | 초록 유지 바가 넓어질 수 있음, 물고기 움직임 감소, 치명타 확률·배율 증가 | 방향 입력 피해와 6개 풀클리어 피해에 치명타 적용, 풀클리어 보너스 증가 |
| 릴 | 성공 구간이 넓어질 수 있고 커서가 느려져 입력이 쉬워짐 | 중앙으로 당기는 힘 증가, 물고기 이동과 흔들림 감소 | 잘못 누른 입력 1회 보호, 풀클리어 보너스 증가 |

### 파츠를 쉽게 고르는 법

- 물고기 체력을 더 빨리 깎고 싶으면 **바늘**
- 강한 치명타와 완주 보너스를 원하면 **줄**
- 미니게임 조작이 어렵거나 실수를 줄이고 싶으면 **릴**
- 처음에는 릴로 성공률을 안정시키고, 익숙해지면 바늘과 줄 옵션을 강화하는 방식이 편해.

### 일반 파츠 옵션 범위

일반 파츠를 제작하면 아래 범위 안에서 옵션 수치가 무작위로 정해져.

| 파츠 | 생성될 수 있는 주요 옵션 |
| --- | --- |
| 바늘 | 공격력 +2~4, A/B 정밀 피해 배수 +0.06~0.12, B 조작력 +0.01~0.02, C 입력 피해 +2~5%p |
| 줄 | 치명타 확률 +2~4%p, 치명타 배율 +0.08~0.16, A/B 판정 범위 +0~1칸, B 물고기 움직임 ×0.94~0.99, C 완주 보너스 +0.20~0.50 |
| 릴 | A/B 판정 범위 +0~1칸, A 커서 속도 ×0.92~0.98, B 조작력 +0.01~0.02, B 이동·흔들림 ×0.93~0.98, C 실수 보호 1회, C 완주 보너스 +0.08~0.16 |

`×0.92`처럼 1보다 작은 이동·속도 배율은 수치가 낮을수록 움직임이 느려져 조작하기 쉬워진다는 뜻이야.

### 파츠 등급

| 등급 | 옵션 줄 수 | 기본 사용 횟수 |
| --- | --- | --- |
| 일반 | 1줄 | 30회 |
| 희귀 | 2줄 | 70회 |
| 영웅 | 3줄 | 150회 |
| 레전더리 | 4줄 | 300회 |

상위 등급으로 승급하면 옵션 줄 수와 수명이 늘고 옵션 효과도 더 강해져.

## 낚시 조각과 강화 루프

- 낚시 조각은 파츠 제작과 수명 연장에 쓰이는 핵심 재료
- 일반 파츠는 제작으로 만들고, 상위 등급은 합성 승급으로 올림
- 같은 종류 · 같은 등급 파츠 2개를 합쳐 다음 등급 승급을 시도
- 기본 합성 확률은 일반→희귀 70%, 희귀→영웅 45%, 영웅→레전더리 25%
- 옵션 돌리기는 장착된 파츠를 대상으로 하며, 잠근 옵션 수만큼 비용이 2배

## 추천 플레이 감각

- 빠른 템포를 원하면 **근로**
- 높은 등급을 원하면 **행운**
- 커스텀 어획 비율과 숙련 성장을 함께 챙기려면 **지식**
- 미니게임 물고기의 체력을 낮춰 부담을 줄이려면 **감각**
- 익숙하지 않을 때는 미니게임 성공률을 먼저 안정화하는 게 중요해
