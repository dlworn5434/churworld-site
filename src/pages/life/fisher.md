## 어부 핵심 요약

어부는 단순히 낚기만 하는 직업이 아니라, **등급 · 미니게임 · 조각 · 파츠** 까지 이어지는 복합 직업이야.

- 낚시 시 입질을 기다린다
- 커스텀 어획이 걸리면 미니게임이 시작될 수 있다
- 미니게임 실패 시 현재 기준으로 **완전 무보상**
- 성공 시 물고기, 보물, 조각, 파츠 재료 루프로 이어진다

## 미니게임 종류

| 게임 | 어떻게 진행되나 | 핵심 포인트 |
| --- | --- | --- |
| 타이밍 게임 | 움직이는 커서를 히트 칸에 맞춰 입력 | 타이밍, 판정 칸, 정밀 구간 보너스 |
| 당기기 게임 | 밀려나는 커서를 중앙에 붙잡아 유지 | 당김 힘, 중심 밀림, 흔들림 관리 |
| 화살표 게임 | 순서대로 방향 입력을 맞춤 | 입력 길이, 완주 보너스, 반복 정확도 |

## 공용 스탯 체감

| 스탯 | 효과 |
| --- | --- |
| 근로 | 입질 대기시간 감소 |
| 지식 | 커스텀 어획 확률 증가 |
| 행운 | 실버 / 골드 등급 가중치 증가 |
| 감각 | 현재 핵심 적용 아님 |

## 어부 스킬

| 스킬 | 설명 |
| --- | --- |
| 쌍걸 | 추가 어획 발동 확률 증가 |
| 보물 사냥꾼 | 보물 획득 확률 증가 |
| 숙련된 낚시 | 노멀 비중을 낮추고 상위 등급 비중을 높임 |
| 조각 수집 | 낚시 조각 추가 획득 확률 증가 |

## 낚시 파츠 시스템

어부 작업대에서는 낚싯대에 파츠를 장착하고 관리할 수 있어.  
파츠는 **낚싯대를 손에 든 상태에서 어부 작업대 사용**을 기준으로 이해하면 편해.

| 파츠 | 역할 | 주요 예시 |
| --- | --- | --- |
| 바늘 | 공격형 | 데미지, 타이밍 게임 정밀 구간 보너스, 당기기 게임 당김 힘 |
| 줄 | 치명타 · 안정성 | 치명타 확률, 치명타 배율, 판정 칸 수, 중심 밀림 |
| 릴 | 조작 편의 | 타이밍 속도, 당김 힘, 흔들림, 입력 길이 감소 |

### 파츠 등급

| 등급 | 옵션 줄 수 | 기본 사용 횟수 |
| --- | --- | --- |
| 일반 | 1줄 | 30회 |
| 희귀 | 2줄 | 70회 |
| 영웅 | 3줄 | 150회 |
| 레전더리 | 4줄 | 300회 |

## 낚시 조각과 강화 루프

- 낚시 조각은 파츠 제작과 수명 연장에 쓰이는 핵심 재료
- 일반 파츠는 제작으로 만들고, 상위 등급은 합성 승급으로 올림
- 같은 종류 · 같은 등급 파츠 2개를 합쳐 다음 등급 승급을 시도
- 기본 합성 확률은 일반→희귀 70%, 희귀→영웅 45%, 영웅→레전더리 25%
- 옵션 돌리기는 장착된 파츠를 대상으로 하며, 잠근 옵션 수만큼 비용이 2배

## 추천 플레이 감각

- 빠른 템포를 원하면 **근로**
- 높은 등급을 원하면 **행운**
- 커스텀 어획 비율을 높이고 싶으면 **지식**
- 익숙하지 않을 때는 미니게임 성공률을 먼저 안정화하는 게 중요해
