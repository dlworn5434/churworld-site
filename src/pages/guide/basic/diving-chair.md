## 잠수 서버란?

잠수 전용 서버에 접속해 있는 동안 일정 시간마다 **별**을 모으는 콘텐츠입니다. 의자를 설치하거나 앉지 않아도 적립되며, 모은 별을 판매하면 **잠수 포인트**를 얻습니다.

생활 서버와 잠수 서버에서 별 창고, 잠수 포인트, 등록한 프리미엄 의자를 함께 사용합니다.

## 잠수 시작과 종료

1. 생활 서버에서 **`/잠수 이동`**을 입력하거나 잠수 이동 안내원 **꿈의 조각**을 우클릭합니다.
2. 잠수 서버에 도착하면 검은 배경에 **별동별 파밍중**과 다음 별까지 남은 시간이 표시됩니다.
3. 잠수를 마치려면 **`/잠수 종료`**를 입력해 생활 서버로 돌아갑니다.

잠수 화면에서는 본인 몸·장비·손과 다른 플레이어가 보이지 않습니다. 채팅, 명령어, 별 창고와 판매는 계속 사용할 수 있습니다.

생활 서버가 점검 중이라 돌아갈 수 없다면 잠수 서버에 머물며 적립을 이어갈 수 있습니다. 잠수 서버도 종료되거나 접속이 끊기면 적립이 멈춥니다.

## 별 지급 간격과 프리미엄 의자

별은 기본 **100초마다 1개**씩 지급됩니다. **서로 다른 프리미엄 의자를 영구 등록할 때마다 5초씩** 줄어들며, 가장 짧은 간격은 **70초**입니다.

| 등록한 프리미엄 의자 종류 | 별 지급 간격 |
| --- | ---: |
| 0종 | 100초 |
| 1종 | 95초 |
| 2종 | 90초 |
| 3종 | 85초 |
| 4종 | 80초 |
| 5종 | 75초 |
| 6종 이상 | 70초 |

### 프리미엄 의자 등록하기

생활 서버의 `/잠수` 메뉴에서 의자 구매를 이용합니다. 프리미엄 구매권 1개로 무작위 **의자 등록 아이템**을 얻고, 해당 아이템을 손에 들고 우클릭하면 1개를 소모해 영구 등록합니다.

- 이미 등록한 종류는 다시 등록되지 않으며, 등록 시도만으로 아이템이 소모되지 않습니다.
- 뽑기에서는 이미 등록한 종류도 나올 수 있습니다.
- 등록하지 않은 아이템을 인벤토리에 보관하는 것만으로는 간격이 줄어들지 않습니다.
- 등록한 종류 수에 따른 단축은 잠수 서버에서도 적용됩니다.
- 현재 구매 가능 의자와 구매 조건은 `/잠수` 메뉴에서 확인할 수 있습니다.

## 별 창고와 판매

획득한 별은 인벤토리 대신 **`/잠수창고`**에 자동 보관됩니다. `/stars`도 같은 창고를 엽니다.

| 별 | 획득 확률 | 개당 판매 포인트 |
| --- | ---: | ---: |
| 흔한 별 | 70% | 1P |
| 푸른 별 | 20% | 5P |
| 붉은 별 | 8% | 20P |
| 전설의 별 | 2% | 200P |

창고에서 별을 판매해 포인트로 바꿀 수 있습니다. **모두 팔기**를 누르면 보관 중인 별을 전부 판매하며, 보유 포인트는 `/잠수 points`로 확인합니다.

## 포인트 상점

포인트 상품은 **생활 서버에서 `/starshop`**으로 구매합니다. 잠수 서버에서는 별 적립과 판매만 이용할 수 있으므로, 상품을 사고 싶다면 `/잠수 종료`로 돌아와 주세요.

상품별 가격, 판매 여부와 구매 제한은 상점에 표시됩니다. 구매 전에 현재 안내와 인벤토리 빈칸을 확인하세요.

## 생활 서버에서 의자 이용하기

생활 서버의 기존 의자 잠수도 이용할 수 있습니다. 일반 의자 아이템을 우클릭하면 **내 잠수 의자** 목록이 열리고, 일반 의자 또는 등록한 의자를 선택해 앉습니다. 일반 의자 아이템은 사용해도 소모되지 않습니다.

- 생활 서버에서는 스폰 월드에서 정상적으로 앉아 있어야 적립됩니다.
- 어떤 의자 외형을 골라도 등록한 프리미엄 종류 수에 따른 지급 간격이 적용됩니다.
- 평평한 고체 바닥과 충분한 주변 공간이 필요하며, 물속·계단·반블록이나 비행 중에는 시작할 수 없습니다.
- 의자에서 내리거나 `/잠수 종료`를 입력하면 의자 잠수가 끝납니다.

잠수 전용 서버를 이용할 때는 위 착석 조건이나 의자 아이템이 필요하지 않습니다.

## 디스코드 음성 보상

마인크래프트 계정을 연결한 뒤 인정되는 디스코드 음성 활동에 참여하면 별을 받을 수 있습니다. 음성 보상도 같은 확률표를 사용하며, `/잠수창고`에 합산됩니다.

계정 연결 방법과 음성 활동 인정 조건은 디스코드의 현재 안내를 확인해 주세요.

## 자주 묻는 질문

### Q. 게임을 꺼도 별이 쌓이나요?

아니요. 잠수 서버에 접속한 동안만 적립됩니다. 재접속하거나 서버를 이동하면 다음 별까지 남은 시간은 새로 시작합니다. 이미 받은 별과 포인트는 유지됩니다.

### Q. 검은 화면에 다른 사람이 보이지 않아요.

정상적인 잠수 화면입니다. 화면에 표시되는 남은 시간으로 적립 상태를 확인하고, 생활 서버로 돌아갈 때는 `/잠수 종료`를 입력하세요.

### Q. 잠수 서버에서 상점이 열리지 않아요.

상품 구매는 생활 서버에서만 가능합니다. 잠수 서버에서는 `/잠수창고`로 별을 판매한 뒤, 생활 서버로 돌아가 `/starshop`을 이용하세요.

## 명령어

| 명령어 | 기능 |
| --- | --- |
| `/잠수 이동` | 잠수 전용 서버로 이동 |
| `/잠수 종료` | 잠수 서버에서 생활 서버로 복귀, 생활에서는 의자 잠수 종료 |
| `/잠수` 또는 `/sd` | 잠수 메뉴 열기 |
| `/잠수창고` 또는 `/stars` | 별 창고 열기·판매 |
| `/잠수 points` | 보유 잠수 포인트 확인 |
| `/starshop` | 생활 서버에서 포인트 상품 구매 |
