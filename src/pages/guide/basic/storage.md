## 자동 창고 정리란?

**투입함에 아이템을 넣고 닫으면, 액자에 지정한 품목에 맞춰 보관 상자로 자동 이동하는 기능**입니다. 여러 종류의 재료를 한곳에 넣어도 등록된 상자로 나누어 보관할 수 있습니다.

| 구성 | 역할 |
| --- | --- |
| 투입함 | 정리할 아이템을 넣는 상자. 창고마다 1개를 지정합니다. |
| 목적지 상자 | 품목별로 아이템을 받는 보관 상자입니다. |
| 분류 액자 | 목적지 상자에 직접 붙이고, 받을 아이템의 견본을 넣는 액자입니다. |

예를 들어 조약돌 액자를 붙인 상자와 철 주괴 액자를 붙인 상자를 준비하면, 투입함에 넣은 조약돌과 철 주괴가 각각 해당 상자로 옮겨집니다.

## 누가 사용할 수 있나요?

- **마을장·부마을장·매니저** 등 마을 땅 관리 권한을 가진 유저가 창고를 생성하고 분류 품목을 설정할 수 있습니다.
- 일반 마을원도 **투입함과 목적지 상자의 보관함 사용 권한**이 있으면 자동 정리를 이용할 수 있습니다.
- 투입함과 목적지 상자는 **같은 마을의 점유지 안**에 있어야 합니다. 창고 등록으로 다른 그룹의 보관함 권한을 우회할 수는 없습니다.
- 분류 액자를 설치하거나 설정하려면 해당 위치의 **아이템 액자 사용 권한**도 필요합니다.
- 개인 잠금이 걸린 상자나 액자는 자동 창고로 이용할 수 없습니다. 큰 상자는 연결된 양쪽 모두 영역·권한·잠금 조건을 만족해야 합니다.

마을 그룹별 권한은 [마을 안내](/guide/basic/village)에서 확인할 수 있습니다.

## 창고 만들기

1. 자기 마을 점유지에 투입함으로 쓸 **일반 상자 또는 큰 상자**를 놓습니다.
2. `/창고 생성 재료창고`처럼 창고 이름을 정해 명령어를 입력합니다.
3. **60초 안에 투입함을 우클릭**합니다. 시간이 지났다면 생성 명령어를 다시 입력하세요.
4. 투입함에서 기본 **32블록 이내**에 품목별 보관 상자를 놓습니다.
5. 각 보관 상자에 **아이템 액자를 직접 붙이고**, 보관할 바닐라 아이템을 견본으로 넣습니다. 액자 설치·견본 변경 시 목적지 등록을 시도합니다.
6. `/창고 목록`으로 목적지 수를 확인합니다. 등록되지 않았다면 `/창고 새로고침 재료창고`를 사용하세요.

창고 이름은 **1~24자**이며 한글·영문·숫자·밑줄(`_`)·하이픈(`-`)을 사용할 수 있습니다. 공백이나 같은 마을에서 이미 사용 중인 이름은 사용할 수 없습니다.

주변 탐색은 현재 불러와진 구역에서 진행됩니다. 멀리 떨어진 상자가 등록되지 않으면 해당 구역 가까이에서 새로고침한 뒤 다시 확인하세요.

## 한 상자에 여러 품목 지정하기

목적지 상자 하나에 기본 **최대 5종**을 등록할 수 있습니다. 액자에 넣은 대표 품목도 이 한도에 포함됩니다.

1. 등록된 분류 액자를 **Shift + 우클릭**해 설정 화면을 엽니다.
2. 아래쪽 **내 인벤토리에서 추가할 아이템을 클릭**합니다. 견본만 등록되며 인벤토리의 아이템은 소모되지 않습니다.
3. 추가한 품목을 빼려면 위쪽 분류 칸의 해당 아이템을 **우클릭**합니다.
4. **저장**을 눌러 적용합니다. 취소하거나 저장 없이 창을 닫으면 변경 내용이 적용되지 않습니다.

첫 번째 품목은 **액자에 들어 있는 대표 아이템**이라 설정 화면에서 해제할 수 없습니다. 대표 품목을 바꾸려면 액자의 견본을 바꾸세요.

등록된 액자를 가까이에서 바라보면 그 상자의 분류 품목이 **본인에게만 아이템 모양으로 표시**됩니다. 시선을 떼면 사라지며, 표시된 아이콘을 가져갈 수는 없습니다.

## 아이템 정리하기

1. 등록한 투입함을 열고 정리할 아이템을 넣습니다.
2. **투입함을 닫습니다.** 닫는 동작을 계기로 자동 정리가 시작됩니다.
3. 잠시 기다린 뒤 목적지 상자와 투입함에 남은 아이템을 확인합니다.

- 분류 품목과 일치하지 않는 아이템은 **투입함에 남습니다**.
- 목적지에 공간이 부족하면 들어갈 수 있는 만큼만 옮기고, 남은 수량은 투입함에 둡니다.
- 목적지를 비웠거나 설정을 바꾼 뒤에는 **투입함을 다시 열었다 닫아** 정리를 요청하세요.
- 누군가 상자를 열고 있거나 정리·안전 점검이 진행 중이면 이동 또는 상자 조작이 잠시 제한될 수 있습니다.
- 같은 종류라도 이름·인챈트·물약 효과 등이 다르면 다른 품목으로 판정될 수 있습니다. 옮기려는 아이템과 같은 견본을 등록하세요.

## 지원 범위와 기본 한도

| 항목 | 기본 기준 |
| --- | --- |
| 마을당 자동 창고 | 최대 3개 |
| 창고당 목적지 상자 | 최대 32개 |
| 목적지 상자당 분류 품목 | 대표 품목 포함 최대 5종 |
| 목적지 탐색 거리 | 투입함 기준 반경 32블록 |
| 지원 상자 | 일반 상자와 큰 상자 |

위 수치는 기본 설정 기준이며, 서버에서 별도로 안내하는 한도가 있으면 해당 안내를 따르세요.

- 함정 상자·통·셜커 상자·엔더 상자·호퍼는 투입함이나 목적지 상자로 사용할 수 없습니다.
- 서버 전용 작물·재료 등 **커스텀 아이템은 자동 정리 대상이 아닙니다**. 일반 마인크래프트의 바닐라 아이템을 사용하세요.
- 내용물이 든 번들·컨테이너 아이템이나 장전된 석궁처럼 내부에 다른 아이템을 담고 있는 물품도 자동 이동하지 않습니다.
- 자동 창고로 등록된 상자에 연결한 **호퍼의 아이템 이동은 기본적으로 차단**됩니다.
- **투입함을 서로 붙여 놓아도 목적지 목록을 공유하지 않습니다.** 목적지 상자 하나를 여러 창고에 중복 등록할 수 없으므로, 창고별 보관 상자를 구분해 배치하세요.

## 관리 명령어

`<이름>`에는 등록한 창고 이름을 입력합니다. 예를 들어 `/창고 일시정지 재료창고`처럼 사용합니다.

| 명령어 | 기능 |
| --- | --- |
| `/창고 도움말` | 사용 가능한 창고 명령어 안내 |
| `/창고 목록` | 내 마을의 창고 이름·작동 상태·목적지 수·투입함 위치 확인 |
| `/창고 생성 <이름>` | 투입함 선택을 시작해 창고 생성 |
| `/창고 새로고침 <이름>` | 주변의 불러와진 상자와 액자를 다시 탐색 |
| `/창고 일시정지 <이름>` | 해당 창고의 자동 정리 중지 |
| `/창고 재개 <이름>` | 일시정지한 창고의 자동 정리 재개 |
| `/창고 삭제 <이름> 확인` | 자동 창고 등록 삭제. **실제 상자와 안의 아이템은 유지** |

생성·새로고침·일시정지·재개·삭제는 마을 땅 관리 권한이 필요합니다. 일시정지한 창고를 새로고침하려면 먼저 재개하세요. `/창고정리`로 입력해도 같은 명령을 사용할 수 있습니다.

## 정리가 되지 않을 때

1. `/창고 목록`에서 **작동 중인지, 목적지가 등록됐는지** 확인하세요.
2. 목적지 액자에 올바른 견본이 있고, 분류 설정을 **저장**했는지 확인하세요.
3. 바닐라 아이템인지, 견본과 이름·효과 등이 같은지 확인하세요.
4. 목적지에 빈 공간이 있는지, 다른 유저가 상자를 열고 있지 않은지 확인하세요.
5. 상자 양쪽의 마을 영역·그룹 권한·개인 잠금 상태를 확인하세요.
6. 필요한 구역 가까이에서 `/창고 새로고침 <이름>`을 실행한 뒤 투입함을 다시 열었다 닫아 보세요.

안전 점검이나 복구 안내가 계속되면 창고를 무리하게 부수거나 다시 등록하지 말고, **창고 이름과 화면에 나온 안내 문구를 운영진에게 전달**해 주세요.
