## 거래소 열기

거래소는 플레이어가 직접 가격을 정해 물품을 사고파는 공간입니다. 통합 메뉴의 **거래소** 버튼이나 `/거래소`로 열 수 있습니다.

처음 열면 두 거래 방식을 선택합니다.

- **팝니다 거래소**: 판매자가 올린 완성된 매물을 바로 구매
- **삽니다 거래소**: 구매자가 원하는 아이템과 개당 가격을 주문으로 올리고, 같은 아이템을 가진 유저가 주문에 판매

## 주요 명령어

| 명령어 | 기능 |
| --- | --- |
| `/거래소` | 팝니다·삽니다 선택 화면 열기 |
| `/거래소 팝니다` | 팝니다 거래소 바로 열기 |
| `/거래소 등록` | 주 손에 든 아이템 묶음을 팝니다 매물로 등록 |
| `/거래소 삽니다 [개당가격]` | 주 손 아이템 1개를 견본으로 삽니다 주문 입력 시작 |
| `/거래소 삽니다 <단가> <목표수량>` | 목표 수량이 정해진 삽니다 주문 등록 |
| `/거래소 삽니다 <단가> 무제한 <최대예산>` | 예산이 남는 동안 받는 삽니다 주문 등록 |
| `/거래소 내등록` | 내가 등록한 팝니다 매물 확인·취소 |
| `/거래소 내삽니다` | 내가 등록한 삽니다 주문 확인·취소 |
| `/거래소 보관함` | 구매품과 취소·만료 반환품 수령 |
| `/거래소 정산` | 판매대금과 삽니다 주문의 남은 예치금 수령 |
| `/거래소 검색 [검색어]` | 팝니다 매물을 이름으로 검색 |
| `/거래소 기록` | 내 거래 기록 확인 |
| `/거래소 도움말` | 게임 안에서 명령어 도움말 확인 |

## 공통 이용 제한

| 항목 | 현재 기준 |
| --- | ---: |
| 가격·개당 가격 | 1원~9,999,999,999원 |
| 팝니다 매물·삽니다 주문 유지 시간 | 7일 |
| 동시에 등록할 수 있는 팝니다 매물 | 최대 10개 |
| 동시에 등록할 수 있는 삽니다 주문 | 최대 10개 |
| 24시간 팝니다 신규 등록 | 최대 25회 |
| 24시간 삽니다 신규 등록 | 최대 25회 |
| 계정당 팝니다 누적 등록 | 최대 500회 |
| 계정당 삽니다 누적 등록 | 최대 500회 |
| 삽니다 목표 수량 | 1~2,304개 |
| 삽니다 최대 예산 | 최대 9,999,999,999원 |
| 판매 수수료 | 판매대금의 1% |

팝니다 매물을 구매한 경우와 삽니다 주문에 아이템을 판매한 경우 모두 판매자 정산액에서 1% 수수료가 차감됩니다.

## 팝니다: 아이템 판매하기

### 매물 등록

1. 판매할 아이템 묶음을 주 손에 듭니다.
2. `/거래소 등록`을 입력하거나 팝니다 거래소의 등록 버튼을 누릅니다.
3. 채팅에 **해당 아이템 묶음 전체의 판매 가격**을 입력합니다.
4. 확인 화면에서 아이템 이름, 수량과 총가격을 확인하고 등록을 확정합니다.
5. `/거래소 내등록`에서 남은 시간과 판매 상태를 확인합니다.

가격 입력을 시작한 뒤 60초 안에 완료해야 하며, 입력 중 손에 든 아이템이 바뀌면 등록이 취소됩니다. 등록이 끝난 물품은 거래소가 보관하므로 인벤토리에서 사라지는 것이 정상입니다.

### 매물 구매

1. 팝니다 거래소에서 원하는 매물을 선택합니다.
2. 구매 확인 화면에서 아이템, 수량과 총가격을 다시 확인합니다.
3. 구매를 확정합니다.
4. `/거래소 보관함`을 열어 구매한 아이템을 직접 수령합니다.

자신이 등록한 매물은 직접 구매할 수 없습니다.

### 판매 완료·취소·만료

- 판매가 완료되면 `/거래소 정산`에서 수수료를 제외한 판매대금을 받습니다.
- 판매 중인 매물을 취소하면 아이템이 거래소 보관함으로 이동합니다.
- 7일이 지나 만료된 매물도 거래소 보관함으로 이동합니다.

## 삽니다: 구매 주문 만들기

삽니다 주문은 원하는 아이템의 **견본 1개**를 기준으로 만듭니다. 주문을 만들 때 견본 아이템은 소비되지 않지만, 주문에 표시된 아이템과 같은 종류·이름·설명·옵션을 가진 물품만 체결할 수 있습니다.

### 목표 수량 주문

1. 원하는 아이템을 주 손에 1개 이상 듭니다.
2. `/거래소 삽니다 <단가> <목표수량>`을 입력하거나 삽니다 거래소의 등록 버튼을 누릅니다.
3. 개당 가격과 목표 수량을 확인합니다.
4. `개당 가격 × 목표 수량` 전액을 예치하고 주문을 확정합니다.

다른 유저가 한 개씩 판매해 목표 수량을 모두 채우면 주문이 완료됩니다.

### 예산 내 무제한 주문

1. 원하는 아이템을 주 손에 듭니다.
2. `/거래소 삽니다 <단가> 무제한 <최대예산>`을 입력합니다.
3. 최대 예산을 예치하고 주문을 확정합니다.

목표 개수를 정하지 않고 예산 안에서 계속 구매하며, 남은 예산이 개당 가격보다 적어지면 더 이상 체결되지 않습니다.

### 삽니다 주문에 판매하기

1. 삽니다 거래소에서 판매하려는 주문을 선택합니다.
2. 주문의 견본과 정확히 같은 아이템을 **주 손에 1개만** 듭니다.
3. 판매 확인 화면에서 개당 가격과 수수료를 확인합니다.
4. 판매를 확정합니다. 여러 개를 판매하려면 한 개씩 반복합니다.
5. 판매자는 `/거래소 정산`에서 판매대금을 받습니다.

자신이 만든 삽니다 주문에는 직접 판매할 수 없습니다.

### 구매품과 남은 예치금

- 삽니다 주문으로 구매된 아이템은 주문자의 `/거래소 보관함`에 쌓입니다.
- 주문을 취소하거나 7일이 지나 만료되면 사용하지 않은 예치금은 **환불금 정산 대기**로 이동합니다.
- 남은 예치금은 지갑에 자동으로 들어오지 않으므로 `/거래소 정산`에서 직접 받아야 합니다.

## 등록할 수 없는 물품

- 상자·셜커 상자처럼 내부에 다른 아이템을 담을 수 있는 물품
- 아이템 설명에 **거래불가**가 표시된 물품
- 거래소 등록 화면에서 거절되는 특수 물품

이름만 같은 아이템이라도 내구도, 설명, 인챈트와 추가 옵션이 다를 수 있습니다. 팝니다 구매 화면과 삽니다 판매 화면에서 실제 아이템 정보를 확인한 뒤 확정하세요.

## 보관함과 정산

구매한 물품과 취소·만료되어 반환되는 물품은 바로 인벤토리에 들어오지 않고 **거래소 보관함**으로 이동합니다. `/거래소 보관함`을 열어 직접 수령하세요.

보관함에서 안전하게 수령하려면 일반 인벤토리에 빈칸이 1개 이상 필요합니다.

팝니다 판매대금, 삽니다 주문에 판매한 대금, 취소·만료된 삽니다 주문의 남은 예치금은 자동으로 지갑에 들어오지 않습니다. `/거래소 정산`에서 한꺼번에 받을 수 있습니다.

## 기본 이용 순서

1. `/거래소`에서 팝니다 또는 삽니다를 선택합니다.
2. 거래 전에 아이템, 수량, 총가격 또는 개당 가격을 확인합니다.
3. 판매자는 `/거래소 내등록`과 `/거래소 내삽니다`에서 주문 상태를 확인합니다.
4. 아이템은 `/거래소 보관함`, 돈과 예치금 환불은 `/거래소 정산`에서 받습니다.
5. 7일 만료 전에 내 주문을 확인하고 보관함과 정산 목록을 주기적으로 비웁니다.
