## 거래소 이용 전 준비

거래소는 플레이어가 직접 가격을 정해 물품을 사고파는 공간입니다. 통합 메뉴의 **거래소** 버튼이나 `/거래소`로 열 수 있습니다.

거래소를 이용하려면 **마인리스트 또는 마인보드에서 당일 서버 추천**을 완료해야 합니다. 추천 보상은 [상점 이용법](/guide/basic/shop#서버-추천과-보상)에서 확인하세요.

## 주요 명령어

| 명령어 | 기능 |
| --- | --- |
| `/거래소` | 거래소 메인 화면 열기 |
| `/거래소 등록` | 손에 든 아이템을 판매 물품으로 등록 |
| `/거래소 내등록` | 내가 현재 판매 중인 물품 확인 |
| `/거래소 보관함` | 구매·취소·만료된 물품 수령 |
| `/거래소 정산` | 판매가 끝난 물품의 판매대금 수령 |
| `/거래소 검색` | 이름으로 판매 물품 검색 |
| `/거래소 기록` | 내 거래 기록 확인 |
| `/거래소 도움말` | 게임 안에서 명령어 도움말 확인 |

## 판매 등록 제한

| 항목 | 현재 기준 |
| --- | ---: |
| 판매 유지 시간 | 7일 |
| 동시에 판매할 수 있는 물품 | 최대 10개 |
| 24시간 동안 등록할 수 있는 횟수 | 최대 25회 |
| 판매 수수료 | 판매금액의 1% |

수수료는 거래가 성사됐을 때 판매대금에서 차감됩니다. 판매 가격을 정할 때 실제 정산 금액이 등록 가격보다 적다는 점을 고려하세요.

## 등록할 수 없는 물품

- 상자·셜커 상자처럼 내부에 다른 아이템을 담을 수 있는 물품
- 아이템 설명에 **거래불가**가 표시된 물품
- 거래소 등록 화면에서 거절되는 특수 물품

판매할 아이템의 이름, 수량, 내구도, 옵션을 확인한 뒤 등록하세요. 등록 완료 후에는 구매자가 보는 물품과 가격을 다시 확인하는 것이 안전합니다.

## 보관함과 정산

구매한 물품과 취소·만료되어 반환되는 물품은 바로 인벤토리에 들어오지 않고 **거래소 보관함**으로 이동합니다. `/거래소 보관함`을 열어 직접 수령하세요.

판매가 완료된 뒤 받을 돈도 자동으로 지갑에 들어오지 않습니다. `/거래소 정산`에서 판매 내역을 확인하고 대금을 받아야 합니다.

## 추천 이용 순서

1. 당일 서버 추천을 완료합니다.
2. 판매할 아이템을 주 손에 들고 `/거래소 등록`을 입력합니다.
3. 수량과 가격을 확인해 등록합니다.
4. `/거래소 내등록`에서 판매 상태와 남은 시간을 확인합니다.
5. 판매 후에는 `/거래소 정산`, 취소·만료 후에는 `/거래소 보관함`을 확인합니다.

7일이 지난 물품은 자동으로 판매 목록에서 내려가므로 보관함을 주기적으로 정리하세요.
