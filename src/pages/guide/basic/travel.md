## 개인 홈

| 명령어 | 기능 |
| --- | --- |
| `/sethome [이름]` | 현재 위치를 개인 홈으로 저장 |
| `/home [이름]` | 저장한 개인 홈으로 이동 |
| `/homes` | 내 홈 목록 확인 |
| `/delhome <이름>` | 저장한 홈 삭제 |

홈 이름은 한글, 영문, 숫자, `_`, `-`를 사용해 16자까지 지정할 수 있습니다. 이름을 생략하면 `home`으로 저장됩니다.

기본 개인 홈은 1개입니다. 츄르냥은 총 3개, 골드츄르냥은 총 4개, 로얄츄르냥은 총 5개까지 설정할 수 있습니다.

## 공개 홈

- `/phome 설정` — 현재 위치를 공개 홈으로 등록
- `/phome 삭제` — 공개 홈 삭제
- `/phome 방문` — 공개 홈 방문
- `/phomelist` — 공개 홈 목록 GUI 열기

기본 공개 홈은 1개이며 츄르냥 이상은 최대 2개까지 사용할 수 있습니다.

## 이전 위치로 돌아가기

`/back`은 직전 텔레포트 위치로 돌아갑니다. 현재 설정상 츄르냥 이상 등급 혜택에 포함됩니다.

## 랜덤 이동

`/rtp`는 마을 1~6과 야생 1~6에서 안전한 무작위 위치를 찾습니다.

| 항목 | 현재 설정 |
| --- | --- |
| 이동 범위 | X/Z -5,000 ~ 5,000 |
| 일반 재사용 시간 | 3,600초 (60분) |
| 츄르냥 재사용 시간 | 180초 (3분) |
| 물 위 도착 | 임시 보트에 자동 탑승 |

## 엘리베이터

같은 X/Z 좌표에 층을 만들고 **점프하면 위층**, **웅크리면 아래층**으로 이동하는 방식입니다. 한 번에 탐색하는 최대 층 높이는 40블록이고, 재사용 대기시간은 0.5초입니다.

지원되는 바닥 조합은 다음과 같습니다.

- 위 빨간색 양탄자 / 아래 파란색 양털
- 위 석영 블록 / 아래 레드스톤 블록
- 위 석영 반 블록 / 아래 철 블록

현재 설정상 엘리베이터는 츄르냥 이상 등급 혜택에 포함됩니다.
