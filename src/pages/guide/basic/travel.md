## 개인 홈

| 명령어 | 기능 |
| --- | --- |
| `/sethome [이름]` | 현재 위치를 개인 홈으로 저장 |
| `/home [이름]` | 저장한 개인 홈으로 이동 |
| `/homes` | 내 홈 목록 확인 |
| `/delhome <이름>` | 저장한 홈 삭제 |

홈 이름은 한글, 영문, 숫자, `_`, `-`를 사용해 16자까지 지정할 수 있습니다. 이름을 생략하면 `home`으로 저장됩니다.

기본 개인 홈은 1개입니다. 츄르냥은 총 3개, 골드츄르냥은 총 4개, 로얄츄르냥은 총 5개까지 설정할 수 있습니다.

## 공개 홈

- `/phome 설정 <이름>` — 현재 위치를 해당 이름의 공개 홈으로 등록
- `/phome 삭제` — 공개 홈 삭제
- `/phome 방문` — 공개 홈 방문
- `/phomelist` — 공개 홈 목록 GUI 열기

기본 공개 홈은 1개이며 츄르냥 이상은 최대 2개까지 사용할 수 있습니다.

## 이전 위치로 돌아가기

`/back`은 직전 텔레포트 위치로 돌아갑니다. 현재 설정상 츄르냥 이상 등급 혜택에 포함됩니다.

## 랜덤 이동

`/rtp`는 마을 1~6과 야생 1~6에서 안전한 무작위 위치를 찾습니다.

| 항목 | 현재 설정 |
| --- | --- |
| 이동 범위 | X/Z -5,000 ~ 5,000 |
| 일반 재사용 시간 | 3,600초 (60분) |
| 츄르냥 재사용 시간 | 180초 (3분) |
| 물 위 도착 | 임시 보트에 자동 탑승 |

## 상점 택시

스폰에 있는 **상점택시**를 우클릭하면 상점으로 바로 이동합니다.

- 이동 비용과 별도 명령어가 없습니다.
- 택시 설명에 `우클릭하면 상점으로 이동`이 표시됩니다.
- 연속해서 누를 때는 약 1.5초의 간격이 필요합니다.

## 엘리베이터

특정 블록 조합을 같은 X/Z 좌표에 설치하면 층 사이를 빠르게 이동할 수 있습니다.

![츄르월드 엘리베이터의 세 가지 블록 조합](/assets/guides/elevator-blocks.png)

*왼쪽부터 빨간색 양탄자와 파란색 양털, 석영 블록과 레드스톤 블록, 석영 반 블록과 철 블록 조합입니다.*

### 설치 가능한 블록 조합

| 위쪽 블록 | 아래쪽 블록 |
| --- | --- |
| 빨간색 양탄자 | 파란색 양털 |
| 석영 블록 | 레드스톤 블록 |
| 석영 반 블록 | 철 블록 |

### 설치 방법

1. 위 표에 있는 조합 중 하나로 출발 층의 엘리베이터를 설치합니다.
2. 출발 지점과 **같은 X/Z 좌표**의 다른 층에 동일한 조합을 설치합니다.
3. 이동하려면 출발 지점과 도착 지점을 포함해 **엘리베이터가 2개 이상** 있어야 합니다.
4. 한 층 사이의 높이는 최대 **40블록**까지 가능합니다.

### 사용 방법

- 엘리베이터 위에서 **점프**하면 위층으로 이동합니다.
- 엘리베이터 위에서 **Shift(웅크리기)**를 누르면 아래층으로 이동합니다.
- 재사용 대기시간은 **0.5초**입니다.

현재 설정상 엘리베이터는 **츄르냥 이상 등급 혜택**에 포함됩니다. 이용 권한이 없으면 올바르게 설치해도 작동하지 않습니다.

## 서버 기능 블록

아래 기능은 운영진이 서버 시설에 설치한 **특수 기능 블록**에서만 작동합니다. 같은 종류의 일반 블록을 직접 놓아도 기능 블록이 되지 않습니다.

| 기능 블록 | 바닥 모양 | 밟았을 때 효과 | 낙하 피해 보호 |
| --- | --- | --- | --- |
| 점프대 | 슬라임 블록 | 위쪽으로 높이 도약 | 해당 도약에서 1회 보호 |
| 부스터블럭 | 금 블록 | 바라보는 수평 방향으로 빠르게 이동 | 보호 없음 |
| 도약부스터 | 꿀 블록 | 위쪽과 바라보는 방향으로 함께 도약 | 해당 도약에서 1회 보호 |

기능 블록은 밟으면 자동으로 작동합니다. 부스터블럭과 도약부스터는 바라보는 방향을 기준으로 이동하므로, 올라가기 전에 진행 방향을 확인하세요.
