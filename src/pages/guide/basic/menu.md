## 메뉴 여는 방법

- 단축키: **Shift + F**
- 명령어: `/메뉴` 또는 `/menu`

통합 메뉴는 서버의 주요 기능으로 들어가는 중앙 허브입니다. 메인, 마을, 전투 탭으로 나뉘며 전투 탭에서 **더 타워**와 **잔향록**을 이용할 수 있습니다. 무협 RPG는 준비 중입니다.

아래 설명은 **최신 츄르월드 전용 클라이언트** 기준입니다. 런처를 업데이트한 뒤 게임을 완전히 종료하고 다시 실행하세요. 웅크리기나 보조 손 교체 키를 바꿨다면 `Shift + F` 대신 바꾼 키 조합을 사용합니다.

처음 접속했다면 [안내 맵](/guide/basic/tutorial)을 확인한 뒤 앞으로 이동해 NPC를 눌러 츄르월드로 출발하세요.

## 메뉴 안에서 이동하기

- 버튼을 클릭해 기능을 열고, **뒤로** 또는 `Backspace`로 상위 메뉴에 돌아갑니다.
- **닫기** 또는 `Esc`는 메뉴를 닫습니다.
- `Tab`·방향키로 항목을 선택하고 `Enter`·`Space`로 실행할 수도 있습니다.
- 여러 페이지가 있는 목록은 화살표로 넘기세요. 생활 직업·스킬의 긴 설명은 본문이나 스크롤바를 끌거나 마우스 휠로 읽을 수 있습니다.

기존 인벤토리 메뉴를 쓰려면 `/churumenu legacy`, 새 메뉴로 돌아오려면 `/churumenu modern`을 입력하세요. 전용 모드가 없거나 오래된 경우에는 기존 메뉴가 표시될 수 있습니다.

## 메인 기능

| 메뉴 | 연결되는 기능 |
| --- | --- |
| 생활 | 생활 직업·스킬과 생산 메뉴 |
| 내정보 | 코디·칭호 등 개인 메뉴 |
| 의뢰 | 현재 이용 가능한 `/의뢰` 목록 |
| 워프 | 야생, 지옥, 엔더, 스폰 이동 |
| 거래소 | 판매 물품과 구매 주문을 함께 이용하는 유저 거래소 |
| 후원상점 | 후원 상점 열기 |
| 상점 | 요리·농부·잡화·건축·어부·광부·희귀 자원 원격 상점 선택. 로얄츄르냥 전용 |
| 위키 | 현재 보고 있는 공식 위키 열기 |
| 디스코드 · 추천 | 공식 디스코드와 서버 추천 페이지 열기 |
| 길라잡이 | `/길라잡이` 메뉴 |
| 가방 | `/가방` 열기 |
| 우편함 | `/우편함` 열기 |
| 도감 | 생활·생존·기타·방어구 도감 열기 |
| 쓰레기통 | 버릴 아이템을 넣는 전용 창 |
| 설정 | 스폰 BGM·키보드 설정 |

## 생활과 내정보

생활은 **메인 왼쪽의 생활 버튼**에서 엽니다. 직업이나 스킬을 고른 뒤 오른쪽 설명과 효과를 확인하고 투자하세요. 자세한 육성 방법은 [생활 성장 안내](/life/growth)를 확인하세요.

내정보에서는 코디·칭호 등 개인 메뉴를 엽니다. 준비 중으로 표시된 항목은 아직 이용할 수 없습니다.

## 워프 메뉴

워프 메뉴에는 야생 1~6, 지옥 1~3, **엔더 1**, 스폰 이동이 연결되어 있습니다. 지옥과 엔더는 공용 레벨 조건이 있으므로 [월드 안내](/map)를 먼저 확인하세요.

월드 사이의 일반 포탈 이동은 막혀 있습니다. 지옥과 엔더를 포함한 월드 이동은 **Shift + F 통합 메뉴의 워프 버튼**을 이용하세요.

## 마을 탭

마을 탭에서는 마을 1~6의 등록 위치를 선택합니다. 하단의 위키, 디스코드, 길라잡이, 가방, 우편함, 쓰레기통, 설정은 메인 탭과 동일하게 사용할 수 있습니다.

자기 마을을 관리하려면 `/마을`을 입력하세요. 마을원·초대·손님·경작지·땅과 그룹·설정·세금·조공 등을 메뉴에서 선택할 수 있습니다. **뒤로**로 마을 메뉴에 돌아오고, 마을 메인에서 다시 뒤로 가면 통합 메뉴가 열립니다.

다른 마을을 둘러보려면 `/마을 목록`을 이용하세요. 공개 설정과 방문·손님 초대의 차이는 [마을 안내](/guide/basic/village#공개-마을-방문)에 정리되어 있습니다.

## 키보드 설정

설정 메뉴의 **키보드 설정** 또는 `/키보드`로 엽니다. `/키보드 세팅`도 사용할 수 있습니다.

1. 기능 이름을 검색하거나 키보드 그림에서 키를 선택합니다.
2. 바꿀 기능의 현재 키 버튼을 누르고 새 키나 마우스 버튼을 입력합니다. `Esc`로 입력을 취소할 수 있습니다.
3. **적용**을 눌러 저장합니다. 적용 전에 닫으면 변경을 버릴지 확인합니다.

- **해제**는 키 지정을 비우고, **기본**은 해당 기능의 기본 키로 되돌립니다.
- 주황색은 키가 겹친다는 뜻입니다. 사용 상황이 다른 기능은 같은 키를 써도 문제가 없을 수 있습니다.
- 직접 지정한 개인 키는 업데이트 후에도 유지됩니다. 안내와 키가 다르면 여기에서 현재 지정을 확인하세요.

기본 지도·비행·채팅 단축키는 [HUD와 채팅 설정](/guide/basic/hud#자주-쓰는-단축키)에서 확인할 수 있습니다.

## 전투 탭

| 메뉴 | 현재 상태 | 안내 |
| --- | --- | --- |
| 더 타워 | 이용 가능 | 1~4인 30층 전투 콘텐츠. [더 타워 안내](/combat/tower) |
| 잔향록 | 이용 가능 | 행동·원정·전투를 진행하는 서버 판정형 RPG. [잔향록 안내](/combat/echoes) |
| 무협 RPG | 준비 중 | 정식 공개 전까지 이용할 수 없음 |

더 타워와 잔향록의 전용 화면을 정상적으로 사용하려면 최신 츄르월드 전용 클라이언트가 필요합니다.

## 알아둘 점

- 메뉴에서 기능을 선택하면 GUI가 닫히고 명령어 또는 이동이 실행될 수 있습니다.
- **상점** 버튼은 현재 로얄츄르냥 이상에게만 열리며, **후원상점**은 별도 메뉴입니다.
- 아이템을 실수로 버리지 않도록 쓰레기통은 확인 후 사용하세요.
- 스폰 BGM은 설정 메뉴에서 켜고 끌 수 있습니다.
- 화면 배치와 상단 정보창·채팅 글자 크기는 `J`키에서 조절합니다. [HUD와 채팅 설정](/guide/basic/hud)을 확인하세요.
