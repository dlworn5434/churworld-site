## 코디 보관함

`/코디`를 입력하거나 통합 메뉴의 **내 정보 → 코디**에서 보유한 치장품을 확인할 수 있습니다.

| 분류 | 예시 |
| --- | --- |
| 모자 | 머리에 표시되는 치장품 |
| 등 장식 | 날개와 가방처럼 등에 표시되는 치장품 |
| 왼손 | 왼손 주변에 표시되는 장식 |
| 풍선 | 플레이어를 따라다니는 풍선형 장식 |
| 이펙트 | 몸 주변이나 이동 경로에 표시되는 효과 |

보유한 코디만 착용할 수 있으며 같은 부위의 코디를 바꾸면 이전 코디가 해제됩니다. 전용 클라이언트를 사용하면 캐릭터 미리보기가 포함된 코디 화면이 열리고, 미리보기 기능을 사용할 수 없는 환경에서는 기본 보관함 화면으로 열립니다.

## 코디 뽑기

`/코디뽑기`에서 뽑기권을 사용해 코디 또는 도구 스킨을 획득할 수 있습니다.

- 일반 코디 뽑기: 모자, 등 장식, 왼손 장식과 이펙트 획득
- 도구 스킨 뽑기: 기존 치장품과 분리된 도구 외형 획득
- 10회 뽑기: 뽑기권 10회분을 사용해 총 11개 획득
- 10회 보너스 1개는 희귀 등급 이상
- 이미 보유한 일반 코디가 나오면 등급에 맞는 마일리지 획득
- 도구 스킨은 1회에 뽑기권 3장, 10회에 30장 사용

현재 뽑기권 가격과 판매 여부는 [상점과 거래](/guide/basic/shop)에서 확인하세요. 뽑기 구성은 바뀔 수 있으므로 최종 사용 전 `/코디뽑기` 화면의 설명을 기준으로 확인하는 것이 가장 정확합니다.

## 안전하게 이용하기

- 장착 중인 코디와 새로 획득한 코디는 `/코디`에서 다시 확인할 수 있습니다.
- 뽑기 전에 필요한 뽑기권 수량과 선택한 뽑기 종류를 확인하세요.
- 코디는 능력치를 높이는 장비가 아니라 캐릭터 외형을 꾸미는 콘텐츠입니다.
