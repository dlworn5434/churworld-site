## 코디 보관함

`/코디`를 입력하거나 통합 메뉴의 **내 정보 → 코디**에서 보유한 치장품을 확인할 수 있습니다.

| 분류 | 예시 |
| --- | --- |
| 모자 | 머리에 표시되는 치장품 |
| 등 장식 | 날개와 가방처럼 등에 표시되는 치장품 |
| 왼손 | 왼손 주변에 표시되는 장식 |
| 풍선 | 플레이어를 따라다니는 풍선형 장식 |
| 이펙트 | 몸 주변이나 이동 경로에 표시되는 효과 |
| 도구 스킨 | 호환되는 무기·도구의 외형 |
| 방어구 스킨 | 호환되는 투구·흉갑·각반·장화의 외형 |

보유한 코디만 착용할 수 있으며 같은 부위의 코디를 바꾸면 이전 코디가 해제됩니다. 전용 클라이언트를 사용하면 캐릭터 미리보기가 포함된 코디 화면이 열리고, 미리보기 기능을 사용할 수 없는 환경에서는 기본 보관함 화면으로 열립니다.

## 코디 뽑기

`/코디뽑기`에서 뽑기권을 사용해 원하는 종류의 뽑기를 선택할 수 있습니다.

| 뽑기 | 1회 | 10회 | 주요 결과 |
| --- | ---: | ---: | --- |
| 츄르월드 코디 뽑기 | 1장 | 10장 | 모자, 등 장식, 왼손 장식, 이펙트 |
| 도구 스킨 뽑기 | 3장 | 30장 | 호환되는 무기·도구 스킨 |
| 방어구 스킨 뽑기 | 2장 | 20장 | 투구·흉갑·각반·장화 스킨 |

10회 뽑기는 보너스 1개를 포함해 총 11개를 획득하며, 보너스는 희귀 등급 이상입니다. 이미 보유한 일반 코디가 나오면 등급에 맞는 마일리지를 받고, 도구·방어구 스킨은 같은 스킨을 여러 개 보관할 수 있습니다.

현재 뽑기권 가격과 판매 여부는 [상점과 거래](/guide/basic/shop)에서 확인하세요. 뽑기 구성은 바뀔 수 있으므로 최종 사용 전 `/코디뽑기` 화면의 설명을 기준으로 확인하는 것이 가장 정확합니다.

## 도구·방어구 스킨 적용

획득한 스킨은 계정 보관함에 저장됩니다. `/코디`를 열고 스킨을 적용할 장비를 주 손에 든 뒤, 장비와 호환되는 스킨을 선택하세요. 스킨 1개가 보관함에서 사용되고 장비의 외형이 바뀝니다.

- 장비의 능력치, 인챈트, 이름과 현재 내구도는 그대로 유지됩니다.
- 스킨이 적용된 동안에는 장비 내구도가 감소하지 않습니다.
- 모루나 대장장이 작업대를 사용해도 결과 장비가 호환되면 스킨 외형이 이어집니다.
- 이미 다른 커스텀 외형이 있는 장비는 기존 외형을 먼저 복구하거나 추출해야 합니다.
- 삼지창 모양 스킨을 적용해도 원래 장비에 투척 기능이 생기지는 않습니다.

화면에 표시되는 **적용 대상**을 확인하세요. 예를 들어 곡괭이용 스킨은 검이나 방어구에 적용할 수 없습니다.

| 스킨 시리즈 | 적용 대상 |
| --- | --- |
| 벚꽃 정령 | 도구 16종, 방어구 4부위 |
| 신성한 제피르 | 도구 16종, 방어구 4부위 |
| 사이버 룬 | 도구 16종, 방어구 4부위 |
| 애니멀 | 도구 6종 |

같은 시리즈라도 스킨마다 적용할 수 있는 장비가 다를 수 있으므로 `/코디` 화면의 **적용 대상** 표시를 최종 기준으로 확인하세요.

## 스킨 확인·복구·추출

| 방법 | 기능 |
| --- | --- |
| `/코디 skin 목록` | 계정 보관함의 도구·방어구 스킨과 수량 확인 |
| `/코디 skin 복구` | 주 손에 든 스킨 장비를 원래 외형으로 복구 |
| 스킨 추출권 | 장비 외형을 복구하고 적용돼 있던 스킨을 계정 보관함에 저장 |

스킨 추출권은 일반 인벤토리에서 커서로 집어 스킨 장비 위에 좌클릭해 사용합니다.

## 마일리지 상점

`/코디뽑기 상점`에서 마일리지로 일반 코디를 선택해 구매할 수 있습니다.

| 등급 | 가격 |
| --- | ---: |
| 일반 | 51 마일리지 |
| 희귀 | 120 마일리지 |
| 영웅 | 450 마일리지 |
| 전설 | 1,100 마일리지 |

이미 보유한 일반 코디는 다시 구매할 수 없습니다. 보유 마일리지와 구매 가능한 코디는 상점 화면에서 확인하세요.

## 안전하게 이용하기

- 장착 중인 코디와 새로 획득한 코디는 `/코디`에서 다시 확인할 수 있습니다.
- 뽑기 전에 필요한 뽑기권 수량과 선택한 뽑기 종류를 확인하세요.
- 코디는 능력치를 높이는 장비가 아니라 캐릭터 외형을 꾸미는 콘텐츠입니다.
