## 어떤 상점을 써야 하나요?

| 종류 | 용도 | 여는 방법 |
| --- | --- | --- |
| 생활 분야 상점 | 서버가 준비한 물품 구매·판매 | 통합 메뉴 → **상점** |
| 후원상점 | 츄르 잔액으로 상품 구매 | 통합 메뉴 → **후원상점** |
| 유저 거래소 | 플레이어끼리 물품 등록·거래 | 통합 메뉴 → **거래소**, `/거래소` |
| 물물교환·작물교환 | 아이템끼리 정해진 비율로 교환 | `/물물교환`, `/작물교환` |

거래소의 등록 제한과 정산 방법은 [유저 거래소](/guide/basic/marketplace), 물물교환과 츄르 ATM은 [재화와 교환](/guide/basic/economy)에서 자세히 확인할 수 있습니다.

## 생활 분야 원격 상점

통합 메뉴의 **상점** 버튼에서는 다음 7종의 상점을 선택할 수 있습니다.

| 상점 | 이용 내용 |
| --- | --- |
| 요리 상점 | 완성한 요리 판매 |
| 농부 상점 | 농작물 구매·판매 |
| 잡화 상점 | 농산물·생선·몬스터 전리품 판매. 품목별 일일 판매 제한 적용 |
| 건축 상점 | 일반 블록부터 장식 블록까지 건축 자재 구매 |
| 어부 상점 | 낚시로 얻은 물품 판매 |
| 광부 상점 | 채광으로 얻은 광물 판매 |
| 희귀 자원 상점 | 커스텀 목재와 광물을 고정 가격으로 판매. 품목별 일일 판매 제한 적용 |

원격 상점은 로얄츄르냥 전용 편의 기능입니다. 이용 조건과 다른 혜택은 [츄르냥 멤버십](/support/membership)에서 확인하세요.

건축 상점에는 322종의 건축 자재가 준비되어 있습니다. 품목이 많으므로 필요한 블록은 게임 안의 페이지를 넘겨 확인하세요.

### 상점 클릭 조작

| 조작 | 구매 상점 | 판매 상점 |
| --- | --- | --- |
| 좌클릭 | 1배 수량 구매 | 1배 수량 판매 |
| 우클릭 | 16배 수량 구매 | 16배 수량 판매 |
| Shift + 좌클릭 | 64배 수량 구매 | 64배 수량 판매 |
| Shift + 우클릭 | — | 인벤토리에 있는 해당 상품 전체 판매 |

판매 상점에는 **현재 페이지 전체 판매** 버튼도 있습니다. 누르면 현재 페이지에 표시된 판매 가능 품목을 인벤토리에서 찾아 한꺼번에 판매하므로, 남겨 둘 재료가 있다면 먼저 보관하세요.

### 요리 판매 시세

요리 판매가는 최근 판매량에 따라 변동합니다. 현재 기준 가격에서 **최대 10% 상승하거나 20% 하락**할 수 있습니다. 여러 개를 한꺼번에 팔 때도 16개 단위로 시세가 다시 계산되므로, 판매 버튼에 표시되는 최종 결제액을 확인하세요.

### 일일 판매 제한

잡화 상점과 희귀 자원 상점의 일부 품목은 플레이어별 일일 판매량이 정해져 있습니다. 한도는 품목마다 따로 계산됩니다.

| 상점 | 품목 | 하루 판매 한도 |
| --- | --- | ---: |
| 잡화 | 수박, 호박, 달콤한 열매, 당근, 감자, 비트 | 품목별 160개 |
| 잡화 | 대구, 열대어, 연어 | 품목별 32개 |
| 잡화 | 뼈, 거미 눈, 썩은 살점 | 품목별 160개 |
| 희귀 자원 | 나뭇가지 | 256개 |
| 희귀 자원 | 커스텀 원목 | 128개 |
| 희귀 자원 | 원목 묶음 | 32개 |
| 희귀 자원 | 기어 브론즈 주괴 | 128개 |
| 희귀 자원 | 코어 스틸 주괴 | 64개 |
| 희귀 자원 | 심연 프리즘 주괴 | 16개 |

희귀 자원 상점의 판매 단가는 다음과 같습니다.

| 품목 | 1개 판매 가격 |
| --- | ---: |
| 나뭇가지 | 5원 |
| 커스텀 원목 | 20원 |
| 원목 묶음 | 150원 |
| 기어 브론즈 주괴 | 15원 |
| 코어 스틸 주괴 | 45원 |
| 심연 프리즘 주괴 | 180원 |

남은 판매량은 각 상품 설명에서 확인할 수 있습니다.

## 후원상점

후원상점은 통합 메뉴에서 열 수 있으며 계정에 보관되는 **츄르 잔액**을 사용합니다.

| 상품 | 가격 |
| --- | ---: |
| 루비 | 2,000 츄르 |
| 토파즈 | 3,000 츄르 |
| 아쿠아마린 | 5,000 츄르 |
| 츄르월드 코디 뽑기권 | 2,000 츄르 |
| 프리미엄 잠수 의자 구매권 | 20,000 츄르 |
| 낚시 감각 고정 주사기 | 5,000 츄르 |
| 츄르냥 30일 이용권 | 5,000 츄르 |
| 골드츄르냥 30일 이용권 | 10,000 츄르 |
| 로얄츄르냥 30일 이용권 | 20,000 츄르 |
| 각인 제거서 | 5,000 츄르 |
| 생활 기억의 서 | 10,000 츄르 |
| 공용 초심의 서 | 10,000 츄르 |
| 스탯 재분배 주문서 | 5,000 츄르 |
| 강화 하락 방지권 | 5,000 츄르 |

루비·토파즈·아쿠아마린은 마을 조공에 사용할 수 있습니다. 상품 구성과 가격은 변경될 수 있으므로 구매 직전 상점 화면을 최종 기준으로 확인하세요.

## 츄르 코인과 충전 코인의 차이

- **츄르 코인**: 인벤토리에 보관되는 실물 아이템입니다. 가방 확장과 일부 물물교환 등에 사용합니다.
- **츄르 충전 코인**: 표시된 금액만큼 계정의 츄르 잔액을 충전하는 사용 아이템입니다.
- **츄르 잔액**: 후원상점에서 결제할 때 사용하는 계정 재화입니다.

아이템 이름이 비슷하므로 거래하거나 사용하기 전에 설명과 표시 금액을 확인하세요.

## 서버 추천과 보상

각 추천 사이트는 하루에 한 번씩 추천 보상을 받을 수 있습니다. 추천 여부와 관계없이 유저 거래소는 이용할 수 있습니다.

| 추천 1회 보상 | 수량 |
| --- | ---: |
| 게임 머니 | 500원 |
| 경험치 병 | 16개 |
| 츄르 코인 | 2개 |
| 100 츄르 충전 코인 | 1개 |
| 마을 플라이권 5분 | 1개 |
| 추천상자 | 1개 |
| 로얄츄르냥 이용권 | 2일 |
| 츄르월드 코디 뽑기권 | 1개 |

마을 플라이권은 마을 안에서 우클릭하면 비행 시간 5분이 추가됩니다. 추천 후 보상 반영까지 잠시 걸릴 수 있으므로 추천한 계정과 현재 접속 중인 계정을 확인하세요.
