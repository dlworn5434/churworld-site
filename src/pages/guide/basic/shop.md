## 어떤 상점을 써야 하나요?

| 종류 | 용도 | 여는 방법 |
| --- | --- | --- |
| 생활 분야 상점 | 서버가 준비한 물품 구매·판매 | 통합 메뉴 → **상점** |
| 후원상점 | 츄르 잔액으로 상품 구매 | 통합 메뉴 → **후원상점** |
| 유저 거래소 | 플레이어끼리 물품 등록·거래 | 통합 메뉴 → **거래소**, `/거래소` |
| 물물교환·작물교환 | 아이템끼리 정해진 비율로 교환 | `/물물교환`, `/작물교환` |

거래소의 등록 제한과 정산 방법은 [유저 거래소](/guide/basic/marketplace), 물물교환과 츄르 ATM은 [재화와 교환](/guide/basic/economy)에서 자세히 확인할 수 있습니다.

## 생활 분야 원격 상점

통합 메뉴의 **상점** 버튼에서는 다음 7종의 상점을 선택할 수 있습니다.

| 상점 | 이용 내용 |
| --- | --- |
| 요리 상점 | 완성한 요리 판매 |
| 농부 상점 | 농작물 구매·판매 |
| 잡화 상점 | 농산물·생선·몬스터 전리품 판매. 품목별 일일 판매 제한 적용 |
| 건축 상점 | 일반 블록부터 장식 블록까지 건축 자재 구매 |
| 어부 상점 | 낚시로 얻은 물품 판매 |
| 광부 상점 | 채광으로 얻은 광물 판매 |
| 희귀 자원 상점 | 커스텀 목재와 광물을 고정 가격으로 판매. 품목별 일일 판매 제한 적용 |

원격 상점은 로얄츄르냥 전용 편의 기능입니다. 이용 조건과 다른 혜택은 [츄르냥 멤버십](/support/membership)에서 확인하세요.

### 상점 클릭 조작

| 조작 | 구매 상점 | 판매 상점 |
| --- | --- | --- |
| 좌클릭 | 1배 수량 구매 | 1배 수량 판매 |
| 우클릭 | 16배 수량 구매 | 16배 수량 판매 |
| Shift + 좌클릭 | 64배 수량 구매 | 64배 수량 판매 |
| Shift + 우클릭 | — | 인벤토리에 있는 해당 상품 전체 판매 |

판매 상점에는 **현재 페이지 전체 판매** 버튼도 있습니다. 누르면 현재 페이지에 표시된 판매 가능 품목을 인벤토리에서 찾아 한꺼번에 판매하므로, 남겨 둘 재료가 있다면 먼저 보관하세요.

### 요리 판매 시세

요리 판매가는 최근 판매량에 따라 변동합니다. 현재 기준 가격에서 **최대 10% 상승하거나 10% 하락**할 수 있으므로, 판매 버튼에 표시되는 실제 단가를 확인하세요.

## 후원상점

후원상점은 통합 메뉴에서 열 수 있으며 계정에 보관되는 **츄르 잔액**을 사용합니다.

| 상품 | 가격 |
| --- | ---: |
| 루비 | 2,000 츄르 |
| 토파즈 | 3,000 츄르 |
| 아쿠아마린 | 5,000 츄르 |
| 츄르월드 코디 뽑기권 | 2,000 츄르 |
| 프리미엄 잠수 의자 구매권 | 20,000 츄르 |
| 낚시 감각 고정 주사기 | 5,000 츄르 |
| 츄르냥 30일 이용권 | 5,000 츄르 |
| 골드츄르냥 30일 이용권 | 10,000 츄르 |
| 로얄츄르냥 30일 이용권 | 20,000 츄르 |
| 각인 제거서 | 5,000 츄르 |
| 생활 기억의 서 | 10,000 츄르 |
| 공용 초심의 서 | 10,000 츄르 |

루비·토파즈·아쿠아마린은 마을 조공에 사용할 수 있습니다. 상품 구성과 가격은 변경될 수 있으므로 구매 직전 상점 화면을 최종 기준으로 확인하세요.

## 츄르 코인과 충전 코인의 차이

- **츄르 코인**: 인벤토리에 보관되는 실물 아이템입니다. 가방 확장과 일부 물물교환 등에 사용합니다.
- **츄르 충전 코인**: 표시된 금액만큼 계정의 츄르 잔액을 충전하는 사용 아이템입니다.
- **츄르 잔액**: 후원상점에서 결제할 때 사용하는 계정 재화입니다.

아이템 이름이 비슷하므로 거래하거나 사용하기 전에 설명과 표시 금액을 확인하세요.

## 서버 추천과 보상

유저 거래소를 이용하려면 **마인리스트 또는 마인보드에서 당일 서버 추천**을 완료해야 합니다. 각 추천 사이트는 하루에 한 번씩 추천 보상을 받을 수 있습니다.

| 추천 1회 보상 | 수량 |
| --- | ---: |
| 게임 머니 | 500원 |
| 경험치 병 | 16개 |
| 츄르 코인 | 2개 |
| 100 츄르 충전 코인 | 1개 |

추천 후 반영까지 잠시 걸릴 수 있습니다. 거래소가 열리지 않는다면 추천한 계정과 현재 접속 중인 계정을 확인한 뒤 다시 시도하세요.
