## 의뢰 시작하기

`/의뢰`를 입력하거나 통합 메뉴의 **의뢰** 버튼을 누르면 현재 의뢰를 확인할 수 있습니다. 의뢰는 생활 활동을 하며 자연스럽게 달성하는 반복 목표입니다.

| 구분 | 한 번에 표시되는 의뢰 |
| --- | ---: |
| 일일 의뢰 | 9개 |
| 주간 의뢰 | 3개 |
| 월간 의뢰 | 3개 |

의뢰마다 목표, 현재 진행도와 보상이 표시됩니다. 완료된 의뢰는 의뢰 화면에서 보상을 받아야 최종 처리됩니다.

## 원하지 않는 의뢰 바꾸기

진행하기 어려운 의뢰는 새로고침할 수 있습니다. 새로고침할수록 비용이 올라가므로 목표와 보상을 먼저 확인하세요.

- 일일 의뢰: 최대 3회, 300원 → 600원 → 900원
- 주간 의뢰: 최대 4회, 회차마다 1,000원씩 증가
- 월간 의뢰: 최대 4회, 3,000셀 → 6,000셀 → 9,000셀 → 12,000셀

자주 하지 않는 의뢰 유형은 최대 2개까지 차단할 수 있습니다. 차단된 유형은 다음 의뢰를 고를 때 제외됩니다.

## 이용할 때 확인할 점

- 진행도와 남은 기간은 `/의뢰` 화면에 표시되는 값을 기준으로 확인하세요.
- 새로고침하면 교체되는 목표를 되돌릴 수 없으므로 먼저 진행도를 확인하세요.
- 보상과 목표 구성은 서버 밸런스에 따라 변경될 수 있습니다.
- 메뉴에서 의뢰가 보이지 않으면 튜토리얼을 먼저 완료했는지 확인하세요.
