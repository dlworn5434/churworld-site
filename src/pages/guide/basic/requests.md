## 의뢰 시작하기

`/의뢰`를 입력하거나 통합 메뉴의 **의뢰** 버튼을 누르면 현재 의뢰를 확인할 수 있습니다. 의뢰는 생활 활동을 하며 자연스럽게 달성하는 반복 목표입니다.

| 구분 | 한 번에 표시되는 의뢰 |
| --- | ---: |
| 일일 의뢰 | 9개 |
| 주간 의뢰 | 3개 |
| 월간 의뢰 | 3개 |

의뢰마다 목표, 현재 진행도와 보상이 표시됩니다. 완료된 의뢰는 의뢰 화면에서 보상을 받아야 최종 처리됩니다.

### 의뢰 완료 보상

아래 보상은 **완료한 의뢰 1개를 직접 수령할 때마다** 지급됩니다.

| 구분 | 게임 머니 | 츄르 코인 |
| --- | ---: | ---: |
| 일일 의뢰 | 300원 | 1개 |
| 주간 의뢰 | 3,000원 | 3개 |
| 월간 의뢰 | 12,000원 | 7개 |

진행도를 모두 채워도 수령하지 않으면 보상이 지급되지 않으므로, 기간이 끝나기 전에 의뢰 화면에서 완료 보상을 받으세요.

## 어떤 행동이 의뢰에 포함되나요?

의뢰에는 다음과 같은 생활·생산·탐험 행동이 사용됩니다.

| 목표 종류 | 진행되는 행동 예시 |
| --- | --- |
| 심기 | 지정된 씨앗이나 작물을 심기 |
| 채집 | 지정된 작물·자원 채집 |
| 낚시 | 조건에 맞는 물고기 낚기 |
| 요리 | 조리대에서 지정 요리 완성 |
| 채광 | 지정 광석이나 광맥 채굴 |
| 제련 | 흔한 화로에서 지정 결과 수령 |
| 벌목 | 지정 원목이나 커스텀 나무 벌목 |
| 제작 | 생활 제작대에서 지정 물품 제작 |
| 설치 | 지정 블록이나 생활 시설 설치 |
| 사냥 | 지정 몬스터 처치 |
| 소비 | 지정 아이템 사용·섭취 |
| 투척 | 지정 아이템 던지기 |

한 의뢰에 목표가 여러 개 표시된다면 **표시된 세부 목표를 모두 완료**해야 보상을 받을 수 있습니다. 비슷한 아이템이어도 의뢰에 지정된 대상과 다르면 진행되지 않으므로 진행도 표시를 확인하세요.

## 원하지 않는 의뢰 바꾸기

진행하기 어려운 의뢰는 새로고침할 수 있습니다. 새로고침할수록 비용이 올라가므로 목표와 보상을 먼저 확인하세요.

- 일일 의뢰: 최대 3회, 300원 → 600원 → 900원
- 주간 의뢰: 최대 4회, 회차마다 1,000원씩 증가
- 월간 의뢰: 최대 4회, 3,000셀 → 6,000셀 → 9,000셀 → 12,000셀

자주 하지 않는 의뢰 유형은 최대 2개까지 차단할 수 있습니다. 차단된 유형은 다음 의뢰를 고를 때 제외됩니다.

## 이용할 때 확인할 점

- 진행도와 남은 기간은 `/의뢰` 화면에 표시되는 값을 기준으로 확인하세요.
- 새로고침하면 교체되는 목표를 되돌릴 수 없으므로 먼저 진행도를 확인하세요.
- 보상과 목표 구성은 서버 밸런스에 따라 변경될 수 있습니다.
- 메뉴에서 의뢰가 보이지 않으면 튜토리얼을 먼저 완료했는지 확인하세요.
