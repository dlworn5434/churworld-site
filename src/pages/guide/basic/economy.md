## 물물교환

`/물물교환`으로 일반 물물교환 화면을 열 수 있습니다. 돈을 지불하는 상점과 달리 화면에 표시된 재료를 제출하고 정해진 결과물을 받습니다.

- 재료와 결과물의 종류·수량을 모두 확인한 뒤 교환하세요.
- 목록에는 흔한 작업대, 생활 숙련도 경험치 쿠폰, 경험치 병, 낚시 감각 고정 주사기, 확성기 등이 표시될 수 있습니다.
- 교환 목록은 바뀔 수 있으므로 게임 안의 물물교환 화면을 최종 기준으로 확인하세요.

## 작물 등급 교환

`/작물교환`으로 **풍요의 작물 교환소**를 열 수 있습니다. 등록된 커스텀 작물을 같은 종류의 더 높은 등급으로 교환합니다.

현재 교환 가능한 작물은 토마토, 양배추, 옥수수, 레몬, 상추, 무, 석류, 포도, 바나나, 파인애플, 오렌지, 딸기입니다.

| 교환 방법 | 결과 |
| --- | --- |
| 하위 등급 작물 3개 | 바로 다음 등급 작물 1개 |
| 1성 작물 6개 | 같은 작물의 3성 1개 |
| 2성 작물 2개 | 같은 작물의 3성 1개 |

예를 들어 같은 작물의 1성 3개를 2성 1개로, 2성 3개를 3성 1개로 바꿀 수 있습니다. 서로 다른 작물은 합쳐서 교환할 수 없습니다.

## 츄르 ATM

서버의 **츄르 ATM NPC**에서는 캐시를 계정의 츄르 잔액으로 바꿀 수 있습니다. 교환 비율은 **1캐시 = 1츄르**입니다.

ATM 화면의 빠른 선택 금액은 100, 1,000, 10,000, 100,000입니다. 교환 전에 차감될 캐시와 충전될 츄르를 확인하세요.

츄르 잔액, 츄르 코인, 츄르 충전 코인의 차이는 [상점 이용법](/guide/basic/shop#츄르-코인과-충전-코인의-차이)에서 확인할 수 있습니다.

## 돈 보내기

`/pay <플레이어> <금액>`으로 다른 플레이어에게 게임 머니를 보낼 수 있습니다.

- 플레이어 이름과 금액을 다시 확인한 뒤 전송하세요.
- 자기 자신에게는 보낼 수 없습니다.
- 잔액이 부족하면 전송되지 않습니다.
- 거래 약속과 확인은 서버 내 공개 채널이나 스레드에서 진행하는 것이 안전합니다.

## 재화 확인 명령어

| 명령어 | 기능 |
| --- | --- |
| `/재화 목록` | 현재 사용할 수 있는 재화 종류 확인 |
| `/재화 조회` | 내 게임 머니 잔액 확인 |
| `/재화 조회 <재화>` | 내 지정 재화 잔액 확인 |
| `/재화 순위 <재화> [페이지]` | 해당 재화의 보유 순위 확인 |

명령어에서 요구하는 재화 이름은 `/재화 목록`에 표시되는 값을 사용하세요.
