## 튜토리얼이 먼저인 이유

신규 유저는 로비에서 생활 튜토리얼을 완료한 뒤 본 서버 플레이를 시작합니다. 완료 전에는 통합 메뉴와 일반 명령어, 로비 밖 이동이 제한됩니다.

- 진행 확인과 시작: `/튜토리얼`
- 적용 대상: 처음 접속한 신규 유저
- 진행 장소: 로비의 **생활 튜토리얼 안내원**
- 허용되는 명령어: 튜토리얼, 귓속말, 답장, 리소스팩 관련 명령어

> Shift + F나 `/메뉴`가 열리지 않는다면 오류가 아니라 튜토리얼 진행 상태를 먼저 확인해야 합니다.

## 체험 순서

| 순서 | 체험 | 완료 목표 |
| ---: | --- | --- |
| 1 | 농사 | 씨앗 심기, 자동 파종, 곡선 수확, 작물 수확 |
| 2 | 채광 | 광석 채굴, 광석 감지, 광부의 각성 |
| 3 | 벌목 | 나무 벌목, 나무 감지, 숲의 분노 |
| 4 | 작업대 | 흔한 작업대 열기와 결과물 수령 |
| 5 | 화로 | 흔한 화로 제련과 결과물 수령 |
| 6 | 낚시 | 낚싯대 던지기와 미니게임 성공 |
| 7 | 낚시 파츠 | 파츠 화면 열기와 파츠 장착 |

각 체험에는 임시 도구와 재료가 제공됩니다. 화면에 표시되는 현재 목표를 완료하면 다음 체험 장소로 이동합니다.

## 꼭 기억할 조작

| 분야 | 조작 |
| --- | --- |
| 농부 자동 파종 | 괭이를 들고 **Shift + 좌클릭** |
| 농부 곡선 수확 | 괭이를 들고 **Shift + 우클릭** |
| 광석 감지 | 곡괭이를 들고 **Shift + 우클릭** |
| 광부의 각성 | 곡괭이를 들고 **Shift + C** 또는 생활 GUI의 스킬 버튼 |
| 나무 감지 | 도끼를 들고 **Shift + 좌클릭** |
| 숲의 분노 | 도끼를 들고 **Shift + 우클릭** |

전용 클라이언트의 **설정 → 조작 설정 → LifeCore 생활**에서 각 생활 스킬의 보조키를 직접 지정할 수도 있습니다. 지정한 스킬 키는 Shift와 함께 누릅니다.

## 농사 체험에서 배우는 것

- 비닐하우스 유리는 작물 바로 위 최대 5칸 안에서 인식됩니다.
- 유리를 화분 위 3칸 높이에 설치하면 확인하기 쉽습니다.
- 허수아비는 중심에서 7칸 범위의 작물을 까마귀로부터 보호합니다.

## 완료한 뒤

튜토리얼을 끝내면 본 서버 이동과 통합 메뉴가 해제되고 다음 시작 물품을 받습니다.

| 시작 물품 | 수량 |
| --- | ---: |
| 황금 당근 | 16개 |
| 파츠 슬롯 낚싯대 | 1개 |
| 일반 낚싯대 | 1개 |
| 흔한 작업대 | 1개 |
| 경험치 병 | 64개 |
| 건설 도면 | 1개 |
| 츄르 카메라 | 1개 |
| 인챈트된 철 방어구 세트 | 1세트 |
| 인챈트된 철 삽·괭이·도끼·곡괭이 | 각 1개 |
| 일반 잠수 의자 | 1개 |

### 시작 장비 인챈트

| 장비 | 인챈트 |
| --- | --- |
| 철 투구 | 보호 II, 내구성 III |
| 철 흉갑 | 보호 II |
| 철 각반 | 보호 II |
| 철 장화 | 가벼운 착지 III, 발사체로부터 보호 III |
| 철 삽 | 효율 II, 내구성 II |
| 철 괭이 | 효율 II, 내구성 II |
| 철 도끼 | 효율 II |
| 철 곡괭이 | 효율 II, 내구성 II |

시작 물품을 받을 수 있도록 인벤토리 빈칸을 충분히 확보하세요. 카메라 필름은 [물물교환](/guide/basic/economy#츄르-코인-교환)에서 별도로 얻을 수 있습니다.

이후에는 [첫걸음 가이드](/guide/basic/start)를 따라 `/길라잡이`, 생활 직업, 홈과 가방을 차례로 확인하세요.

진행이 멈춘 것처럼 보이면 `/튜토리얼 상태`로 현재 목표를 다시 확인하고, 안내된 행동을 체험 구역 안에서 수행하세요.
