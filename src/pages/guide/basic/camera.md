## 준비하기

츄르 카메라는 전용 화면으로 사진을 촬영하고 편집한 뒤, 인화한 사진을 월드의 벽에 설치하는 콘텐츠입니다. 카메라 화면을 사용하려면 **카메라 모드가 포함된 츄르월드 전용 Fabric 클라이언트**가 필요합니다.

| 획득 방법 | 필요한 재료 |
| --- | ---: |
| 신규 유저 튜토리얼 완료 보상 | 카메라 1개 |
| `/물물교환` 카메라 교환 | 츄르 코인 10개 |
| `/물물교환` 필름 교환 | 츄르 코인 3개당 필름 1개 |

튜토리얼 보상에는 카메라만 포함됩니다. 사진을 인화하려면 필름을 따로 준비하세요.

## 카메라 열기와 촬영

카메라를 주 손에 들고 공중이나 블록을 **우클릭**하면 뷰파인더가 열립니다.

| 조작 | 기능 |
| --- | --- |
| 마우스 좌클릭 | 현재 화면 촬영 |
| 마우스 우클릭 또는 Esc | 카메라 화면 닫기 |
| `V` | 사진 크기 변경 |
| `C` | 10종 촬영 필터 순서대로 변경 |
| `G` | 화면 가이드 표시 전환 |
| 마우스 휠 또는 `-`, `=` | 1.0배부터 4.0배까지 줌 조절 |

촬영한 뒤 편집 화면에서 결과를 확인하고 인화할 수 있습니다. 사진을 최종 인화하는 데 성공할 때만 필름이 사용됩니다.

## 사진 크기와 필름

| 사진 크기 | 필요한 필름 | 벽에 표시되는 크기 |
| --- | ---: | --- |
| 1×1 | 1개 | 1블록 × 1블록 |
| 2×2 | 2개 | 2블록 × 2블록 |
| 4×4 | 4개 | 4블록 × 4블록 |
| 6×4 | 6개 | 가로 6블록 × 세로 4블록 |

큰 사진은 설치할 벽에 사진 전체가 들어갈 평평한 공간이 필요합니다. 촬영 전에 선택한 크기와 보유 필름을 확인하세요.

## 사진 편집

촬영 후 편집 화면에서는 다음 항목을 조절할 수 있습니다.

- 준비된 색감 프리셋
- 노출
- 대비
- 채도
- 색온도
- PNG 스티커 최대 8개

스티커는 파일을 선택하거나 화면으로 끌어와 추가할 수 있습니다. 추가한 스티커는 드래그해 이동하고 크기를 조절할 수 있으며, **Shift + 마우스 휠**로 회전하거나 선택한 스티커를 삭제할 수 있습니다.

편집을 마치면 인화 버튼으로 사진 아이템을 만듭니다. 인화 재사용 대기시간은 **10초**입니다.

## 벽에 사진 설치하기

인화한 사진을 주 손에 들고 평평한 벽의 앞면을 우클릭하면 설치됩니다.

1. 사진 크기만큼 비어 있는 평평한 벽을 준비합니다.
2. 사진 아이템을 들고 설치할 벽의 앞면을 우클릭합니다.
3. 설치 방향과 사진이 차지할 공간을 확인합니다.
4. 회수하려면 사진 앞면을 바라보고 **Shift + 좌클릭**합니다.

사진을 회수할 때는 인벤토리에 빈칸을 마련하세요. 일반 블록을 부수는 방식이 아니라 사진 앞면에서 Shift + 좌클릭해야 합니다.

## 사진 보관과 설치 한도

| 항목 | 한도 |
| --- | ---: |
| 플레이어가 보관할 수 있는 사진 | 최대 20장 |
| 플레이어가 벽에 설치할 수 있는 사진 | 최대 20장 |
| 한 청크에 설치할 수 있는 벽 사진 | 최대 8장 |

한도에 도달하면 필요하지 않은 사진을 정리하거나 설치한 사진을 회수한 뒤 다시 시도하세요.

## 사진 관리 명령어

`/ccamera`와 `/churcamera`는 같은 명령어입니다.

| 명령어 | 기능 |
| --- | --- |
| `/ccamera photos` | 내 사진 UUID와 보관 수량 확인 |
| `/ccamera reprint <사진 UUID>` | 내 사진을 같은 크기로 다시 인화 |
| `/ccamera delete <사진 UUID>` | 벽에 설치되지 않은 내 사진 기록 삭제 |

재인화할 때도 해당 사진 크기에 맞는 필름이 필요합니다. 사진 UUID는 `/ccamera photos`에 표시된 값을 그대로 사용하세요. 삭제한 사진 기록은 다시 사용할 수 없으므로 UUID를 확인한 뒤 삭제하세요.

## 작동하지 않을 때

- 카메라 우클릭 화면이 열리지 않으면 최신 츄르월드 전용 클라이언트인지 확인합니다.
- 인화되지 않으면 사진 크기에 필요한 필름 수량과 10초 대기시간을 확인합니다.
- 벽에 설치되지 않으면 사진 크기만큼 평평하고 비어 있는 공간인지 확인합니다.
- 회수되지 않으면 사진 앞면을 정확히 바라보고 Shift + 좌클릭합니다.
