## 설정 화면 열기

최신 츄르월드 전용 클라이언트에서 **`J`키**를 누르면 HUD 배치 모드가 열립니다. 키를 바꿨다면 게임의 조작 설정에서 **HUD 배치 모드 열기**에 지정한 키를 사용하세요.

화면 왼쪽 아래의 **HUD 설정**은 상단 정보창을, **채팅 설정**은 채팅 글자 크기를 조절하는 메뉴입니다.

## HUD 위치와 크기

배치 화면에서 **채팅창·아이템 획득 HUD·생활 스킬 쿨타임 HUD**를 원하는 위치로 끌어 옮기세요. 각 영역의 **오른쪽 아래 손잡이**를 끌면 크기를 바꿀 수 있습니다.

- 아이템 획득 HUD와 쿨타임 HUD는 하단 버튼으로 각각 켜고 끌 수 있습니다.
- 조절을 마치면 **완료**를 눌러 배치를 저장하세요.
- 상단 정보창은 아래의 **HUD 설정**에서 따로 조절합니다.

## 상단 정보창 설정

`J` → 왼쪽 아래 **HUD 설정**을 누르세요. 편지지 모양의 상단 정보창은 **왼쪽 위에 고정**되며 크기와 표시 상태를 바꿀 수 있습니다.

| 설정 | 조절 범위와 기능 |
| --- | --- |
| 크기 | 60~160%, 기본 100% |
| 배경 투명도 | 0~100%. 100%에서는 편지지 배경만 사라짐 |
| 표시: 켜짐/꺼짐 | 상단 정보창 전체를 표시하거나 숨김 |
| 기본값 | 상단 정보창의 크기 100%·배경 투명도 0%·표시 켜짐으로 복원 |

**배경 투명도를 높여도 글자·아이콘·마나바는 그대로 보입니다.** 정보까지 모두 숨기려면 **표시: 꺼짐**을 선택하세요. 이 화면의 기본값 버튼은 상단 정보창 설정만 되돌립니다.

슬라이더를 놓거나 화면을 닫으면 설정이 저장됩니다. **완료** 또는 `ESC`로 HUD 배치 화면에 돌아갈 수 있습니다.

## 채팅 글자 크기

`J` → 왼쪽 아래 **채팅 설정** → **채팅 글자 크기**에서 조절하세요.

- **70~150%**, **5% 단위**로 조절하며 기본값은 **100%**입니다.
- 슬라이더를 선택한 뒤 좌우 방향키로도 조절할 수 있습니다.
- 채팅 본문의 글자와 함께 표시되는 이모티콘에 적용되며, 예시 화면에서 크기를 확인할 수 있습니다.
- **글자 크기 기본값**을 누르면 글자 크기만 100%로 돌아갑니다.
- 슬라이더를 놓거나 완료·`ESC`로 돌아가면 저장됩니다.

채팅창 자체의 폭과 높이를 바꾸려면 HUD 배치 화면의 채팅창 손잡이를 조절하세요.

## 채팅 이모티콘

채팅 입력칸 오른쪽의 **이모티콘 버튼** 또는 **`Alt + E`**로 선택창을 열 수 있습니다. 전체·인사·애정·기분·응원·일상 탭에서 고양이 이모티콘을 고르면 커서 위치에 입력됩니다.

`Enter`로 채팅을 보내고 `ESC`로 선택창을 닫으세요. 이모티콘이 제대로 보이려면 보내는 사람과 받는 사람 모두 최신 전용 클라이언트를 사용해야 합니다.
