## 이젤 열기

빈 벽이나 넓은 공간을 바라보고 `/daub open [크기]`를 입력하세요. 크기는 `1`, `2`, `3` 중에서 선택할 수 있습니다.

| 조작 | 기능 |
| --- | --- |
| 우클릭 길게 누르기 | 바라보는 곳에 그리기 |
| 마우스 휠 | 붓 크기 조절 |
| `Q` | 마지막 작업 되돌리기 |
| `F` | 그리기 도구 변경 |
| `/daub color #RRGGBB` | HEX 색상 지정 |
| `/daub brush <1~24>` | 붓 크기 직접 지정 |
| `/daub theme [이름]` | 현재 테마 확인 또는 변경 |

이젤과 24블록보다 멀어지거나 다른 월드로 이동하면 작업 화면이 자동으로 닫히고 `autosave`에 저장됩니다. `/daub load autosave`로 이어서 그릴 수 있습니다.

## 저장하고 이어서 그리기

| 명령어 | 기능 |
| --- | --- |
| `/daub save <이름>` | 현재 작품 저장 |
| `/daub load <이름>` | 저장한 작품 불러오기 |
| `/daub saves` | 저장된 작품 목록 확인 |
| `/daub delete <이름>` | 저장한 작품 삭제 |
| `/daub close` | 현재 이젤 닫기 |

이름을 붙인 작품은 최대 30개까지 저장할 수 있습니다. 저장 공간이 가득 차면 필요 없는 작품을 삭제하거나 같은 이름의 저장 칸을 덮어쓰세요.

## 지도 작품으로 만들기

`/daub export <이름>`으로 저장한 그림을 걸 수 있는 지도 작품으로 내보낼 수 있습니다. 여러 장으로 구성된 작품을 지도 한 장으로 만들려면 `/daub export single <이름>`을 사용하세요.

- 지도 내보내기는 10초의 재사용 대기시간이 있습니다.
- 인벤토리가 가득 차면 일부 지도가 발밑에 떨어질 수 있습니다.
- 내보낸 지도는 잃어버리지 않도록 바로 보관하세요.
