## 그림 시작하기

츄르월드 자체 그림 기능 **ChurPaint**는 월드 안에 캔버스와 도구판을 펼쳐 그림을 그리는 기능입니다. 그림 전용 모드나 리소스팩을 따로 설치할 필요는 없습니다.

1. 앞쪽에 **가로 6칸·세로 3칸** 정도의 빈 공간이 있는 안전한 곳에 서세요.
2. 인벤토리를 **1칸 이상** 비워 주세요. 보조 손에 아이템이 있다면 **2칸**이 필요합니다.
3. `/그림`을 입력하고 작품 크기를 선택하세요. 깃털 붓이 자동으로 장착됩니다.

| 작품 크기 | 원본 크기 | 설치할 때 필요한 액자 |
| --- | --- | --- |
| 1칸 | 128 × 128 | 1개 |
| 4칸 | 256 × 256 | 4개, 가로 2 × 세로 2 |

편집할 때는 두 크기 모두 넓은 캔버스로 보입니다. 4칸 작품의 점선은 실제 액자 경계이며, `/그림 칸표시`로 켜고 끌 수 있습니다. 안내선은 완성된 그림에 포함되지 않습니다.

## 그리기와 도구 사용

캔버스와 양옆 도구판을 **시선으로 가리켜** 조작하세요. 왼쪽에는 그리기·선택·편집·저장 도구, 오른쪽에는 색상·굵기·불투명도 설정이 있습니다.

| 조작 | 기능 |
| --- | --- |
| 우클릭을 누른 채 시선 이동 | 선 그리기. 버튼을 놓으면 확정 |
| 좌클릭 | 점이나 도장 찍기 |
| 도구판을 가리켜 클릭 | 도구·색상·설정 선택 |
| `F` 또는 `/그림 도구` | 전체 도구 창 열기 |
| `/그림 실행취소` · `/그림 다시실행` | 이전 작업 되돌리기·복구 |
| `/그림 닫기` | 저장하고 편집 종료 |

편집 중에는 마우스 휠·숫자키로 손을 바꾸거나 아이템을 이동·버릴 수 없습니다. 편집을 닫으면 원래 손에 들었던 아이템으로 돌아갑니다.

붓·지우개·채우기 외에도 직선·사각형·타원, 올가미 선택, 이동·복사·붙여넣기·반전을 사용할 수 있습니다. 도형이나 선택 영역을 옮길 때도 **우클릭을 누른 채 움직이고 놓아서 확정**하세요. 진행 중인 미리보기는 `/그림 취소`로 취소할 수 있습니다.

### 색과 화면 조절

- 기본 색상, 색상 모음, 최근 색과 즐겨찾기에서 색을 고를 수 있습니다.
- **붓 색 조절**에서 색조·채도·명도를 미리 보고 적용할 수 있습니다. 지도에서 표현되는 색은 원래 고른 색과 조금 다를 수 있으므로 표시 샘플을 확인하세요.
- 붓 크기는 **1~16px**, 불투명도는 **1~100%**입니다.
- 확대·화면 끌기, 모눈·중앙선, 좌우·상하 대칭을 사용할 수 있습니다.
- 그림 전체나 선택 영역의 명도·채도 보정은 미리보기를 확인한 뒤 **적용**해야 반영됩니다.

## 저장하고 이어서 그리기

| 명령어 | 기능 |
| --- | --- |
| `/그림 새 <이름>` | 이름을 정해 새 그림 만들기 |
| `/그림 저장` | 현재 그림 저장 |
| `/그림 목록` | 내 그림 목록 확인 |
| `/그림 열기 <이름>` | 저장한 그림 이어 그리기 |
| `/그림 관리` | 이름 변경·복제·휴지통·복원·설치본 관리 |
| `/그림 닫기` | 저장하고 편집 종료 |

작품은 자동 저장되며, 편집을 닫거나 접속을 종료할 때도 저장합니다. 중요한 작업을 마친 뒤에는 `/그림 저장`으로 직접 저장해 주세요. 편집용 작품은 한 사람당 최대 **30개**입니다.

휴지통으로 옮긴 작품은 관리 화면에서 복원할 수 있으며, 이미 설치한 지도 그림은 유지됩니다. 이름을 바꾸거나 복제할 때 같은 이름의 다른 작품을 덮어쓰지는 않습니다.

## 액자에 그림 걸기

1. 편집 중 `/그림 받기`로 설치용 지도를 받으세요.
2. 일반 액자 또는 발광 액자에 지도를 넣으세요.
3. 4칸 그림은 **위쪽 1·2, 아래쪽 3·4** 순서로 배치하세요.

설치용 지도는 **받은 시점의 그림을 담은 복사본**입니다. 원본을 수정해도 전에 받거나 나눠 준 지도는 바뀌지 않습니다. 수정한 그림을 전시하려면 지도를 다시 받아 교체하세요. 액자 설치에는 해당 장소의 건축·보호 권한이 적용됩니다.

## 다른 사람의 그림 관람

그리는 사람의 **8블록 이내**로 다가가면 별도 명령어 없이 작업 중인 캔버스를 볼 수 있습니다. 그림 하나에 최대 **4명**이 관람할 수 있으며, 여러 그림의 관람 연결을 합쳐 최대 **8개**까지 표시됩니다.

관람자는 그림만 볼 수 있고 도구판이나 편집 권한은 공유되지 않습니다. 멀어지거나 다른 월드로 이동하면 관람 화면이 사라지며, 그리는 사람이 편집을 닫으면 함께 종료됩니다.
