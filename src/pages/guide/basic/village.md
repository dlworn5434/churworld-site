## 마을이란?

마을은 특정 지역(청크)을 점유해서 우리만의 구역으로 만들고,  
마을 레벨을 올리면서 **인원 / 땅 / 경작지** 한도를 늘려가는 정착 콘텐츠야.

## 마을 생성

### 생성 조건
- 한 유저는 마을 1개만 가입 가능
- 이미 다른 마을에 가입되어 있으면 마을 생성 불가
- 통합 메뉴로 **마을1~마을6** 월드 중 한 곳으로 이동한 뒤 생성
- 새 마을 중심은 기존 마을 중심에서 최소 **7청크** 떨어져 있어야 함
- 생성할 때 확보되는 3×3 영역이 다른 마을의 점유지와 겹치면 생성 불가
- 생성 비용은 **5,000원**
- 마을 이름은 1~16자이며 공백과 색상 코드는 사용할 수 없음

### 명령어
- `/마을 생성 <마을명>`

### 생성 보상
- 마을 생성 시 자동으로 **9청크(3×3)** 를 기본 점유해줘

마을1~마을6의 점유되지 않은 황무지에서는 일반 건축이 제한돼. 건축하려는 땅을 먼저 마을 땅으로 점유해야 해.

## 점유(클레임) 시스템

### 황무지란?
마을이 점유하지 않은 땅은 황무지로 취급돼.  
황무지는 마을이 땅을 확장하면서 점유할 수 있어.

### 점유 방법
1. `/마을` 메뉴에서 **마을 지도**를 열기
2. 지도 모드를 **점유**로 맞추고 마을 땅과 연결된 황무지를 선택

점유하려는 청크에 직접 서서 `/마을 땅 점유` 명령어를 사용해도 돼.

### 점유 규칙
- 점유하려는 청크는 마을 땅과 인접해야 함
- 가로 / 세로 인접만 가능
- 대각선 인접은 불가능
- 점유는 **매니저 이상**만 가능
- 점유 한도는 마을 인원수가 아닌 **마을 레벨별 고정 총량**으로 계산
- 생성할 때 받은 9청크도 마을의 전체 점유 수에 포함
- 점유 비용은 마을 레벨이 아니라 **점유 후 몇 번째 청크가 되는지**에 따라 증가
- 점유 비용은 마을 금고가 아니라 **점유를 실행한 플레이어의 개인 잔액**에서 결제
- 현재 점유 수, 전체 한도와 다음 점유 비용은 `/마을` 메뉴에서 확인 가능

### 점유 비용

| 점유 후 전체 청크 수 | 청크당 비용 |
| ---: | ---: |
| 1~30청크 | 1,000원 |
| 31~50청크 | 3,000원 |
| 51~70청크 | 5,000원 |
| 71~100청크 | 7,000원 |
| 101~150청크 | 10,000원 |
| 151~220청크 | 15,000원 |
| 221~300청크 | 20,000원 |
| 301~400청크 | 25,000원 |
| 401~500청크 | 32,000원 |
| 501~650청크 | 50,000원 |
| 651~800청크 | 70,000원 |
| 801~1,000청크 | 90,000원 |
| 1,001~1,300청크 | 120,000원 |
| 1,301~1,500청크 | 150,000원 |

예를 들어 현재 30청크를 점유하고 있다면 다음 31번째 청크의 비용은 **3,000원**이야.

### 점유 해제
- `/마을 땅 해제`
- 해제해도 점유 비용은 환불되지 않음

### 점유 범위 확인
- `/마을 땅 범위`
- GUI에서도 확인 가능

## 그룹(땅 관리 단위)

마을의 점유지는 그룹 단위로 관리돼.

### 그룹 특징
- 하나의 그룹이 여러 청크를 포함할 수 있어
- 하나의 청크는 한 그룹에만 속해
- 마을 생성 시 기본 그룹이 자동 생성
- 마을원이 가입하면 기본 그룹에 자동 추가

### 그룹이 중요한 이유
그룹별로 아래 항목을 따로 운영할 수 있어.
- 접근 가능한 멤버
- 권한(보호 / 사용 가능 기능)
- 경작지 지정 가능 여부

방문자·손님·다른 그룹·그룹원마다 아래 권한을 다르게 정할 수 있어.

- 블록 설치와 파괴
- 상자 등 보관함 사용
- 기능 블록, 문, 버튼과 레버, 제작대 사용
- 기타 블록 상호작용
- 농지 훼손(경작지 밟기)
- 양동이 사용
- 엔티티 상호작용과 공격
- 아이템 액자와 그림 사용

### 기본 권한과 그룹별 권한

행동 권한은 아래 순서로 적용돼.

1. 해당 그룹에서 직접 지정한 커스텀 권한
2. 마을 기본 권한
3. 시스템 기본값

마을 설정에서는 **엄격·주거·작업장** 기본 프리셋을 선택할 수 있어. 그룹에는 **주거·농장·창고·작업장** 프리셋을 적용할 수 있고, 개별 권한을 우클릭해 초기화하면 마을 기본 권한을 다시 따라가.

- 그룹 프리셋 적용은 마을장만 가능해.
- 매니저는 방문자·손님·다른 그룹·일반 그룹원의 권한을 편집할 수 있어.
- 매니저와 마을장 등급의 권한은 마을장만 편집할 수 있어.

### 농지 훼손(경작지 밟기) 권한

이 권한은 평범하게 밭 위를 걸어 다니는 것을 막는 기능이 아니야. 점프하거나 높은 곳에서 떨어져 **바닐라 경작지 블록이 흙으로 변하는 행동**만 관리해.

- 권한 **OFF**: 농지가 흙으로 변하지 않도록 훼손 행동을 취소
- 권한 **ON**: 밭을 밟아 흙으로 만들 수 있음
- 일반 보행은 막지 않으며 캐릭터를 밀어내지도 않음
- 마을에서 별도로 지정하는 경작지 청크와는 무관함
- 점유지 안에 있는 모든 바닐라 경작지 블록에 적용

### 기타 블록 상호작용 권한

상자·문·화로·버튼처럼 우클릭해서 사용하는 블록 가운데 **다른 권한 항목으로 따로 분류되지 않은 블록**을 사용하는 권한이야.

출입 가능 여부와 행동별 권한은 서로 다른 설정이야. 다른 유저가 마을에 들어오는 것 자체를 막으려면 행동 권한이 아니라 **마을 출입을 OFF**로 설정해야 해. 출입을 허용했더라도 그룹 권한에서 상자·건축·농지 훼손 같은 행동은 각각 제한할 수 있어.

### 경작지의 외부인 보호 설정

마을에서 경작지로 지정한 청크에는 외부인 대상 보호 설정 두 가지를 사용할 수 있어. 여기서 외부인은 마을원이 아닌 유저를 뜻하며, **초대된 손님도 외부인으로 처리**돼.

| 설정 | 보호 범위 | 기본값 |
| --- | --- | --- |
| 외부인 경작지 이용 차단 | 지정 경작지 청크에서 블록 설치·파괴와 상호작용 차단 | ON |
| 외부인 경작지 출입 차단 | 지정 경작지 청크로 들어오는 것 자체를 차단 | OFF |

경작지 출입 차단은 걷기뿐 아니라 텔레포트·차량 이동·접속·부활에도 적용돼. 이 두 설정은 **농지 훼손 권한**과 **마을 출입 설정**과 각각 별개야.

### 마을 PVP 설정

PVP는 그룹별 행동 권한이 아니라 마을 전체에 적용하는 설정이야.

- 마을장만 ON/OFF를 변경할 수 있어.
- 해당 마을의 모든 점유지에 같은 설정이 적용돼.
- 황무지의 PVP 설정과는 별도로 작동해.
- PVP가 ON인 지역에서도 서버의 유저 간 PVP 규칙은 지켜야 해.

### 관련 GUI
- `/마을 땅 관리`

## 마을원(멤버) / 초대

### 마을원 초대
- `/마을 초대 <닉네임>`
- 상대가 온라인이라면 현재 월드와 관계없이 초대 가능
- 일반 마을원 초대는 **5분** 동안 유효
- `/마을 초대 목록` — 보낸 초대 확인
- `/마을 초대 취소 <닉네임>` — 아직 수락하지 않은 초대 취소

### 수락하면?
- 마을에 가입됨
- 유효한 마을 스폰이 설정되어 있으면 그곳으로 이동
- 기본 그룹에 자동 추가

### 마을원 관리 명령어

- `/마을 매니저 <닉네임>` — 마을장이 매니저 임명·해임
- `/마을 탈퇴` — 일반 마을원과 매니저가 마을에서 탈퇴
- `/마을 위임 <닉네임>` — 마을장이 마을원에게 마을장 위임
- `/마을 삭제 확인` — 마을을 영구 삭제

마을장은 탈퇴할 수 없으므로 위임하거나 마을을 삭제해야 해. 탈퇴한 유저의 개인 경작지는 소유가 풀려 빈 경작지로 남고, 마을을 삭제하면 점유지·그룹·경작지·손님·마을 설정이 모두 삭제되어 복구할 수 없어.

## 매니저

마을장은 마을원 중 매니저를 임명할 수 있어.

### 매니저가 할 수 있는 것
- 땅 점유 / 해제 관리
- 그룹 생성 / 이동 / 권한 설정
- 일반 마을원 추방 등 일부 마을원 관리
- 손님 초대 / 관리
- 마을 건축 설치 / 회수 / 공용 재료 관리

마을장은 일반 마을원 추방뿐 아니라 매니저 임명·해임도 할 수 있어. 마을장 위임이 완료되면 기존 마을장은 매니저가 되고, 새 마을장은 모든 땅 그룹에 포함돼.

### 관리 GUI
- `/마을 관리`
- `/마을 땅 관리`

## 마을 건축

마을장과 매니저는 건설 도면과 도구함(건차)을 이용해 자기 마을 점유지에 장식 가구와 효과 타워를 설치할 수 있어. 마을 건축을 이용하려면 **HybridBuild 클라이언트 모드**가 필요해.

도면을 여는 방법, 공용 재료 보관, 205종의 장식 가구, 효과 타워와 설치 제한은 [마을 건축 안내](/guide/basic/construction)에서 확인해 줘.

## 자주 쓰는 마을 관리 기능

- `/마을 이름변경 <새이름>` — 마을장이 5,000원을 사용해 이름 변경
- `/마을 돈 넣기 <금액|전부>` — 마을원이 마을 은행에 돈 입금
- `/마을 출금 <금액|최대>` — 마을장이 현재 자산의 한 번당 최대 30% 인출
- `/마을 스폰` — 마을 스폰으로 이동
- `/마을 스폰 설정` — 매니저 이상이 점유지 안에서 스폰 설정
- `/마을 플라이 날기` — 마을 점유지 안에서 비행 시작
- `/마을 플라이 해제` — 마을 비행 종료
- `/마을 플라이 시간` — 남은 마을 비행 시간 확인
- `/마을 랭킹 [페이지]` — 누적 조공 XP 기준 마을 랭킹 확인

일반 유저의 마을 비행 시간은 실제로 날고 있을 때만 소모돼. 자기 마을 점유지 밖으로 나가면 비행이 자동으로 꺼지므로 공중에서 경계를 넘지 않도록 먼저 착지해 줘. 로얄츄르냥 멤버십은 마을 점유지에서 비행 시간을 무제한으로 이용할 수 있어.

마을 랭킹은 실시간이 아니라 매일 **00시·06시·12시·18시**에 갱신돼. 조공 직후에는 다음 갱신까지 순위가 그대로 보일 수 있어.

### 마을 월드에서 개인 홈 설정

개인 홈은 `/sethome [이름]`으로 저장할 수 있지만, 다른 마을의 생활 공간을 홈으로 이용하지 못하도록 위치 제한이 적용돼.

- 다른 마을의 점유지 안이나 그 점유지에서 **10청크 이내**에는 개인 홈을 새로 설정하거나 같은 이름의 홈을 갱신할 수 없음
- 점유되지 않은 황무지라도 다른 마을 점유지에서 10청크 이내라면 설정할 수 없음
- 현재 서 있는 청크가 **자신이 가입한 마을의 점유지**라면 주변 10청크 안에 다른 마을 땅이 있어도 개인 홈을 설정할 수 있음
- 개인 홈으로 이동할 때도 저장된 목적지 위치를 확인해. 주변 점유 상태가 바뀌어 제한 구역이 된 홈은 이동이 막힐 수 있음
- 저장된 목적지 청크가 자신의 마을 점유지라면 다른 마을이 가까워도 개인 홈으로 이동할 수 있음
- 이 규칙은 개인 홈에 적용되는 보호 기준이야. 공개 홈은 별도 공개 홈 규칙을 따라
- 홈 개수는 기본 1개에서 멤버십 혜택에 따라 늘어남

홈 저장·이동·삭제와 공개 홈 사용법은 [이동과 홈 안내](/guide/basic/travel)에서 확인해 줘.

### 마을 출입 설정

마을 설정에서 손님 초대 기본 시간, 마을 출입 상태와 기본 권한을 관리할 수 있어.

| 마을 출입 | 입장할 수 있는 유저 | 행동 권한 |
| --- | --- | --- |
| ON | 누구나 입장 가능 | 블록 사용·건축·농지 훼손 등은 그룹별 행동 권한을 따로 적용 |
| OFF | 마을원과 초대된 손님만 입장 가능 | 입장한 유저에게 그룹별 행동 권한을 따로 적용 |

즉, 다른 유저의 **입장 자체를 막는 설정**과 입장한 유저가 **무엇을 할 수 있는지 정하는 권한**은 별개야.

## 마을 청크 바이옴 변경

마을장은 자기 마을 점유 청크의 바이옴을 마을 설정에서 변경할 수 있어.

### 이용 조건

- 마을장만 사용할 수 있어.
- 변경할 자기 마을 점유 청크 안에 직접 서 있어야 해.
- 바이옴을 적용할 때마다 마을장 **개인 잔액에서 10,000원**이 결제돼.
- 한 마을에서 바이옴을 변경해 둘 수 있는 청크는 최대 **10개**야.
- 이미 변경한 청크를 다른 바이옴으로 다시 지정해도 변경 청크 수는 추가되지 않아.
- 원래 바이옴으로 복원하는 것은 무료야.

### 선택 가능한 바이옴

| 평원 계열 | 숲 계열 | 온난·건조 지역 | 추운 지역 |
| --- | --- | --- | --- |
| 평원 | 숲 | 사바나 | 타이가 |

## 손님(외부인 임시 초대)

마을원이 아닌 외부인을 일정 시간 손님으로 초대할 수 있어.

### 손님 초대
- `/마을 손님 초대 <닉네임> [분]`
- 매니저 이상만 가능
- 상대가 온라인일 때 초대할 수 있고, 초대장은 **3분** 동안 유효
- 초대 화면에서는 5·10·30·60·120분 중 체류 시간을 선택할 수 있음
- `/마을 손님 목록` — 현재 손님 확인
- `/마을 손님 취소 <닉네임>` — 아직 수락하지 않은 초대 취소
- `/마을 손님 정보 [닉네임]` — 본인 또는 지정한 손님의 남은 시간 확인

### 손님 규칙
- 초대 수락 시 유효한 마을 스폰이 설정되어 있으면 그곳으로 이동
- 만료 전까지 다른 손님 초대는 받을 수 없음
- 채널 이동 후 접속하면 자동 이동될 수 있음
- 손님이 나가기: `/마을 손님 퇴장`
- 강제 추방: `/마을 손님 추방 <닉네임>`
- 만료·퇴장·추방 시 마을 월드 스폰으로 이동
- 손님은 일반 방문자와 별도의 **손님 권한 단계**로 처리되며, 그룹 설정에 따라 제한될 수 있음

## 마을 로그

매니저 이상은 마을 관리 기록을 확인할 수 있어.

- `/마을 로그` — 기록된 최근 마을 관리 내역 확인
- `/마을 로그막대기` — 자기 마을 점유지의 블록별 기록을 보는 막대기 수령
- 로그 막대기는 매니저 이상이 **3시간마다 한 번** 받을 수 있어.
- 막대기로 블록을 우클릭하면 최근 설치·파괴 기록과 보관함을 연 기록을 확인할 수 있어.

로그에는 보관함을 **누가 열었는지**가 남지만, 보관함 안에서 어떤 아이템을 넣거나 꺼냈는지까지 기록되지는 않아.

## 경작지(커스텀 농사 구역)

마을의 점유지 중 일부를 경작지로 지정할 수 있어.

### 경작지 특징
- 매니저 이상이 마을 점유지를 먼저 경작지 청크로 지정
- 개인 경작지는 자신이 속한 땅 그룹의 빈 경작지만 설정 가능
- 공용 경작지는 모든 마을원이 함께 심고 수확 가능
- 이미 경작지인 땅에는 중복 지정 불가
- 개인 한도와 마을 공용 한도는 마을 레벨에 따라 각각 증가
- 개인 경작지를 공용으로 전환하면 기존 개인 소유는 자동 해제

### 점유 청크와 경작지 청크의 차이

- **마을 전체 점유**는 마을이 소유할 수 있는 모든 땅의 최대 청크 수야.
- **경작지 청크**는 이미 점유한 마을 땅을 농사용으로 지정한 청크야. 경작지를 지정한다고 마을 점유 한도가 추가로 늘어나지는 않아.
- **개인 경작지 한도**는 마을원 한 명마다 적용돼.
- **마을 공용 경작지 한도**는 마을 전체가 함께 사용하는 공용 청크 수에 적용돼.
- 경작지로 지정만 하고 아직 개인·공용 소유가 정해지지 않은 청크는 **빈 경작지**로 남아 있어.

### 확인 / 설정
- `/마을 땅 관리` GUI에서 확인 가능
- 개인 설정: `/마을 경작지 설정`
- 개인 해제: `/마을 경작지 해제`
- 공용 설정·해제: `/마을 경작지 공용설정`, `/마을 경작지 공용해제`
- 현재 청크 확인: `/마을 경작지 정보`

### 조공 시스템
조공은 아이템을 바쳐 **마을 경험치(XP)** 를 올리는 시스템이야.

#### 조공 GUI 열기
- `/마을 조공`
- 또는 `/마을 메뉴` → 조공 버튼

#### 조공 방법
1. 조공 GUI에 아이템을 넣어둠
2. `[조공하기]` 버튼 클릭

#### 검사 / 정리 버튼
`[검사/정리]` 버튼을 누르면
- 조공 가능한 아이템만 남기고
- 조공 불가 아이템은 자동 반환되고
- 예상 XP 합계도 보여줘

#### 조공 목록 보기
`[조공 목록]` 버튼에서
- 어떤 아이템이 조공 가능한지
- 개당 XP가 얼마인지  
직접 확인 가능해.

### 월간 조공 순위

이번 달에 각 마을이 올린 조공 XP는 누적 마을 랭킹과 별도로 집계돼.

- 집계 기간은 한국 시간 기준 **매월 1일 00:00부터 다음 달 1일 00:00까지**야.
- 현재 월간 조공 상위 3개 마을은 스폰의 **TOP3 표시**에서 확인할 수 있어.
- TOP3에는 순위 마을과 마을장이 표시되며, 순위에 맞춰 자동으로 갱신돼.
- 스폰의 월간 조공 순위표에서는 TOP10과 각 마을의 이번 달 조공 XP를 함께 확인할 수 있어.
- TOP3 마을의 현재 마을원에게는 순위에 따른 칭호가 제공돼. 순위가 바뀌거나 마을에서 나가면 칭호도 갱신되며, `/칭호 메뉴`에서 장착할 수 있어.
- 매월 1일 00:00이 되면 새 월간 집계가 시작돼. 기존의 `/마을 랭킹`은 누적 조공 XP 순위이므로 월간 순위와 서로 다를 수 있어.

## 주간 돈 세금·조공 세금과 마을 자산

마을의 주간 납부 항목은 **게임 머니로 내는 돈 세금**과 **조공 XP로 채우는 조공 세금**으로 나뉘어. `/마을 세금`에서 내 납부 상태, 마을원의 납부 현황과 누적 마을 자산을 확인할 수 있어.

### 돈 세금

- 마을장은 매주 납부할 요일과 금액을 설정할 수 있어
- 설정 범위는 주당 **1원~100,000원**
- 신규 가입자와 세금 설정이 바뀐 기존 마을원은 다음 납부 회차부터 적용돼
- 돈 세금은 `/마을 세금` GUI의 납부 버튼으로 내야 해
- 미납된 주차가 있으면 여러 주분을 한 번에 납부할 수 있어
- 접속하면 납부 예정일이나 미납 상태가 안내돼

### 조공 세금

- 마을장은 매주 마을원이 채울 조공 XP를 설정할 수 있어
- `/마을 조공`에서 아이템을 바치면 가장 오래된 미납 주차부터 채워져
- 한 번에 전부 채우지 못해도 조공한 만큼 부분 납부로 저장돼
- 세금 납부에 사용된 조공 XP도 그대로 마을 경험치에 누적돼

### 미납 처리

돈 세금과 조공 세금 중 **어느 하나라도 4주분이 밀리면** 마을에서 자동 추방돼. 마을장은 자동 추방 대상에서 제외되며, 미납 현황과 남은 기간은 세금 GUI에서 확인할 수 있어.

### 마을 자산

- 납부된 세금은 마을 자산으로 누적돼
- `/마을 돈 넣기 <금액|전부>`로 직접 넣은 돈도 마을 자산에 합산돼
- 단, **금고 직접 입금은 주간 돈 세금 납부로 처리되지 않아**. 세금은 반드시 `/마을 세금`에서 납부해야 해
- 매니저 이상은 정상 납부자와 미납자 목록을 확인할 수 있어
- 마을장만 자산을 인출할 수 있어
- 현재 한 번에 인출 가능한 최대 금액은 누적 자산의 **30%**

## 처음 마을을 찾는 유저

아직 한 번도 마을을 만들거나 가입하지 않은 신규 유저는 마을1~마을6에서 마을을 둘러볼 수 있는 전용 비행 시간을 받을 수 있어.

- `/마을찾기 플라이` — 신규 유저용 마을 찾기 비행 켜기·끄기
- `/마을찾기 플라이 시간` — 남은 시간 확인
- 사용할 수 있는 총 비행 시간은 **20분**
- 직접 끄면 남은 시간이 보존되고, 마을 월드를 벗어나면 자동으로 꺼짐
- 처음 마을을 생성하거나 가입하면 더 이상 사용할 수 없음

## FAQ

조공 GUI의 `[조공 목록]` 버튼을 보면 돼.  
`[검사/정리]` 버튼을 누르면 조공 불가 아이템은 자동 반환돼.
