## 마을이란?

마을은 특정 지역(청크)을 점유해서 우리만의 구역으로 만들고,  
마을 레벨을 올리면서 **인원 / 땅 / 경작지** 한도를 늘려가는 정착 콘텐츠야.

## 마을 생성

### 생성 조건
- 한 유저는 마을 1개만 가입 가능
- 이미 다른 마을에 가입되어 있으면 마을 생성 불가
- 통합 메뉴로 **마을1~마을6** 월드 중 한 곳으로 이동한 뒤 생성
- 새 마을 중심은 기존 마을 중심에서 최소 **7청크** 떨어져 있어야 함
- 생성할 때 확보되는 3×3 영역이 다른 마을의 점유지와 겹치면 생성 불가
- 생성 비용은 **5,000원**
- 마을 이름은 1~16자이며 공백과 색상 코드는 사용할 수 없음

### 명령어
- `/마을 생성 <마을명>`

### 생성 보상
- 마을 생성 시 자동으로 **9청크(3×3)** 를 기본 점유해줘

마을1~마을6의 점유되지 않은 황무지에서는 일반 건축이 제한돼. 건축하려는 땅을 먼저 마을 땅으로 점유해야 해.

## 점유(클레임) 시스템

### 황무지란?
마을이 점유하지 않은 땅은 황무지로 취급돼.  
황무지는 마을이 땅을 확장하면서 점유할 수 있어.

### 점유 방법
1. `/마을` 메뉴에서 **마을 지도**를 열기
2. 지도 모드를 **점유**로 맞추고 마을 땅과 연결된 황무지를 선택

점유하려는 청크에 직접 서서 `/마을 땅 점유` 명령어를 사용해도 돼.

### 점유 규칙
- 점유하려는 청크는 마을 땅과 인접해야 함
- 가로 / 세로 인접만 가능
- 대각선 인접은 불가능
- 점유는 **매니저 이상**만 가능
- 점유 한도는 마을 인원수가 아닌 **마을 레벨별 고정 총량**으로 계산
- 생성할 때 받은 9청크도 마을의 전체 점유 수에 포함
- 점유 비용은 마을 레벨이 아니라 **점유 후 몇 번째 청크가 되는지**에 따라 증가
- 현재 점유 수, 전체 한도와 다음 점유 비용은 `/마을` 메뉴에서 확인 가능

### 점유 비용

| 점유 후 전체 청크 수 | 청크당 비용 |
| ---: | ---: |
| 1~30청크 | 1,000원 |
| 31~50청크 | 5,000원 |
| 51~70청크 | 7,000원 |
| 71~100청크 | 10,000원 |
| 101~150청크 | 15,000원 |
| 151~220청크 | 20,000원 |
| 221~300청크 | 25,000원 |
| 301~400청크 | 32,000원 |
| 401~500청크 | 50,000원 |
| 501~650청크 | 70,000원 |
| 651~800청크 | 90,000원 |
| 801~1,000청크 | 120,000원 |
| 1,001~1,300청크 | 150,000원 |

예를 들어 현재 30청크를 점유하고 있다면 다음 31번째 청크의 비용은 **5,000원**이야.

### 점유 해제
- `/마을 땅 해제`
- 해제해도 점유 비용은 환불되지 않음

### 점유 범위 확인
- `/마을 땅 범위`
- GUI에서도 확인 가능

## 그룹(땅 관리 단위)

마을의 점유지는 그룹 단위로 관리돼.

### 그룹 특징
- 하나의 그룹이 여러 청크를 포함할 수 있어
- 하나의 청크는 한 그룹에만 속해
- 마을 생성 시 기본 그룹이 자동 생성
- 마을원이 가입하면 기본 그룹에 자동 추가

### 그룹이 중요한 이유
그룹별로 아래 항목을 따로 운영할 수 있어.
- 접근 가능한 멤버
- 권한(보호 / 사용 가능 기능)
- 경작지 지정 가능 여부

방문자·손님·다른 그룹·그룹원마다 아래 권한을 다르게 정할 수 있어.

- 블록 설치와 파괴
- 상자 등 보관함 사용
- 기능 블록, 문, 버튼과 레버, 제작대 사용
- 기타 블록 상호작용과 경작지 밟기
- 양동이 사용
- 엔티티 상호작용과 공격
- 아이템 액자와 그림 사용
- PVP

출입 가능 여부와 블록 사용 권한은 서로 다른 설정이야. 마을 입장을 허용했더라도 그룹 권한에서 상자나 건축 기능을 제한할 수 있어.

### 관련 GUI
- `/마을 땅 관리`

## 마을원(멤버) / 초대

### 마을원 초대
- `/마을 초대 <닉네임>`
- 채널 / 월드 상관없이 초대 가능

### 수락하면?
- 마을에 가입됨
- 즉시 마을 월드 스폰으로 이동
- 기본 그룹에 자동 추가

## 매니저

마을장은 마을원 중 매니저를 임명할 수 있어.

### 매니저가 할 수 있는 것
- 땅 점유 / 해제 관리
- 그룹 생성 / 이동 / 권한 설정
- 마을원 관리(일부 기능)
- 손님 초대 / 관리

### 관리 GUI
- `/마을 관리`
- `/마을 땅 관리`

## 자주 쓰는 마을 관리 기능

- `/마을 이름변경 <새이름>` — 마을장이 5,000원을 사용해 이름 변경
- `/마을 돈 넣기 <금액|전부>` — 마을원이 마을 은행에 돈 입금
- `/마을 스폰` — 마을 스폰으로 이동
- `/마을 스폰 설정` — 매니저 이상이 점유지 안에서 스폰 설정
- `/마을 플라이 날기` — 마을 점유지 안에서 비행 시작
- `/마을 플라이 해제` — 마을 비행 종료
- `/마을 플라이 시간` — 남은 마을 비행 시간 확인
- `/마을 랭킹 [페이지]` — 누적 조공 XP 기준 마을 랭킹 확인

일반 유저의 마을 비행은 보유 시간이 소모되며, 로얄츄르냥 멤버십은 마을 점유지에서 비행 시간을 무제한으로 이용할 수 있어.

### 마을 출입 설정

마을 설정에서 손님 초대 기본 시간, 입장 공개·비공개 상태와 기본 권한을 관리할 수 있어. 비공개 마을에는 마을원과 초대받은 손님만 들어갈 수 있어.

## 손님(외부인 임시 초대)

마을원이 아닌 외부인을 일정 시간 손님으로 초대할 수 있어.

### 손님 초대
- `/마을 손님 초대 <닉네임> [분]`
- 매니저 이상만 가능

### 손님 규칙
- 초대 수락 시 즉시 마을로 이동
- 만료 전까지 다른 손님 초대는 받을 수 없음
- 채널 이동 후 접속하면 자동 이동될 수 있음
- 손님이 나가기: `/마을 손님 퇴장`
- 강제 추방: `/마을 손님 추방 <닉네임>`
- 권한은 방문자로 처리되며, 그룹 설정에 따라 제한될 수 있음

## 경작지(커스텀 농사 구역)

마을의 점유지 중 일부를 경작지로 지정할 수 있어.

### 경작지 특징
- 매니저 이상이 마을 점유지를 먼저 경작지 청크로 지정
- 개인 경작지는 자신이 속한 땅 그룹의 빈 경작지만 설정 가능
- 공용 경작지는 모든 마을원이 함께 심고 수확 가능
- 이미 경작지인 땅에는 중복 지정 불가
- 개인 한도와 마을 공용 한도는 마을 레벨에 따라 각각 증가
- 개인 경작지를 공용으로 전환하면 기존 개인 소유는 자동 해제

### 점유 청크와 경작지 청크의 차이

- **마을 전체 점유**는 마을이 소유할 수 있는 모든 땅의 최대 청크 수야.
- **경작지 청크**는 이미 점유한 마을 땅을 농사용으로 지정한 청크야. 경작지를 지정한다고 마을 점유 한도가 추가로 늘어나지는 않아.
- **개인 경작지 한도**는 마을원 한 명마다 적용돼.
- **마을 공용 경작지 한도**는 마을 전체가 함께 사용하는 공용 청크 수에 적용돼.
- 경작지로 지정만 하고 아직 개인·공용 소유가 정해지지 않은 청크는 **빈 경작지**로 남아 있어.

### 확인 / 설정
- `/마을 땅 관리` GUI에서 확인 가능
- 개인 설정: `/마을 경작지 설정`
- 개인 해제: `/마을 경작지 해제`
- 공용 설정·해제: `/마을 경작지 공용설정`, `/마을 경작지 공용해제`
- 현재 청크 확인: `/마을 경작지 정보`

## 마을 레벨 & 조공

마을은 조공을 통해 경험치를 올리고 레벨업해.

### 레벨업하면 좋아지는 점
- 최대 인원 증가
- 점유 가능한 땅 증가
- 경작지 슬롯 증가

### 레벨별 한도

| 레벨 | 누적 필요 XP | 최대 인원 | 마을 전체 점유 | 개인 경작지(1인당) | 마을 공용 경작지(마을 전체) |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 1 | 0 | 5명 | 20청크 | 1개 | 1개 |
| 2 | 6,000 | 8명 | 35청크 | 2개 | 2개 |
| 3 | 12,000 | 12명 | 50청크 | 2개 | 3개 |
| 4 | 24,000 | 20명 | 80청크 | 3개 | 5개 |
| 5 | 48,000 | 24명 | 120청크 | 4개 | 7개 |
| 6 | 72,000 | 28명 | 180청크 | 4개 | 10개 |
| 7 | 192,000 | 32명 | 280청크 | 5개 | 14개 |
| 8 | 384,000 | 37명 | 450청크 | 5개 | 18개 |
| 9 | 768,000 | 42명 | 750청크 | 6개 | 24개 |
| 10 | 1,536,000 | 50명 | 1,300청크 | 7개 | 32개 |

마을의 전체 점유 한도는 **현재 인원수와 무관하게 마을 레벨로만 결정**돼. 한도에 도달하면 기존 땅을 해제하거나 마을 레벨을 올리기 전까지 추가 점유할 수 없어.

### 조공 시스템
조공은 아이템을 바쳐 **마을 경험치(XP)** 를 올리는 시스템이야.

#### 조공 GUI 열기
- `/마을 조공`
- 또는 `/마을 메뉴` → 조공 버튼

#### 조공 방법
1. 조공 GUI에 아이템을 넣어둠
2. `[조공하기]` 버튼 클릭

#### 검사 / 정리 버튼
`[검사/정리]` 버튼을 누르면
- 조공 가능한 아이템만 남기고
- 조공 불가 아이템은 자동 반환되고
- 예상 XP 합계도 보여줘

#### 조공 목록 보기
`[조공 목록]` 버튼에서
- 어떤 아이템이 조공 가능한지
- 개당 XP가 얼마인지  
직접 확인 가능해.

## 주간 돈 세금·조공 세금과 마을 자산

마을의 주간 납부 항목은 **게임 머니로 내는 돈 세금**과 **조공 XP로 채우는 조공 세금**으로 나뉘어. `/마을 세금`에서 내 납부 상태, 마을원의 납부 현황과 누적 마을 자산을 확인할 수 있어.

### 돈 세금

- 마을장은 매주 납부할 요일과 금액을 설정할 수 있어
- 설정 범위는 주당 **1원~100,000원**
- 새로 가입한 마을원은 다음 납부 회차부터 적용돼
- 미납된 주차가 있으면 여러 주분을 한 번에 납부할 수 있어
- 접속하면 납부 예정일이나 미납 상태가 안내돼

### 조공 세금

- 마을장은 매주 마을원이 채울 조공 XP를 설정할 수 있어
- `/마을 조공`에서 아이템을 바치면 가장 오래된 미납 주차부터 채워져
- 한 번에 전부 채우지 못해도 조공한 만큼 부분 납부로 저장돼
- 세금 납부에 사용된 조공 XP도 그대로 마을 경험치에 누적돼

### 미납 처리

돈 세금과 조공 세금 중 **어느 하나라도 4주분이 밀리면** 마을에서 자동 추방돼. 마을장은 자동 추방 대상에서 제외되며, 미납 현황과 남은 기간은 세금 GUI에서 확인할 수 있어.

### 마을 자산

- 납부된 세금은 마을 자산으로 누적돼
- 매니저 이상은 정상 납부자와 미납자 목록을 확인할 수 있어
- 마을장만 자산을 인출할 수 있어
- 현재 한 번에 인출 가능한 최대 금액은 누적 자산의 **30%**

## 처음 마을을 찾는 유저

아직 한 번도 마을을 만들거나 가입하지 않은 신규 유저는 마을1~마을6에서 마을을 둘러볼 수 있는 전용 비행 시간을 받을 수 있어.

- `/마을찾기 플라이` — 신규 유저용 마을 찾기 비행 시작
- `/마을찾기 플라이 시간` — 남은 시간 확인
- 사용할 수 있는 총 비행 시간은 **20분**
- 처음 마을을 생성하거나 가입하면 더 이상 사용할 수 없음

## FAQ

### Q. 모루로 아이템 이름 바꾸면 조공 안 되나요?
아니야. 조공 아이템은 `Material / CMD(커스텀 모델 데이터)` 기준으로 인식돼서 이름을 바꿔도 같은 아이템으로 처리돼.

### Q. 조공할 아이템이 뭔지 모르겠어요
조공 GUI의 `[조공 목록]` 버튼을 보면 돼.  
`[검사/정리]` 버튼을 누르면 조공 불가 아이템은 자동 반환돼.
