## 가방 열기

- `/가방` 또는 `/bag` — 첫 페이지 열기
- `/가방 설정` — 자동 획득, 메시지와 아이템 필터 설정 열기
- `/가방 페이지 <번호>` — 지정한 페이지 바로 열기

통합 메뉴의 **가방** 버튼으로도 열 수 있습니다.

## 크기와 페이지

가방은 처음 **1줄(9칸)**로 시작합니다. 츄르 코인으로 **10줄**, 프리미엄 가방 확장권으로 **20줄**을 각각 추가해 영구 공간을 최대 **31줄(279칸)**까지 늘릴 수 있습니다.

두 확장은 사용 횟수와 한도를 따로 계산합니다. 한 페이지에는 최대 45칸이 표시되며, 공간이 늘어나면 이전·다음 페이지 버튼으로 이동합니다.

### 로얄츄르냥 보너스 공간

로얄츄르냥 이용 중에는 영구 확장 공간과 별도로 **3줄(27칸)**이 추가됩니다. 코인·프리미엄 확장을 모두 마쳤다면 총 **34줄(306칸)**까지 사용할 수 있습니다.

로얄츄르냥 기간이 끝나면 보너스 27칸은 닫히고 가방은 영구 확장 크기로 돌아갑니다. 보너스 칸에 남아 있던 아이템은 사라지지 않고 **우편함으로 이동**하므로 `/우편함`에서 수령하세요.

등급별 다른 혜택은 [츄르냥 멤버십](/support/membership)에서 확인할 수 있습니다.

## 확장 비용

### 츄르 코인 확장

인벤토리에 필요한 **츄르 코인**을 준비하고 가방의 **일반 가방 확장** 버튼을 누르세요. 게임 머니가 아닌 아이템을 사용하며, 한 번에 **1줄(9칸)**씩 최대 **10회** 확장할 수 있습니다.

| 코인 확장 횟수 | 필요한 츄르 코인 |
| --- | ---: |
| 1회째 | 5개 |
| 2회째 | 10개 |
| 3회째 | 20개 |
| 4회째 | 30개 |
| 5회째 | 40개 |
| 6회째 | 50개 |
| 7회째 | 60개 |
| 8회째 | 70개 |
| 9회째 | 80개 |
| 10회째 | 90개 |

코인 확장 10회에 필요한 수량은 **누적 455개**입니다. 프리미엄 확장을 먼저 해도 코인 가격이나 남은 코인 확장 횟수는 바뀌지 않습니다.

### 프리미엄 가방 확장권

인벤토리에 **프리미엄 가방 확장권**을 넣고 가방의 **프리미엄 9칸 확장** 버튼을 누르세요. 확장권 1개로 영구 공간이 **1줄(9칸)** 늘어납니다.

- 츄르 코인 확장과 별도로 **최대 20회** 사용 가능
- 코인 확장을 10회 모두 마친 뒤에도 프리미엄 확장 가능
- 각 버튼에서 코인·프리미엄의 사용 횟수와 남은 횟수 확인 가능
- 로얄츄르냥 이용 여부와 관계없이 확장한 공간은 영구 유지

### 기존에 확장한 가방

확장 방식이 나뉘기 전의 **가방 크기와 다음 코인 확장 가격은 그대로 유지**됩니다. 예전에 어떤 수단으로 확장했는지에 따라 코인 단계를 다시 계산하거나 초기화하지 않습니다.

이전에 사용한 확장권은 새 프리미엄 20회 한도에 포함되지 않습니다. **변경 후 사용하는 확장권부터 따로 계산**하므로, 예를 들어 변경 전에 이미 11줄이었다면 기존 코인 확장 단계는 완료 상태로 유지되고 프리미엄 확장권 20개를 추가로 사용해 31줄까지 늘릴 수 있습니다.

## 모두 넣기

가방 화면의 **모두 넣기**를 누르면 인벤토리와 단축바의 아이템을 가방에 들어가는 만큼 옮깁니다.

- 갑옷 슬롯과 보조손에 든 아이템은 옮기지 않습니다.
- 가방 필터에서 제외한 종류는 넣지 않습니다.
- 가방 공간이 부족해 남은 아이템은 원래 인벤토리에 그대로 남습니다.

## 자동 획득

아이템을 주우면 먼저 인벤토리로 들어가고, 인벤토리에 들어가지 못한 **넘친 수량만** 빈 가방 칸으로 자동 이동합니다. `/가방 설정`에서 다음 항목을 조절하세요.

- 자동 획득 사용 여부
- 자동 획득 메시지 표시 여부
- 획득하지 않을 아이템을 종류별로 고르는 필터

필터에서 선택한 종류는 줍지 않고 바닥에 그대로 남으며, 가방에 직접 넣는 것도 제한됩니다. 필요해서 줍고 싶은 아이템은 필터 선택을 해제하세요. 가방까지 가득 차면 더 이상 자동 보관되지 않으므로 채집 전에 인벤토리와 가방의 여유 공간을 확인하는 것이 좋습니다.

현재 필터에서 선택할 수 있는 품목은 **안산암, 섬록암, 화강암, 뾰족한 점적석, 점적석 블록, 돌, 조약돌, 네더랙**입니다. 필터는 아이템을 삭제하지 않으며, 선택한 품목은 바닥에 남습니다.

## 안전하게 사용하기

- 커서에 아이템을 든 상태에서는 일부 가방 조작이 제한될 수 있습니다.
- 페이지를 넘기기 전 이동한 아이템이 제자리에 저장되었는지 확인하세요.
- 서버에서 나갈 때 열려 있는 가방은 자동으로 저장됩니다.
