## 가방 열기

- `/가방` 또는 `/bag` — 첫 페이지 열기
- `/가방 설정` — 자동 획득과 메시지 설정 열기
- `/가방 페이지 <번호>` — 지정한 페이지 바로 열기

통합 메뉴의 **가방** 버튼으로도 열 수 있습니다.

## 크기와 페이지

가방은 처음 **1줄(9칸)**로 시작해 최대 **11줄(99칸)**까지 확장할 수 있습니다. 한 페이지에는 45칸이 표시되며, 공간이 늘어나면 이전·다음 페이지 버튼으로 이동합니다.

## 확장 비용

현재 서버는 게임 머니 확장 방식을 사용합니다. 한 줄을 추가할 때마다 비용이 1,000원씩 늘어납니다.

| 추가되는 줄 | 비용 | 확장 후 전체 칸 |
| --- | ---: | ---: |
| 2줄 | 1,000원 | 18칸 |
| 3줄 | 2,000원 | 27칸 |
| 4줄 | 3,000원 | 36칸 |
| 이후 | 이전보다 1,000원 증가 | 최대 99칸 |

확장 버튼은 가방 GUI 안에서 선택할 수 있습니다.

## 자동 획득

인벤토리가 가득 찬 상태에서 아이템을 주우면 빈 가방 칸으로 자동 이동할 수 있습니다. `/가방 설정`에서 다음 항목을 조절하세요.

- 자동 획득 사용 여부
- 자동 획득 메시지 표시 여부

가방까지 가득 차면 더 이상 자동 보관되지 않으므로 채집 전에 여유 공간을 확인하는 것이 좋습니다.

## 안전하게 사용하기

- 커서에 아이템을 든 상태에서는 일부 가방 조작이 제한될 수 있습니다.
- 페이지를 넘기기 전 이동한 아이템이 제자리에 저장되었는지 확인하세요.
- 서버에서 나갈 때 열려 있는 가방은 자동으로 저장됩니다.
