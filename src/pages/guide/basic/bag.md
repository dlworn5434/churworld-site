## 가방 열기

- `/가방` 또는 `/bag` — 첫 페이지 열기
- `/가방 설정` — 자동 획득, 메시지와 아이템 필터 설정 열기
- `/가방 페이지 <번호>` — 지정한 페이지 바로 열기

통합 메뉴의 **가방** 버튼으로도 열 수 있습니다.

## 크기와 페이지

가방은 처음 **1줄(9칸)**로 시작해 최대 **11줄(99칸)**까지 확장할 수 있습니다. 한 페이지에는 45칸이 표시되며, 공간이 늘어나면 이전·다음 페이지 버튼으로 이동합니다.

## 확장 비용

가방은 게임 머니가 아니라 인벤토리에 보유한 **츄르 코인**을 사용해 확장합니다. 츄르 코인은 아이템이므로 확장하기 전에 필요한 수량을 인벤토리에 넣어 두세요.

| 추가되는 줄 | 필요한 츄르 코인 | 확장 후 전체 칸 |
| --- | ---: | ---: |
| 2줄 | 20개 | 18칸 |
| 3줄 | 40개 | 27칸 |
| 4줄 | 60개 | 36칸 |
| 5줄 | 80개 | 45칸 |
| 6줄 | 100개 | 54칸 |
| 7줄 | 120개 | 63칸 |
| 8줄 | 140개 | 72칸 |
| 9줄 | 160개 | 81칸 |
| 10줄 | 180개 | 90칸 |
| 11줄 | 200개 | 99칸 |

11줄까지 확장하는 데 필요한 츄르 코인은 **누적 1,100개**입니다. 확장 버튼은 가방 GUI 안에서 선택할 수 있습니다.

## 자동 획득

아이템을 주우면 먼저 인벤토리로 들어가고, 인벤토리에 들어가지 못한 **넘친 수량만** 빈 가방 칸으로 자동 이동합니다. `/가방 설정`에서 다음 항목을 조절하세요.

- 자동 획득 사용 여부
- 자동 획득 메시지 표시 여부
- 획득하지 않을 아이템을 종류별로 고르는 필터

필터에서 선택한 종류는 줍지 않고 바닥에 그대로 남으며, 가방에 직접 넣는 것도 제한됩니다. 필요해서 줍고 싶은 아이템은 필터 선택을 해제하세요. 가방까지 가득 차면 더 이상 자동 보관되지 않으므로 채집 전에 인벤토리와 가방의 여유 공간을 확인하는 것이 좋습니다.

현재 필터에서 선택할 수 있는 품목은 **안산암, 섬록암, 화강암, 뾰족한 점적석, 점적석 블록, 돌, 조약돌, 네더랙**입니다. 필터는 아이템을 삭제하지 않으며, 선택한 품목은 바닥에 남습니다.

## 안전하게 사용하기

- 커서에 아이템을 든 상태에서는 일부 가방 조작이 제한될 수 있습니다.
- 페이지를 넘기기 전 이동한 아이템이 제자리에 저장되었는지 확인하세요.
- 서버에서 나갈 때 열려 있는 가방은 자동으로 저장됩니다.
