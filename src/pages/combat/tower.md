## 더 타워는 어떤 콘텐츠인가요?

더 타워는 매 원정마다 무구와 각인 카드를 조합해 **총 30층**을 공략하는 전투 콘텐츠입니다. 혼자 도전하거나 2~4명의 원정대를 만들어 함께 도전할 수 있습니다.

- 검·활·방패·주먹 중 하나를 선택해 출전
- 층을 돌파하며 각인 카드와 유물을 골라 이번 원정의 빌드 완성
- 탑에서 얻은 장비, 장신구, 무구 숙련도와 강화는 다음 원정에도 유지
- 일반·베테랑·승천·악몽 난이도 제공
- 탑 안에서는 블록을 설치하거나 파괴할 수 없음

더 타워의 준비 화면과 전투 HUD를 사용하려면 **츄르월드 전용 Fabric 클라이언트로 접속해야 합니다.** 일반 클라이언트에서는 정상적으로 출전할 수 없습니다.

## 입장하는 순서

1. `Shift + F` 통합 메뉴에서 **전투 → 더 타워**를 선택하거나 `/탑 시작`을 입력합니다.
2. 탑 대기실과 준비 화면에서 사용할 무구, 장비, 장신구와 난이도를 확인합니다.
3. 함께 도전한다면 원정대를 만들고 인원을 초대합니다.
4. 모든 인원이 준비되면 파티장이 출전을 확정합니다. 혼자라면 바로 출전을 확정할 수 있습니다.
5. 출전 무구와 첫 각인을 선택하면 1층 원정이 시작됩니다.

`/탑 시작`은 곧바로 전투를 시작하는 명령어가 아니라 **탑 대기실로 들어가는 명령어**입니다. 대기실에서 준비를 마친 뒤 출전해야 합니다.

탑에서는 탑 전용 무구와 장비, 물약을 사용합니다. 일반 월드에서 들고 있던 아이템과 상태는 원정과 분리해 보관되며, 정상적으로 나가면 입장 전 상태로 돌아옵니다.

## 혼자 또는 원정대로 도전하기

| 인원 | 이용 방법 |
| --- | --- |
| 1명 | 원정대를 만들지 않고 혼자 출전 |
| 2~4명 | `/탑 파티`에서 원정대를 만들고 초대 후 함께 출전 |

- 협동 출전에는 최소 2명, 최대 4명이 필요합니다.
- 파티장은 초대, 추방, 출전 시작과 출전 대기 취소를 관리합니다.
- 각 원정대원은 자신의 무구와 탑 장비를 준비해야 합니다.
- 인원이 늘어나면 전투에 등장하는 적 구성도 원정대 규모에 맞게 조정됩니다.
- 원정대 구성이 바뀌거나 누군가 준비 조건을 만족하지 못하면 출전 준비가 취소될 수 있습니다.

초대와 수락은 `/탑 파티` 화면에서 진행하는 것을 권장합니다. 원정 중에는 원정대를 바꾸거나 장비·장신구·강화를 변경할 수 없습니다.

## 무구와 난이도

### 무구

| 무구 | 전투 특징 |
| --- | --- |
| 검 | 근거리 공격과 패링·반격을 중심으로 싸움 |
| 활 | 거리를 유지하며 조준과 차지 공격으로 싸움 |
| 방패 | 방어와 방패치기·반격, 협동 중 아군 보호에 유리 |
| 주먹 | 빠르게 파고들며 연속 공격과 기동으로 싸움 |

무구마다 숙련 성장과 두 가지 규율이 따로 있습니다. 처음에는 익숙한 무구로 일반 난이도를 연습하고, 공격 간격·회피·패링·조준 방식이 손에 익은 뒤 높은 난이도에 도전하는 것을 권장합니다.

### 난이도

| 난이도 | 설명 |
| --- | --- |
| 일반 | 탑의 적과 층 기믹을 익히기 좋은 기본 난이도 |
| 베테랑 | 적이 강해지고 숙련 경험치와 장비 획득 기회가 좋아짐 |
| 승천 | 높은 생존력과 완성된 빌드를 요구하는 상급 난이도 |
| 악몽 | 가장 높은 전투 난도와 보상을 목표로 하는 최상급 난이도 |

난이도는 원정을 시작할 때 확정되며 진행 중에는 변경할 수 없습니다. 아직 선택할 수 없는 난이도는 준비 화면에 표시되는 해금 조건을 먼저 달성해야 합니다.

## 30층 진행 구조

| 층 | 주요 내용 |
| --- | --- |
| 3·13·23층 | 유물 선택 |
| 5·9·15·19·25·29층 | 장비 보상이 보장되는 정예 구간 |
| 10·20·30층 | 보스 전투와 층핵 획득 |
| 30층 | 최종 보스와 원정 정복 |

일반 층에서도 장비를 얻을 수 있으며, 정예 구간에서는 장비 보상이 보장됩니다. 보스 층에서는 더 많은 장비를 얻을 수 있고 10·20·30층에서 획득하는 층핵은 무구 강화와 규율 성장에 사용됩니다.

### 각인 카드 선택

전투 사이에 각인 선택 화면이 열리면 세 장 중 하나를 골라 이번 원정의 빌드를 강화합니다.

- 선택 화면마다 세 장의 카드가 제시됨
- 선택 화면마다 전체 카드를 바꾸는 무료 새로고침 1회
- 각 막마다 원하지 않는 카드 계열을 제외하는 소거 1회
- 90초 동안 고르지 않으면 첫 번째 유효 카드가 자동 선택됨

선택한 각인과 유물은 현재 원정에서만 작동하며, 패배·포기·정복으로 원정이 끝나면 초기화됩니다. 반대로 탑 장비, 장신구, 무구 숙련도와 강화는 계속 유지됩니다.

## 체력과 탑 물약

- 원정 시작 체력: 100
- 시작 탑 물약: 2개
- 물약 1개 사용 시 체력 35 회복
- 보스 처치 시 체력 20 회복, 물약 1개 보충
- 체력이 35 이하가 되는 위기 상황에는 `최후의 숨결`과 짧은 무적이 발동

탑 물약은 일반 월드의 물약과 별개입니다. 남은 개수는 HUD에서 확인할 수 있으며, 모두 사용하면 다음 보스 보충 전까지 추가로 사용할 수 없습니다.

## 탑 장비와 장신구

### 장비 부위

탑 장비는 다섯 부위로 나뉩니다.

- 머리
- 가슴
- 손
- 다리
- 발

장비에는 부위별 주 능력과 보조 옵션이 붙습니다. 층과 난이도가 높을수록 좋은 결과가 나올 가능성이 높지만, 장비 결과는 매번 독립적으로 정해집니다.

필요하지 않은 장비를 분해하면 **장비 조각**을 얻습니다. 장비 조각은 탑 상점에서 새 장비와 장신구를 복원하는 데 사용합니다.

### 장신구

장신구는 `반지·목걸이·부적` 세 슬롯을 사용합니다.

- 최고 기록이 10층 이상일 때 장신구 상점 이용 가능
- 장신구는 탑 상점에서만 획득
- 보스가 장신구를 직접 떨어뜨리지 않음
- 각 뽑기는 서로 독립이며 누적 천장이나 10회 확정 보상이 없음

장신구 등급 확률은 희귀 76%, 영웅 21%, 전설 3%입니다. 정확한 상품과 비용은 탑 상점 화면에서도 다시 확인할 수 있습니다.

## 무구 숙련도·강화·규율

### 무구 숙련도

무구별 숙련도는 최대 30랭크입니다. 해당 무구로 층과 보스를 돌파하면 숙련 경험치를 얻으며, 숙련 보상은 무조건적인 공격력 증가보다 무구 조작과 각인 선택을 보조하는 방향으로 적용됩니다.

### 무구 강화

- 무구별 최대 `+5`
- 강화 1단계마다 해당 무구 효과 4% 증가
- 강화 실패·하락·파괴 없음
- 강화 단계에 따라 장비 조각과 층핵 사용

준비 화면의 무구 공방이나 `/탑 강화 <무기>`로 강화할 수 있습니다. 예를 들어 검을 강화하려면 `/탑 강화 검`을 입력할 수 있습니다.

### 규율과 전승 집중

해당 무구의 숙련도 5랭크와 강화 +5를 모두 달성하면 무구별 **규율**이 열립니다. 무구마다 두 가지 규율이 있으며, 다른 규율로 바꿀 때는 층핵 1개가 필요합니다.

전승 집중은 첫 각인 선택을 원하는 규율 방향으로 유도하는 기능입니다. 기본 저장 한도는 3회이며, 실제 출전이 성공했을 때만 1회가 사용됩니다.

## 탑 상점

모든 가격은 장비 분해로 얻는 **장비 조각** 기준입니다.

| 상품 | 비용 | 이용 조건 |
| --- | ---: | --- |
| 무작위 부위 장비 1개 | 100 | 최고 1층 이상 |
| 무작위 부위 장비 10개 | 900 | 최고 1층 이상 |
| 원하는 부위 장비 1개 | 150 | 최고 1층 이상 |
| 전체 장신구 1회 | 300 | 최고 10층 이상 |
| 전체 장신구 10회 | 2,700 | 최고 10층 이상 |
| 반지·목걸이·부적 집중 1회 | 330 | 최고 10층 이상 |
| 반지·목걸이·부적 집중 10회 | 2,970 | 최고 10층 이상 |

10회 상품도 결과는 각각 독립적으로 결정됩니다. 장신구 10회 상품에는 확정 등급이나 천장이 없습니다.

## 랭킹 원정

랭킹 원정에서는 장신구와 무구 강화는 적용되지만, 기록 경쟁의 조건을 맞추기 위해 일부 영구 성장 보너스가 제한됩니다.

- 장신구와 강화: 적용
- 무구 숙련도의 직접 능력치 보너스: 미적용
- 수집형 영구 패시브: 미적용
- 칭호와 외형: 적용

도전 과제로 얻는 칭호는 능력치를 올리지 않는 표시·수집 보상입니다.

## 재접속과 안전한 종료

전투 중 연결이 끊겼다면 **45초 안에 같은 계정으로 다시 접속**해 주세요. 유예 시간 안에 돌아오면 진행 중인 원정을 이어갈 수 있습니다.

- 잠시 끊겼을 때: 바로 재접속하고 탑 상태 확인
- 복구 안내가 표시될 때: `/탑 복구` 사용
- 현재 원정을 포기할 때: `/탑 중단`
- 대기실에서 일반 월드로 돌아갈 때: `/탑 나가기`

서버 상황에 따라 새 원정 입장이 잠시 대기열에 들어갈 수 있습니다. 이 경우 반복해서 입장 버튼을 누르지 말고 화면에 표시되는 순번을 기다려 주세요. 이미 시작한 원정은 입장 대기 때문에 중단되지 않습니다.

| --- | --- |
| `/탑 시작` | 탑 대기실 입장 |
| `/탑 메뉴` | 전용 준비 화면 열기 |
| `/탑 메뉴 상자` | 상자형 준비 화면 열기 |
| `/탑 파티` | 원정대 생성·초대·수락·탈퇴·추방 화면 |
| `/탑 나가기` | 탑 대기실 나가기 |
| `/탑 상태` | 현재 원정·대기 상태 확인 |
| `/탑 중단` | 진행 중인 원정 포기 또는 출전 대기 취소 |

| `/탑 복구` | 중단된 상태의 안전 복구 시도 |

## 입장이 되지 않을 때

1. 츄르월드 전용 Fabric 클라이언트로 접속했는지 확인합니다.
2. 이미 다른 원정이나 탑 입장 대기에 들어가 있는지 `/탑 상태`로 확인합니다.
3. 원정대원 전원이 온라인이고 준비를 마쳤는지 확인합니다.
4. 인원이 2~4명인지, 파티장이 출전을 누르고 있는지 확인합니다.
5. 모든 입장 공간이 사용 중이라면 현재 대기 순번을 기다립니다.

전용 클라이언트가 정상인데도 화면이 열리지 않거나 저장된 원정을 이어갈 수 없다면 반복해서 명령을 입력하지 말고 운영진에게 문의해 주세요.
