## 가장 자주 쓰는 명령어

| 명령어 | 기능 |
| --- | --- |
| `/메뉴` | 통합 메뉴 열기 |
| `/길라잡이` | 초반 진행 목표 열기 |
| `/life` | 생활 메인 메뉴 열기 |
| `/의뢰` | 의뢰 목록 열기 |
| `/가방` | 개인 가방 열기 |
| `/우편함` | 우편함 열기 |
| `/거래소` | 유저 거래소 열기 |
| `/마을` | 마을 메뉴와 도움말 열기 |

## 생활

| 명령어 | 기능 |
| --- | --- |
| `/life skills mining` | 광부 스킬 GUI |
| `/life skills farming` | 농부 스킬 GUI |
| `/life skills fishing` | 어부 스킬 GUI |
| `/life skills cooking` | 요리사 스킬 GUI |
| `/life skills woodcutting` | 나무꾼 스킬 GUI |
| `/life skills smithing` | 대장술 스킬 GUI |
| `/life fishing` | 어부 메뉴 바로 열기 |
| `/life scan` | 광석 감지 시작 |
| `/life scan off` | 광석 감지 종료 |
| `/life scan mode distance` | 가까운 광석부터 표시 |
| `/life scan mode value` | 가치가 높은 광석부터 표시 |
| `/life mana` | 현재 마나 확인 |
| `/life recipes` | 요리 레시피북 열기 |
| `/경험치` | 적용 중인 경험치 증가 확인 |

## 이동과 홈

| 명령어 | 기능 |
| --- | --- |
| `/sethome [이름]` | 개인 홈 저장 |
| `/home [이름]` | 개인 홈으로 이동 |
| `/homes` | 개인 홈 목록 |
| `/delhome <이름>` | 개인 홈 삭제 |
| `/phome 설정` | 공개 홈 등록 |
| `/phomelist` | 공개 홈 목록 GUI |
| `/rtp` | 허용 월드에서 랜덤 이동 |
| `/back` | 직전 텔레포트 위치로 이동. 등급 혜택 필요 |

## 마을과 소통

| 명령어 | 기능 |
| --- | --- |
| `/마을 도움말` | 마을 명령어 확인 |
| `/마을 생성 <이름>` | 새 마을 생성 |
| `/마을 관리` | 마을 관리 GUI |
| `/마을 조공` | 조공 GUI |
| `/채팅` | 지역·마을 채팅 모드 선택 |
| `/질문 <내용>` | 전체 질문 보내기 |
| `/답변 <플레이어> <내용>` | 질문에 답변하기 |
| `/칭호` | 보유 칭호 선택 |

## 가방과 편의

| 명령어 | 기능 |
| --- | --- |
| `/가방 설정` | 자동 획득과 메시지 설정 |
| `/가방 페이지 <번호>` | 가방의 지정 페이지 열기 |
| `/제작대` | 원격 제작대 열기. 등급 혜택 필요 |
| `/혜택` | 츄르냥 등급 혜택 확인 |
| `/cp lock` | 개인 잠금 모드 시작 |
| `/cp unlock` | 개인 잠금 해제 모드 시작 |
| `/cp list` | 내 잠금 목록 확인 |

명령어가 동작하지 않는다면 현재 월드, 공용 레벨 조건, 보유 등급과 권한을 먼저 확인하세요.
