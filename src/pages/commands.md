## 가장 자주 쓰는 명령어

| 명령어 | 기능 |
| --- | --- |
| `/튜토리얼` | 신규 유저 생활 튜토리얼 진행 상태 확인 |
| `/메뉴` | 통합 메뉴 열기 |
| `/길라잡이` | 초반 진행 목표 열기 |
| `/life` | 생활·생산 메인 메뉴 열기 |
| `/의뢰` | 의뢰 목록 열기 |
| `/가방` | 개인 가방 열기 |
| `/우편함` | 우편함 열기 |
| `/거래소` | 유저 거래소 열기 |
| `/마을` | 마을 메뉴와 도움말 열기 |
| `/잠수` | 잠수 의자와 별 관련 메인 메뉴 열기 |

## 생활

| 명령어 | 기능 |
| --- | --- |
| `/life skills mining` | 광부 스킬 GUI |
| `/life skills farming` | 농부 스킬 GUI |
| `/life skills fishing` | 어부 스킬 GUI |
| `/life skills woodcutting` | 나무꾼 스킬 GUI |
| `/life fishing` | 어부 메뉴 바로 열기 |
| `/life 도감` | 생활 도감 열기. `/life codex`도 가능 |
| `/life scan` | 광석 감지 시작 |
| `/life scan off` | 광석 감지 종료 |
| `/life scan mode distance` | 가까운 광석부터 표시 |
| `/life scan mode value` | 가치가 높은 광석부터 표시 |

## 생산

| 명령어 | 기능 |
| --- | --- |
| `/life skills cooking` | 요리사 스킬 GUI |
| `/life skills smithing` | 대장술 스킬 GUI |
| `/life recipes` | 요리 레시피북 열기 |
| `/제작 로그 대기열` | 진행 중인 생활 제작 확인 |
| `/제작 로그 [수]` | 최근 생활 제작 결과 확인 |

## 생활·생산 공통

| 명령어 | 기능 |
| --- | --- |
| `/life mana` | 현재 마나 확인 |
| `/경험치` | 적용 중인 경험치 증가 확인 |
| `/큐브 검사` | 주 손 드라코라이트 방어구의 잠재능력 확인 |
| `/큐브 수령` | 완료되거나 선택 대기 중인 큐브 결과 받기 |
| `/장비강화` | 주 손의 본인 각인 드라코라이트 방어구 강화 |

## 이동과 홈

| 명령어 | 기능 |
| --- | --- |
| `/sethome [이름]` | 개인 홈 저장 |
| `/home [이름]` | 개인 홈으로 이동 |
| `/homes` | 개인 홈 목록 |
| `/delhome <이름>` | 개인 홈 삭제 |
| `/phome 설정` | 공개 홈 등록 |
| `/phomelist` | 공개 홈 목록 GUI |
| `/rtp` | 허용 월드에서 랜덤 이동 |
| `/back` | 직전 텔레포트 위치로 이동. 등급 혜택 필요 |

## 마을과 소통

| 명령어 | 기능 |
| --- | --- |
| `/마을 도움말` | 마을 명령어 확인 |
| `/마을 생성 <이름>` | 새 마을 생성 |
| `/마을 관리` | 마을 관리 GUI |
| `/마을 조공` | 조공 GUI |
| `/마을 세금` | 주간 세금 납부와 마을 자산 현황 |
| `/채팅` | 지역·마을 채팅 모드 선택 |
| `/질문 <내용>` | 전체 질문 보내기 |
| `/답변 <플레이어> <내용>` | 질문에 답변하기 |
| `/칭호` | 보유 칭호 선택 |

## 가방과 우편함

| 명령어 | 기능 |
| --- | --- |
| `/가방 설정` | 자동 획득과 메시지 설정 |
| `/가방 페이지 <번호>` | 가방의 지정 페이지 열기 |
| `/우편함 보내기 <플레이어>` | 손에 든 아이템 발송. 기본 비용 1,000원 |
| `/stars` | 별 창고를 열어 획득한 별 판매 |
| `/starshop` | 별 포인트 상점 열기 |
| `/dive stop` | 진행 중인 잠수 종료 |

## 멤버십과 잠금

| 명령어 | 기능 |
| --- | --- |
| `/제작대` | 원격 제작대 열기. 등급 혜택 필요 |
| `/혜택 [등급]` | 츄르냥 멤버십 혜택 확인 |
| `/한닉 <닉네임> [색깔]` | 등록된 한글 닉네임 이용권 사용 |
| `/cp lock` | 개인 잠금 모드 시작 |
| `/cp unlock` | 개인 잠금 해제 모드 시작 |
| `/cp list` | 내 잠금 목록 확인 |

명령어가 동작하지 않는다면 튜토리얼 완료 여부, 현재 월드, 공용 레벨 조건과 보유 멤버십을 먼저 확인하세요.
