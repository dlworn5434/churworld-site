## 자동 창고 정리

| 명령어 | 기능 |
| --- | --- |
| `/창고 도움말` | 자동 창고 명령어 안내 |
| `/창고 목록` | 내 마을의 창고와 작동 상태·목적지 수 확인 |
| `/창고 생성 <이름>` | 60초 안에 투입함을 우클릭해 창고 생성 |
| `/창고 새로고침 <이름>` | 주변의 불러와진 상자와 분류 액자 재탐색 |
| `/창고 일시정지 <이름>` | 자동 정리 중지 |
| `/창고 재개 <이름>` | 자동 정리 재개 |
| `/창고 삭제 <이름> 확인` | 등록만 삭제. 실제 상자와 아이템은 유지 |

생성·설정·관리는 마을장·부마을장·매니저 등 마을 땅 관리 권한이 필요합니다. 등록된 액자를 **Shift + 우클릭**하면 분류 품목을 설정할 수 있습니다. 자세한 설치 순서와 지원 범위는 [자동 창고 정리 안내](/guide/basic/storage)를 확인하세요.

## 카메라·코디와 그림

| 명령어 | 기능 |
| --- | --- |
| `/코디` | 보유 코디 확인과 착용 |
| `/코디뽑기` | 일반 코디·도구·방어구 스킨 뽑기 열기 |
| `/코디뽑기 상점` | 마일리지 코디 상점 열기 |

| `/daub open [1~3]` | 지정한 크기의 그림 이젤 열기 |
| `/daub close` | 현재 이젤 닫기 |
| `/daub save <이름>` | 현재 그림 저장 |
| `/daub load <이름>` | 저장한 그림 불러오기 |
| `/daub saves` | 저장한 그림 목록 확인 |
| `/daub delete <이름>` | 저장한 그림 삭제 |
| `/daub color #RRGGBB` | 붓 색상 지정 |
| `/daub brush <1~24>` | 붓 크기 지정 |
| `/daub export [single] <이름>` | 저장한 작품을 지도 아이템으로 만들기 |

카메라 명령은 `/churcamera`로 입력해도 같은 기능을 사용할 수 있습니다.

## 멤버십과 잠금

| 명령어 | 기능 |
| --- | --- |
| `/멤버십` | 츄르냥 멤버십 구매와 남은 기간 확인 |
| `/제작대` | 원격 제작대 열기. 등급 혜택 필요 |
| `/혜택 [등급]` | 츄르냥 멤버십 혜택 확인 |
| `/수리` | 로얄츄르냥이 주 손의 내구도 장비를 300원에 완전 수리. 재사용 1시간 |
| `/한닉 <닉네임> [색깔]` | 등록된 한글 닉네임 이용권 사용 |
| `/갑옷숨기기` | 로얄츄르냥 전용 갑옷 외형 숨김 전환 |
| `/cp lock` | 개인 잠금 모드 시작 |
| `/cp unlock` | 개인 잠금 해제 모드 시작 |
| `/cp list` | 내 잠금 목록 확인 |

명령어가 동작하지 않는다면 튜토리얼 완료 여부, 현재 월드, 공용 레벨 조건과 보유 멤버십을 먼저 확인하세요.
