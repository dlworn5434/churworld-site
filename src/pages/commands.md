## 생활

| 명령어 | 기능 |
| --- | --- |
| `/생활 도감` · `/life 도감` | 채광·농사·낚시·요리·벌목·생존 도감 열기 |
| `/life skills mining` | 광부 스킬 GUI |
| `/life skills farming` | 농부 스킬 GUI |
| `/life skills fishing` | 어부 스킬 GUI |
| `/life skills woodcutting` | 나무꾼 스킬 GUI |
| `/life fishing` | 어부 메뉴 바로 열기 |
| `/물고기 변환` | 등록된 일반·고급·희귀 물고기를 무지개 물고기로 변환 |
| `/생활 미니게임고정 상태` | 현재 고정된 낚시 미니게임과 남은 기간 확인 |
| `/life scan` | 광석 감지 시작 |
| `/life scan off` | 광석 감지 종료 |
| `/life scan mode distance` | 가까운 광석부터 표시 |
| `/life scan mode value` | 가치가 높은 광석부터 표시 |

## 생활·생산 공통

| 명령어 | 기능 |
| --- | --- |
| `/life mana` | 현재 마나 확인 |
| `/경험치` | 적용 중인 경험치 증가 확인 |
| `/장비스탯` · `/스탯분배` | 드라코라이트 방어구 기본 스탯 분배·재설정 화면 열기 |
| `/큐브 검사` | 주 손 드라코라이트 방어구의 잠재능력 확인 |
| `/큐브 수령` | 완료되거나 선택 대기 중인 큐브 결과 받기 |

생활 도감과 생활 조각 획득·강화석 제작은 현재 이용할 수 있습니다. 별 장비 강화 기능은 아직 준비 중이므로 관련 명령어는 플레이 안내에서 제외합니다.

## 마을과 소통

| 명령어 | 기능 |
| --- | --- |
| `/마을 도움말` | 마을 명령어 확인 |
| `/마을 생성 <이름>` | 새 마을 생성 |
| `/마을 관리` | 마을 관리 GUI |
| `/마을 조공` | 조공 GUI |
| `/마을 세금` | 주간 세금 납부와 마을 자산 현황 |
| `/마을 돈 넣기 <금액\|전부>` | 마을 은행에 돈 입금 |
| `/마을 출금 <금액\|최대>` | 마을장이 마을 자산 일부 인출 |
| `/마을 로그` | 매니저 이상이 최근 마을 관리 기록 확인 |
| `/마을 로그막대기` | 점유지의 블록 설치·파괴·열기 기록 확인 도구 수령 |
| `/마을 스폰` | 마을 스폰으로 이동 |
| `/마을 스폰 설정` | 매니저 이상이 점유지 안에서 마을 스폰 설정 |
| `/마을 플라이 날기` | 내 마을 점유지에서 저장된 비행 시간 사용 |
| `/마을 플라이 해제` | 마을 비행 종료 |
| `/마을 플라이 시간` | 남은 마을 비행 시간 확인 |
| `/마을 랭킹 [페이지]` | 누적 조공 경험치 기준 마을 랭킹 확인 |
| `/마을 이름변경 <새이름>` | 마을장이 5,000원을 내고 이름 변경 |
| `/마을 손님 추방 <닉네임>` | 초대한 손님을 마을에서 내보내기 |
| `/마을찾기 플라이` | 첫 마을 가입 전 사용할 수 있는 20분 탐색 비행 |
| `/마을찾기 플라이 시간` | 남은 탐색 비행 시간 확인 |
| `/채팅` | 지역·마을 채팅 모드 선택 |
| `/질문 <내용>` | 전체 질문 보내기 |
| `/답변 <플레이어> <내용>` | 질문에 답변하기 |
| `/칭호` | 보유 칭호 선택 |

## 멤버십과 잠금

| 명령어 | 기능 |
| --- | --- |
| `/제작대` | 원격 제작대 열기. 등급 혜택 필요 |
| `/혜택 [등급]` | 츄르냥 멤버십 혜택 확인 |
| `/한닉 <닉네임> [색깔]` | 등록된 한글 닉네임 이용권 사용 |

| `/cp unlock` | 개인 잠금 해제 모드 시작 |
| `/cp list` | 내 잠금 목록 확인 |

명령어가 동작하지 않는다면 튜토리얼 완료 여부, 현재 월드, 공용 레벨 조건과 보유 멤버십을 먼저 확인하세요.
