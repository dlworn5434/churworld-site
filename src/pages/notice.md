## 전체 목차 이용하기

넓은 PC 화면에서는 왼쪽에 **전체 목차**가 항상 표시됩니다. 원하는 문서를 누르면 해당 안내로 바로 이동합니다. 화면이 좁거나 모바일에서는 왼쪽의 **전체 목차** 버튼을 눌러 같은 목록을 열 수 있습니다.

문서 이름이 기억나지 않을 때는 목차 위의 **목차에서 검색** 또는 상단의 **문서 검색**을 사용하세요.

## 위키에서 확인할 수 있는 내용

| 분야 | 주요 안내 |
| --- | --- |
| 시작과 편의 | 튜토리얼, 가방, 우편함, 상점, 거래소, 물물교환, 택시, 카메라, 코디 |
| 마을 | 생성과 점유, 권한, 세금, 경작지, 청크 바이옴, 마을 건축과 효과 타워 |
| 생활 | 공용 성장과 스킬 랭크, 6개 직업, 지역 활력, 도감, 제작·강화·큐브 |
| 전투·모험 | 1~4인 더 타워와 서버 판정형 RPG 잔향록 |
| 잠수 | 일반·프리미엄 의자, 포인트 상점과 조각 |
| 후원 | 츄르냥 등급과 이용 기능 |
| 운영 안내 | 서버 규칙, 명령어, 월드 안내와 공식 디스코드 |

장비의 별 강화는 현재 이용할 수 있으며 단계별 재료와 주의사항은 [장비·강화·큐브 안내](/life/equipment)에서 확인할 수 있습니다. 상품 구성이나 게임 화면에 실시간으로 표시되는 값은 접속 중인 서버 화면을 최종 기준으로 확인하세요.
