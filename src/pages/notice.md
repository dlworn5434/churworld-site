## 문서 업데이트

- 신규 카테고리: **후원**
- 신규 문서: **신규 유저 튜토리얼 / 우편함 / 상점과 거래 / 츄르냥 멤버십**
- 츄르냥 멤버십: 로얄 원격 생활상점과 한글 닉네임 이용권 반영
- 마을: 레벨별 인원·점유·경작지 한도와 주간 세금·4주 미납 처리 반영
- 농부: 현재 스킬 GUI와 비닐하우스·허수아비 설명 반영
- 잠수 의자: 토큰·설치 가구 방식, 별 확률과 판매 포인트 반영
- 통합 메뉴: 튜토리얼 잠금, 디스코드·도감·로얄 전용 상점 반영
- 공식 디스코드 링크 최신화
- 생활 콘텐츠: **광부 / 어부 / 농부 / 나무꾼**
- 생산 콘텐츠: **요리사 / 대장술**
- 공통 안내: **성장 구조 / 작업대와 시스템 / FAQ**
- 기본 콘텐츠: **마을 / 잠수 의자**
- 명령어 모음 최신화
- 전용 클라이언트 접속 안내와 공식 디스코드 링크 반영
- 나무꾼 · 대장술 전용 이미지와 생활·생산 분류 추가
