## 제재 기준

외부 모드·리소스팩·프로그램을 통한 아래 항목은 서버에서 금지됩니다. **위반 내용에 따라 경고 1~5점이 부여됩니다.**

모드 전체가 금지된 경우에는 **실제로 사용하거나 활성화하지 않았더라도 설치·보유만으로 제재될 수 있습니다.** 특정 기능만 금지하는 항목은 아래 보충 안내의 범위를 따릅니다.

## 기능별 금지 범위

| 모드·기능 | 보충 안내 |
| --- | --- |
| **Litematica** | **Easy Place(쉬운 설치) 기능 금지**. 설계도 표시와 재료 목록은 이용할 수 있습니다. |
| **Litematica Printer 등** | **프린터 기능 금지** |
| **Inventory Profiles Next** | **자동 보충 기능만 금지** |
| **Tweakeroo** | **반복 입력·건축 자동화 관련 기능 금지** |
| **ClientHarvest** | **자동 농사 관련 기능 금지** |
| **Item Scroller** | **반복 대량 제작 기능 금지**. 일반 스크롤·아이템 이동은 이 제한에 포함되지 않습니다. |
| **셰이더 밝기 조절** | **셰이더는 기본 설정을 사용해 주세요. 밝기 조절 기능을 일정 수준 이상 높여 사용할 경우 제재될 수 있습니다.** |
| **안개 제거·물속 시야 개선·광석 발광** | **해당 기능 금지** |

목록에 없더라도 같은 금지 기능을 제공하는 모드·리소스팩·프로그램에는 같은 기준이 적용됩니다. 허용 여부가 애매하면 사용 전에 운영진에게 문의해 주세요.

그 밖의 이용 기준은 [전체 서버 규칙](/rules)에서 확인할 수 있습니다.
