# 츄르월드 시작 가이드

츄르월드에 처음 온 걸 환영해!

## 1. 서버 접속
- 서버 주소: `churworld.kr`
- 접속 방식: **츄르월드 전용 클라이언트만 가능**
- 먼저 [공식 디스코드](https://discord.gg/9n4F7rYWVE)에 참가해 마인크래프트 계정을 인증하고 화이트리스트 등록을 완료해줘.
- 전용 클라이언트 설치 파일과 최신 배포 안내는 공식 디스코드에서 확인할 수 있어.

## 2. 처음 해야 할 것
- [첫걸음 가이드](/guide/basic/start)에서 가입과 접속 순서 확인하기
- 서버 규칙 확인하기
- `Shift + F` 통합 메뉴 열기

## 3. 추천 루트
1. 공식 디스코드에서 계정을 인증한다
2. 전용 클라이언트로 서버에 접속한다
3. 통합 메뉴와 길라잡이를 확인한다
4. 생활·생산 직업을 고르고 마을에 정착한다

## 4. 도움이 필요할 때
문제가 생기면 공지사항을 먼저 확인하고, 필요한 경우 운영진에게 문의해줘.

## 5. 꼭 기억할 것
츄르월드는 함께 오래 즐기는 서버를 목표로 해.
서로 배려하면서 즐겁게 플레이해줘.
